# TEETH · 代码视频 v2

> **🆕 这是新版（v2，2026-10-07）。** 成片文件名是 `Teeth_v2_1080p60.mp4`。旧版 v1（全红、震动、负片闪的版本）保留在 git 提交 `555c5c8`。

5 Seconds of Summer《Teeth》的纯代码视觉：1920×1080、60 帧、3 分 25 秒、139 BPM。

## 这首歌在讲什么 → 画面

查过这首歌：它写的是一段**又爱又恨、有毒的感情**。歌里说对方有"一颗长着牙的心"，像有两种人格，前一秒深爱，后一秒伤人。
乐队成员说这首歌是"脆弱与攻击性之间的平衡"。编曲是工业摇滚（Tom Morello 弹的吉他），跺脚 + 拍手的重鼓，
官方 MV 是一场"改变意识的实验"，充满幻觉。

所以 v2 的设计：

- **母题：一颗心的两面。** 左半边冷青，右半边品红，中间是骨白。v1 的全屏血红去掉了，红色只留一点点缀。
- **"长着牙的心"**：心脏正中一道缝，平时张着，每一下重鼓**猛地咬合**，两排獠牙交错。
- **实验记录**：右上角是"实验记录 · 第几项"，底部是一条**心电图**，每一下鼓点就是一次心跳。
- **不震动、不闪屏、不撕裂。** 鼓点只驱动画面里发生的事：心跳、咬合、墨滴落下、齿轮咬进一齿、裂纹、玫瑰开放。
- **十段不同的画面**，每段开头一张中英双语字卡（我自己写的短句，不是歌词）。

## 歌词（中英双语）

我不能把整首歌的歌词写进代码，但画面里有一层双语歌词，只要你提供带时间轴的歌词文件：

1. 在网易云音乐 / QQ 音乐找到《Teeth》，导出 **LRC 歌词**（每行形如 `[01:23.45]歌词`）。
2. 存成 `teeth/lyrics/teeth.lrc`（UTF-8）。中文翻译可以三选一：
   - 另存一个 `teeth/lyrics/teeth.zh.lrc`（时间轴和原文对应）；
   - 或者在同一个文件里，同一个时间戳下一行英文、一行中文（网易云"原文 + 翻译"导出就是这种格式）；
   - 或者一行写成 `English / 中文`。
3. 重新渲染。没有这个文件时不显示歌词，其它一切照常。

显示效果：英文大写衬线字，逐词"咬"进来；中文在下面一行，用品红色。
整体偏早或偏晚时，改 `render/src/lyrics.js` 里的 `OFFSET`（秒，正数 = 推迟）。

## 一条命令出片

需要 Node.js 18+ 和 ffmpeg（Windows：`winget install Gyan.FFmpeg`）。

```bash
cd teeth
node build.js                       # 完整构建，成片在 render/out/Teeth_v2_1080p60.mp4（另有分享版）
node build.js --from 46 --to 60     # 只渲染第一次副歌前后（带音乐），先看效果
node build.js --version v3          # 新版本号；不会覆盖旧版
cd render && node src/preview.js shot.png 22 49.5 105 150   # 把几个时间点拼成预览图
```

有 NVIDIA 显卡时自动用显卡编码。速度：单核每帧约 0.1–0.5 秒，8 个进程大约 10–15 分钟。

## 代码结构

- `render/src/frame.js`：按段落选场景、交界处交叉淡化，叠片名、字卡、歌词、HUD 和心电图
- `render/src/world/*.js`：七个场景模块（heart、rorschach、corridor、thorns、machine、mirror、finale）
- `render/src/lyrics.js`：读取 LRC，中英配对，逐词显示
- `render/src/audio.js`：节拍网格和每一拍实测的鼓点强度（来自 `analysis/teeth.json`）

## 音乐分析（已做好）

`analysis/teeth.json` 由 `analysis/analyze.py` 生成（需要 `pip install librosa`）：139 BPM，每拍 0.4317 秒，
全曲漂移在 ±6 毫秒以内；每一拍的底鼓和拍手强度都是实测值。鼓以 8 拍为一个循环：连续 4 下重击，再空 4 拍。
