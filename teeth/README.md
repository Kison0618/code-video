# TEETH · 代码音乐视频

给 `teeth.m4a` 做的纯代码视觉：1920×1080、60 帧、3 分 25 秒。

## 一条命令出片

需要 Node.js 18+ 和 ffmpeg。

```bash
cd teeth
node build.js                       # 完整构建，成片在 render/out/
node build.js --from 46 --to 60     # 只渲染第一次副歌前后（带音乐），先看效果
node build.js --version v2          # 新版本号；不会覆盖旧版
cd render && node src/preview.js shot.png 49.17 104.7 148.2   # 把几个时间点拼成预览图
```

有 NVIDIA 显卡时自动用显卡编码。速度和 NEVER 差不多：每帧约 0.1–0.6 秒（单核），8 个进程大约 10 分钟。

## 这首歌的情绪 → 画面

这首歌暗、狠、带攻击性。鼓是"跺脚 + 拍手"式的重击：以 8 拍为一个循环，连续砸 4 下，再空 4 拍，像一口一口咬下去。所以整支片子只有一个母题：**咬**。

- **颜色**：只用黑、骨白、血红三种（主歌里加一点冷钢蓝），和 NEVER 的金色宇宙完全分开。
- **重击 = 咬合**：每一下重击，上下颚猛地咬住；4 下咬完松开，露出后面层层旋转的环形口。
- **每组第一下**：画面负片反色闪一下，同时横向撕裂、RGB 色散、镜头震动，咬合线上炸出血红裂纹和火星。
- **右上角的 BITE 计数器**：记录到目前为止一共咬了多少下。

## 音乐分析（已做好）

`analysis/teeth.json` 由 `analysis/analyze.py` 生成（需要 `pip install librosa`）：

- **速度**：139 BPM，每拍 0.4317 秒，全曲漂移在 ±6 毫秒以内。
- **鼓点**：每一拍的底鼓和拍手强度都是实测值，画面直接读取，不假设固定鼓型。

| 拍号 | 时间 | 音乐 | 画面 |
|---|---|---|---|
| 0–48 | 0.4–21 秒 | 稀疏的跺脚 | 咬紧的嘴：每咬一下多长出一颗牙；TEETH 在第一下砸下 |
| 48–80 | 21–35 秒 | 主歌 | 咬合缝张开成环形的口，三圈牙反向旋转，每下重击向内一缩 |
| 80–112 | 35–48.7 秒 | 预副歌（没有鼓） | 上下颚从屏幕外逼近，血管从边缘爬进来；108 拍急停，只剩轮廓，红光涌起 |
| 112–176 | 48.7–76 秒 | 副歌 1 | 咬：上下颚每拍咬合，负片闪、撕裂、裂纹、火星，TEETH 被咬在中间 |
| 176–184 | 76–79.8 秒 | 断开 | 嘴张大退出画面，一道大裂纹横穿，低频的红光涌起 |
| 184–240 | 79.8–104 秒 | 主歌 2 + 预副歌 2 | 进入喉咙：一节节牙环朝镜头冲来，远处暗红、近处骨白 |
| 240–304 | 104–131.6 秒 | 副歌 2 | 喉咙隧道加上咬合 |
| 304–368 | 131.6–159 秒 | 桥段 | 冻结的咬合画面上裂开蛛网玻璃，碎片缓缓剥落；两次掐断之后整面玻璃重新炸开，第二次更猛；最后口重新长出来 |
| 368–464 | 159–200.7 秒 | 最后的副歌 | 喉咙、环形口、上下颚、裂纹全部叠加 |
| 464– | 200.7 秒– | 结束 | 最后一口咬死，余光里留下 TEETH |
