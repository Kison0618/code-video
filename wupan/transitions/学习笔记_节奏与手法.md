# 学习笔记：《山河转场》的节奏与手法

读的是 `source/stripped.html`：编排逻辑（第 3452 行起的主脚本）、字幕 CSS（第 145–170 行）、音频引擎（第 2411–3438 行）。原作的"帅"有一半不在 shader 里，在时长、运镜、字幕和声音怎么配。下面先讲原作怎么做，最后是照做的规则。

## 1. 时长和缓动

- **时长按式定，不统一。** 20 式的默认时长从 2.0 秒（甩镜）到 3.6 秒（云海、星河、云影），平均 3.05 秒。规律很清楚：
  - 动作快、一下就完的式短：甩镜 2.0、御风 2.4、涟漪 2.6。
  - 有"过程"的式中等：墨染 3.0、印章 3.0、卷轴 3.2、折扇 3.2。
  - 遮挡式、表现时间流逝的式长：云海 3.6、星河 3.6、云影 3.6。
- **场景停留 6.5 秒**（滑块 3–14 秒），转场速度滑块 0.4×–1.8× 统一缩放所有时长。停留和转场的比例约 2:1，转场占整体时间的三分之一。
- **JS 只给线性 p，缓动全写在 shader 里。** 原因是很多式不是一条曲线，而是分几段：印章 0–0.35 悬着下落、0.35 落印、0.35–0.51 浸开、0.56 起放大；夜雨先起雾、再出水珠、0.45 起水幕往下擦。如果在外面套一层缓动，这些段落的时刻就全乱了。
- **常用的几种曲线：**
  - `mix(p, ease(p), k)`：线性和三次缓动按比例混合，k 取 0.2–0.6。完全的 ease 会显得"停顿"，掺一半线性更连贯。卷轴 0.4、层峦 0.2、流水 0.25。
  - `smoothstep(a, b, p)` 截取一段：某个动作只在 p 的一个区间里发生，前后都是静止的。
  - 指数缩放 `exp(log(S) * e)`：漏窗推镜 24 倍、折扇放大 5.6 倍、印章放大 7.5 倍。这样每帧的放大比例相同，眼睛感觉是匀速推进；线性缩放会让后段显得突然加速。
  - 三角包络 `1 - |2p - 1|`：云海这类遮挡式，p=0.5 遮得最满，换景就藏在那里。
  - tanh S 曲线：甩镜的机位，中间最快、两头速度为零。
- **端点都钉死。** 每式都保证 p=0 精确等于旧图、p=1 精确等于新图，所以转场和停留段可以无缝接在一起。

## 2. 运镜：转场前后都在动

- **每个场景都有 Ken Burns。** 场景数据里写了 `kb`（in 推、out 拉、left/right 横移）和 `focus`（焦点坐标）。缩放幅度很小：推是 1.02→1.17，拉是 1.17→1.02，横移固定 1.12 倍、平移 0.9 个余量。
- **慢推是指数趋近的：** `k = 1 - exp(-age / 9)`，age 是这个场景入场后的秒数。一开始动得最明显，之后越来越慢，不会在停留末尾突然停住。
- **转场期间运镜不停。** 转场时旧场景继续按它的 age 推，新场景从 age=0 开始推。所以转场两侧画面都在动，不是"两张静止图做溶解"，这是原作看起来"活"的主要原因。
- **视频场景只推 4%。** 有视频的场景本身在动，只叠一个很慢的 4% 推镜，避免两种运动打架。
- **运镜不进 shader。** 原作把 Ken Burns 写成每帧的 `uFromXf/uToXf`（`texUV = uv * xf.xy + xf.zw`），转场 shader 完全不知道镜头在动。我们在 skia-canvas 里也照这个做：先把每个场景按当前时刻的推拉画好，再把两张图交给转场。

## 3. 前后两张图怎么挑

原作的"策展"表 `curated` 给 11 对相邻场景各配了两式（第一轮、第二轮），看得出挑选依据：

| 衔接 | 配的式 | 为什么 |
|---|---|---|
| 黄山 → 漓江 | 层峦 / 飞白 | 都是山水，用"山"接"山" |
| 漓江 → 壶口 | 甩镜 / 御风 | 从静水到瀑布，节奏突然加快 |
| 壶口 → 三峡 | 流水 / 移焦 | 黄河接长江，用"水"接"水" |
| 三峡 → 西湖 | 空蒙 / 漏窗 | 从峡谷进入江南，雾气和园林 |
| 西湖 → 泰山 | 折扇 / 夜雨 | 西湖的文人气用折扇收 |
| 泰山 → 天山 | 云海 / 金辉 | 都是高山，云海遮挡换景 |
| 天山 → 巴丹吉林 | 风沙 / 云影 | 从雪山到沙漠 |
| 巴丹吉林 → 九寨沟 | 星河 / 涟漪 | 沙漠夜空接湖水 |
| 九寨沟 → 张家界 | 卷轴 / 墨染 | 山水画式的切换 |
| 张家界 → 珠峰 | 飞雪 / 云海 | 越来越高、越来越冷 |
| 珠峰 → 黄山（循环） | 印章 / 层峦 | 一轮结束，落款 |

- **转场的"材质"取自两幅画面的共同点**（山、水、雾、雪），用来做两个画面之间的桥。没有共同点时（漓江 → 壶口），就用和内容无关、只讲节奏的电影式（甩镜、御风）。
- **开场和结尾是固定的：** 从纸色进入第一幅画用墨染，一轮结束用印章。墨染从"纸上落墨"开始，印章是"落款"，两式首尾呼应。
- **明暗和色调靠 shader 自己衔接**，不靠挑图：云海从画面顶部取天空色给云着色；空蒙的雾色取两张图的平均色；星河在全黑时换景，两张图的亮度差被藏掉。所以策展只需要考虑题材，不太用考虑两张图的明暗是否接得上。
- **主体位置：** 墨染的墨滴落点、涟漪的落水点、御风的消失点都由 seed 决定，在画面中间 60–70% 的范围内随机。原作没有对准主体，我们用的时候可以把 seed 固定成落点靠近主体的那个值。

## 4. 标题和文字怎么出场

- **字幕在转场正中间换。** p 过 0.5 时调 `captionIn(next)`，也就是新画面露出一半时，新字幕才开始出现。旧字幕在转场一开始就 `captionOut()`：0.55 秒内模糊并淡出。所以转场期间画面上几乎没有字，字不会和转场的运动抢视线。
- **逐字"墨入纸"：** 每个字从 `blur(10px)`、上移 0.18em、放大到 1.06 开始，0.9 秒落定（`cubic-bezier(.2,.7,.2,1)`，先快后慢），字与字之间错开 70 ms。地名先出，诗句接着出，作者署名最后。
- **印章最后一下：** 小朱印在所有字出完后（延迟 `0.45 + 字数 × 0.07` 秒）用回弹曲线 `cubic-bezier(.3,1.6,.5,1)` 从 1.5 倍缩回原大，带 -6° 旋转。和大印章转场一样是"落款"的意思。
- **英文、坐标、海拔这些说明文字**比主字幕晚 0.5 秒出现，每行再错开 90 ms，从下方 8 px 处升上来。
- **转场名牌：** 转场开始时在顶部中间显示"转场 · 墨染 · Ink Bleed · 一句描述"，转场结束 0.9 秒后才淡出。这是给演示用的，正片里一般不需要。

## 5. 声音：环境音 + 转场音效

全部是 Web Audio 实时合成，没有一个音频文件。

- **总线：** 总增益（-6 dB）→ 30 Hz 高通 → 胶水压缩（-22 dB 阈值，2:1）→ 限制器（-6 dB，20:1）→ -2 dB 微调。另有一条 5 秒的合成混响（衰减噪声，越往后越暗）。三条子总线：环境音 bed、音效 fx、古琴 music。
- **每个场景一层环境音（bed）：** 2–3 层滤波噪声（白/粉/棕噪声 + 带通或低通），每层都有随机慢变的滤波漂移和"阵风"增益调制；有的场景再加持续低音、偶发事件（鸟叫、驼铃、水滴、远处琴声），三峡还有回声延迟。换场景时两层环境音用 3 秒的等功率曲线交叉淡化。
- **古琴旋律：** Karplus-Strong 拨弦合成，带绰、注、吟、上下这些指法的音高曲线，偶尔弹泛音或八度撮。每个场景有自己的调式（宫商角徵羽）和音区，旋律是稀疏的短句，句间停 3–12 秒。
- **转场音效（我们要用的部分）：** 每式一个配方，由几个基本零件组合，时长跟着转场时长缩放：
  - `shot`：带频率走向的滤波噪声，配包络曲线和声像移动。这是 whoosh 的基础。
  - `swish`：带通的 shot，可以加一层纸张颗粒（crackle）。
  - `rustle`：纸张沙沙声（颗粒噪声，包络不规则地颤动）。
  - `knock`：木头敲击（4 个模态正弦叠加）。
  - `tone` / `bell` / `chime`：正弦音、钟（非谐波泛音）、按当前场景调式取音的风铃。
  - `drop`：水滴（上滑的短正弦）。`creakBuf`：木头吱呀（粘滑脉冲激励共鸣）。
- **配方都和画面同步：** 墨染是一下轻敲 + 笔刷 swish + 纸沙沙；卷轴开头两下木轴敲击、结尾一下；折扇按扇骨数敲 11–15 下，敲击时刻和扇骨展开的时刻一致，音高随扇面从左到右升高；印章在 0.35 × 时长处（落印那一帧）打一记 110→46 Hz 的下滑低音加棕噪声冲击。**音效的重拍对准画面的重拍**，这是原作声音"贴"的原因。
- **抽出来的版本：** `lib/audio/shanhe-audio.js` 是原引擎原样抽出，加了撕纸、描线、排线、翻页四式的配方，以及 `renderTransition(id, { dur, seed })`：用固定种子替换 `Math.random`，离线渲染出一段转场音效。`lib/audio/render_wav.js` 在 Node 里批量导出 WAV；`lib/audio/shanhe_sfx.py` 把它接进 ep01 的 `audio/sfx.py`（events.json 里写 `{"k": "shanhe", "id": "moran", "d": 3.0}`）。固定 seed 保持音效随机结构；本轮跨浏览器会话复测，16 位 PCM 最大差 1 个量化单位，峰值相同，不把 WAV 逐字节一致作为跨会话保证。

## 6. 可以照做的规则

1. **时长：快切 1.6–2.2 秒，有过程的 2.6–3.0 秒，遮挡式和时间跳跃 3.2–3.6 秒。** 在配音视频里比原作再短 10–20%（我们的试用片：翻页 1.6、撕纸 1.8、排线和飞白 2.2、墨染 2.6、印章 3.0），因为旁白在推节奏，转场不能拖。
2. **停留和转场约 2:1 到 1:1。** 原作 6.5 秒停留配 3 秒转场。配音视频里一个镜头至少停 1.4 秒，观众才看得清画面再进入下一次转场。
3. **缓动写在 shader 里，外面只给线性 p。** 在 GSAP 或 HyperFrames 里用 `ease: 'none'`；在 skia-canvas 里用 `p = (t - t0) / dur`。不要在外面再套 ease。
4. **转场期间两边都继续运镜。** 每个镜头入场就开始慢推 2–6%（`k = 1 - exp(-age / 6)`），转场时旧镜头不要定住，新镜头从入场那一刻开始推。先在 2D 里按当前时刻画好两个画面，再交给转场。
5. **字幕在 p=0.5 换。** 旧字幕在转场开始时 0.5 秒内淡出，新字幕在转场过半时开始逐字出现。转场中间不要放字。
6. **转场的材质从两个画面的共同点里挑。** 都是纸和便签：翻页、撕纸；都是版画人物：排线、墨染；推翻上一个结论：撕纸、风沙；下结论、章节收尾：印章；没有共同点、只是换个地方：甩镜。
7. **在我们的米黄纸 + 铜版画风格里，优先用"纸张版画"和"水墨"两族**（排线、翻页、撕纸、描线、墨染、飞白、印章、卷轴），慎用会盖住整片纸面或把纸染冷的式（云海、飞雪、夜雨、星河、流水、御风、漏窗、层峦）。具体评级见 `shots/_我们的画风_适配.png`。
8. **一支片里同一式最多用两次，开头和结尾固定。** 原作开场用墨染、一轮收尾用印章，首尾呼应；中间按策展表不重复。我们的系列可以固定"开场排线、收尾印章"。
9. **每次转场都配音效，重拍对准画面的重拍。** 印章落印、翻页落下、撕纸撕开那一帧要有一下实的声音（敲击、低音冲击）；其余部分用 whoosh 和纸面沙沙填。音效峰值比旁白低 4–8 dB，正片里在 ep01 的混音里再整体 -5 dB。
10. **seed 每个切换点固定一个值。** 原作用随机 seed，每次播放都不一样；视频要能重渲，所以每个切换点写死 seed。墨滴、裂口、光的方向如果压到了主体，换一个 seed 试，不用改 shader。
