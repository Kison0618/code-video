## 重建（云端）
```bash
cd ep03/render
npm install                     # skia-canvas
npm install --no-save playwright-core@1.63.0   # GL 转场桥要用，版本对齐预装的 Chromium
export FONT_DIR=<字体目录> SHANHE_LIB=<仓库>/wupan/transitions/lib SHANHE_CHROME=<chromium 路径> NODE_PATH=$PWD/node_modules
node src/contact3.js mid        # → out/_ep03_拼图.jpg
node src/contact3.js open       # → out/_ep03_开头.png
NO_GL=1 node src/contact3.js mid 015-022 out/x.jpg   # 不开 GL、只看某几句（GL 转场退成淡入）
node src/preview.js out/x.png 110 115                 # 任意时刻
```
本地 Windows 上 `FONT_DIR`、`SHANHE_*` 不设就沿用原来的默认路径。`build.js` 和 ep02 一样，混音脚本名和输出文件名还写着第二集（`mix_v7.py` / `第二集_v7.mp4`），本地出成片前需要改成第三集的。

## 和分镜不一样的地方
- **010–014 答案牌**：E14–E16 和 E03 是坐着、手放膝上的人，答案牌（A / B）用纸片浮在头顶。这样每张牌都能单独弹起、翻面，比让 AI 画“举着空白牌”再往牌上贴字可控。
- **013**：分镜原来写的是“答错的人”纸条矮下去一截，做出来像一块没意义的牛皮纸，删掉了。改成：第三个人先亮出 B，“少了一大截”时“你”的牌也从 A 翻回 B，再配纸签「跟着答错的少了一大截」。画面里没有比例数字，因为文案没给。
- **019 没画中国地图**，用“一墙空货架”（4×3）表示全国。AI 画的中国地图很难保证边界和岛屿完整准确，在国内平台发布有风险。如果一定要地图，需要用标准地图服务的底图。
- **020**：标题已经是“辟谣”，所以印章改成「不缺」，落在第二行“盐也根本不缺”旁边。
- **032**：人流用一张 E31 慢慢平移（画面往右移，人群往右挤）。原来叠在前景、滑动的路人去掉了，看起来像雕像在平移。
- **GL 转场**：5 处（005 墨染、010 排线、016 撕纸、023 翻页、028 飞白）都改成上一句一说完就开始，1.4 秒走完（frame.js 按库里的原时长换算进度）。这样开口 0.3 秒时新画面已经过半。另外，第二集 index.js 里 moran 写的是 2.4 秒，库里是 2.6 秒，所以第二集的墨染其实没走完（停在 92%）。这一集已经换算好了，第二集没改。

## 没把握的地方
1. **画风年代**：AI 带 G/H 系列参考图时，场景图（E13 人群、E24 药店、E30 读书会、E31 人流）都偏向 20 世纪初的西方人物和街景，和“2020 年深夜药店”“国内家长群”的时代感有出入。人物单图（“你”、路人、老两口、老同事）都是东亚面孔。如果要统一成当代国内场景，需要换参考图重生成这几张。
2. **E11 车库剖面**：上面那层是一家玻璃门面的商铺，不像包子铺，所以在店门上贴了「包子铺」纸签。包子的路线按实图量过：店门 → 沿街往左 → 坡道下车库 → 穿过车库 → 右边楼梯上来 → 回店门。
3. **E25 会议室**：画面里白板上的柱状图和饼图是 AI 画的装饰，没有字。“没问题？”印章盖在桌面右下。
4. **009 前半句**：只有“你”一个人和「两种时候最强」纸签，画面偏空。“拿不准”“有压力”两张大签到句末才出来，因为要跟配音卡点。
5. **005 章节卡**：卡片里有一张「No.4」小签，左上角 HUD 同时也亮 No.4，会重复一下。
6. **逐字时间**：时间轴是 exact 对齐，词和画面基本同步，但没有在成片上逐帧核对声音。
7. **字体**：云端没有思源黑体以外的本机字体。楷体换成了霞鹜文楷，Num 换成了 Oswald。本地渲染会用回原字体，数字和“2011 · 3 月”的观感会略有不同。
8. **720p 预览片**：没出。云端每帧都可以渲染，但这一轮先把两张拼图做到位。需要的话可以按 `build.js --from/--to` 出片段。
