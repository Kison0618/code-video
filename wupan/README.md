## 已被否定（2026-10-21）
- 海报 / PPT 式排版（大标题、分栏正文、信息排版）：不是视频画面
- 同一个模型只换材质、光照、后期：看起来就是在换颜色，不算不同风格

- 抖动像素、ASCII、蓝晒：被评“垃圾”；流场、等高线：看不懂
- 太空、太简略的画面（第二版 1/2/9 已重新设计，不是堆元素）
- 用户认可的方向：具体日常物件 + 质感（霓虹、手机界面、实拍加手绘、剪纸）

- 用户澄清（10-22）：“风格”是整片的画面语言；视线追踪、放大镜、仪表、游戏 UI、小票这类是“效果”，可插进任何风格。风格板已分两栏
- 同一个情景（大衣 / 价签 / 橱窗）反复用会让人没法判断风格，每张要换不同情景
- 游戏状态栏（debuff/属性条）效果：用户不要
