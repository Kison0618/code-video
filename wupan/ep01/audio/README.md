# 第一集 音频（D 线：配乐 + 音效 + 混音）

管线照搬 theory（`theory/audio/bgm_prep.py`、`sfx_music.py`、`build.js` 第 37–60 行的混音参数）。所有时间都从 `render/src/timeline.js` 取，不写死秒数；`render/` 下的文件一个都没改。

## 结构

| 文件 | 作用 |
|---|---|
| `cues.js` | 音效事件表 + BGM 压低区间 → `events.json`。前 1 分钟的动作时间照 `s1_head.js` / `nest_cast.js` / `s3_card.js` 的公式抄过来（只读，不 require 场景）；014 以后按配音关键词挂。关键词找不到会直接报错，不会悄悄退回句首 |
| `events.json` | `marks`（DUR、两张章节卡、BGM 对齐点 drop、系列名 series、每句起止）、`duck`（5 段说话块）、`ev`（90 个音效） |
| `bgm.m4a` | 《代码小区》，复制自 `theory/assets/bgm.m4a`（130 秒，73.8 BPM） |
| `bgm_prep.py` | 对齐 + 循环 → `bgm_long.wav`（48 kHz 立体声，未调音量），参数写进 `bgm_info.json` |
| `sfx.py` | 代码合成全部音效 → `sfx.wav`。乐器和基础函数（ping/bell/metal/thump/whoosh/tick/shimmer/pluck/glide/reverb）整段沿用 theory，另加了纸张世界用的 slide/scrape/wood/softpluck/stroke 等 |
| `mix.js` | 混音并套到视频画面上（`-c:v copy`） |
| `measure.py` | ebur128 测量：整体 I / LRA / 真峰值，说话段与间隙段的瞬时响度均值 |
| `_demo_前1分钟_混音.mp4` | 试听版（`render/out/前1分钟_v2.mp4` 的画面 + 本混音，56.50 秒） |

## 重建命令（在 `ep01/` 下执行）

```powershell
$PY = "F:\AI\For AI to use\codex2\AI-Coding-SuperVideos\.venv\Scripts\python.exe"
node audio/cues.js                      # → audio/events.json
& $PY audio/bgm_prep.py                 # → audio/bgm_long.wav + bgm_info.json
& $PY audio/sfx.py                      # → audio/sfx.wav
node audio/mix.js render/out/前1分钟_v2.mp4 audio/_demo_前1分钟_混音.mp4 --to 56.5
node audio/mix.js <全片画面.mp4> <输出.mp4>          # 整集（Claude 用）
node audio/mix.js - audio/_mix.wav                   # 只出混音 wav（不要画面）
& $PY audio/measure.py audio/_mix.wav                # 测电平
```

`MIX_SOLO=vo|bg|fx` 环境变量可以只留一路，用来分别测量。换配音或画面改了时间，从 `cues.js` 起重跑一遍即可。

## BGM

- 对齐点：曲子 17.08 秒那记鼓点 → 片中 1.957 秒（`TL.at('001','底层代码')`，芯片亮起）。曲子从 15.12 秒处开始放，开头 0.3 秒淡入。
- 循环：曲子 119.80 秒跳回 43.68 秒（间隔和 theory 一样是 76.12 秒，1 秒等功率交叉淡化）。theory 原跳点 120.12→44.00 第一次会落在片中 105.0 秒，正好在 022b 说话中间。所以在 118.6–121.0 秒之间整体平移、间隔不变，挑交叉淡化里说话最少的一个，这一段曲子自相似度都在 0.95 左右。
  - 第 1 次跳：片中 104.68 秒（022 和 022b 之间的停顿）
  - 第 2 次跳：片中 180.80 秒（033 和 034 之间的停顿）
  - 两次交叉淡化里一共只压到 0.30 秒说话（淡化窗边缘）
- 全程不断乐。
- 音量（`mix.js`，沿用 theory）：说话时 -13.5 dB，段落之间和片头片尾 -9.5 dB。说话段是把句间停顿 < 1.0 秒的句子并成的 5 块（001–012 / 014–019 / 020–024 / 026–033 / 034–036），所以只在 No.1 卡、019→020、No.2 卡、033→034 四个空档抬起来，句内和普通句间不动，不用 sidechain。包络缓变 0.8 秒；间隙只有 1 秒左右，放不下 0.6 + 0.8 秒的斜坡，就按间隙比例缩短（0.46–0.6 秒），保证中间能抬满。
- 片尾：036 说完离片尾只剩 0.37 秒，来不及抬。所以最后一块压低在系列名出现（`TL.at('036','快来学习吧')` = 202.37 秒）时就开始 0.8 秒抬起，和最后 2.5 秒的余弦淡出叠在一起。淡出只作用于 BGM 和音效，不碰人声。

## 混音链（`mix.js`）

- 人声：`voice/v3/第一集旁白_v3_A4B1C1D4.mp3` → 高通 70 Hz → acompressor（-22 dB，2.5:1，attack 8，release 160，makeup 2）→ loudnorm I=-16 TP=-2 LRA=7
- BGM：`bgm_long.wav` × 上面的压低包络 × 片尾淡出
- 音效：`sfx.wav` -5 dB × 片尾淡出（`sfx.py` 里已带 1.6 秒、18% 湿的小房间混响）
- 总线：amix（不归一化）→ +2 dB → alimiter limit 0.89
- 视频：只取输入的画面流，`-c:v copy`；音频 AAC 320k。`--to N` 只出前 N 秒，结尾 0.5 秒声音淡出。最后会做一次解码自检。
