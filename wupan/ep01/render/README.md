## 结构
管线照搬 `theory/`：skia-canvas 逐帧绘制，Node 多进程分块渲染，再拼接、合成声音。

| 文件 | 作用 |

## 重建
```bash
cd ep01/render
npm install                                   # 只依赖 skia-canvas
node build.js --from 0 --to 5                 # 先跑短片段验证管线 → .render-tmp/clip_0-5.mp4
node build.js                                 # 整段 → out/前1分钟_v1.mp4（同名已存在会停下，加 --version v2）
node build.js --jobs 6                        # 并行进程数，默认 7
node src/preview.js out/x.png 1.36 18.56 34.7 51.87   # 抽帧拼图（带时间码）
```
整段渲染约 70 秒（7 进程）。所有 ffmpeg 调用都用 `F:\AI\For AI to use\codex2\AI-Coding-SuperVideos\.venv\Scripts\ffmpeg.exe`（定义在 `src/core.js`），不走 PATH。

## 修改 1 做了什么
1. 渲染失败（`write EOF`）：ffmpeg 改用绝对路径；并行数从 14 降到 7；每个进程的 ffmpeg stdin 都监听 error，出错时打印 ffmpeg 的 stderr；加了 `--from/--to`，先用 0–5 秒短片段验证通过，再跑整段。整段解码 0 错误。
2. 左上角标签：放大到 44px，用浅色纸片底和深色字；No.1 红签跟在后面。preview 的时间码移到每格右下角，不进成片。
3. 011：迷你代码卡从 9 张减到 5 张，每个蚁室一张，浮在蚂蚁头顶上方 150px，互不重叠。每张只写一次「IF 气味 → 抬出」。
4. 012：去掉对折（中间会出现竖长条）。改成蚁巢整体缩成右上角带白边的小卡片，再淡出，露出人头。
5. 人脑代码卡：每行开始打字时，行首 `IF` 立即出现，后面的字逐个打出。「BUG × 25」改成红笔手写批注，不再排成代码行。

## 没做到 / 待确认
- 逐字时间是按句内字数估算的（`lines_timed.json` 只有句级时间），词和画面可能差 0.1–0.3 秒。如果需要更准，要补逐字时间戳。
- 012 的红字「BUG × 25」画成了批注而不是 `IF …` 代码行，因为分镜要求的是“多出一行红字”，而修改单要求每个代码行都带 IF。如果想要代码行的样子，需要定一句带 IF 的文案。
- 012 缩小的蚁巢卡片淡出时，会短暂压住人脑代码卡的右上角（约 0.4 秒）。
- 文件约 400 MB（约 59 Mbps）。码率高主要是因为全屏每帧都换胶片颗粒，CRF 16 保留了这些颗粒。如果要小一点，可以减弱颗粒或调高 CRF。
- 本段没有 BGM 和音效（按任务单，后面统一做）。
