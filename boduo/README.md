# 被剥夺超级反应 · 墙上的影子

**120 秒**，30fps，横屏 1920×1080 和竖屏 1080×1920 两版（`demo.html?ar=9x16` 是竖屏：同一条时间线，镜头和版式重新排过，不是裁的）。

内容来自芒格《人类误判心理学》第 14 条 Deprival-Superreaction Tendency（被剥夺超级反应倾向），损失厌恶的数据来自卡尼曼和特沃斯基。逐句文案和来源见 `文案.md`。

**配乐和音效不在工程里**，由你在本地挑选、合成。下面的“卡点”表是画面上的大节点。

## 世界：一盏光，一个人，一面墙

全片只有一个世界，也只用一个比喻（参考了木鱼《37% 法则》的做法，见 `../参考拆解/`）：

- 你站在墙前，手心里捧着一团光，光把你的影子投在身后的墙上。
- **影子就是“超级反应”。** 光离身体越近，影子越大：
  - 攥紧的时候，影子大到压满整面墙；
  - 有人来拿的时候，影子变红。
- 结尾松开手，光飘上去散成星星，房间亮起来，你身后的影子变回和你一样大。最后一句字幕“松开手，影子才会变回你的大小”，说的就是画面里正在发生的事。
- 狗、拍卖会上的人、伸过来的手，都是墙上的影子。数字、进度条、股价线都像投在墙上的光。

## 新加的手段

- **整张画面跟着情绪变色**（`main.js` GRADE）：
  - 失去是冷蓝；差一点也是冷蓝；
  - 被抢、愤怒是暗红；
  - 死守是去色的灰；
  - 得到、松手是暖金。
- **毛笔字卡加红印章**（`world.js` callig，字体马善政 Ma Shan Zheng）：
  - 片名“被剥夺超级反应”盖“芒格”；
  - “不甘”盖“失”，“舍不得”盖“攥”，还有一个“抢”。
  - 字是描边发光的，一个字一个字从上往下写出来。
- **会跑的数字**：
  - ×1.0 → ×2.0；
  - 86% → 99.9% → 99.997%，一直到不了 100%；
  - ¥100 → ¥400；
  - −0% → −50%；
  - 一千万被近处的 −100 压下去，再恢复原来的比例。
  - 数字下面配“英文小字 · 中文”的副标。
- **心跳**：死守和崩溃的几段，画面每 0.8 秒暗一下、往里推一点。

## 渲染

```bash
npm install
node render-local.cjs                  # 横屏，逐帧 jpg 到 .render-tmp/frames（0–120 秒 @30fps）
AR=9x16 node render-local.cjs          # 竖屏，到 .render-tmp/frames-9x16（也可以 node render-local-9x16.cjs）
node render.js out 12.5,30,65          # 只出几张静帧
```

- 预览：`demo.html?play`（竖屏 `demo.html?play&ar=9x16`）。没有配乐，按时钟播放；空格暂停，← → 前后 5 秒。
- Chrome 路径用 `CHROME_PATH` 指定。
- 关键帧：`关键帧/`，横竖各 40 张（每 3 秒一张），加两张联系表。

## 文件

- `world.js`：墙上的光、影子、狗、手、观众、墙上的数字和图、毛笔字卡。
- `main.js`：字幕、大字、镜头、情绪调色、每一帧的渲染。
- `core.js`、`fx.js`、`post.js`、`props.js`：从《懂事》的“灯下光尘”引擎复制过来，没改。
