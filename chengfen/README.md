# 查成分 · 性格成分鉴定

一个娱乐向的 VIA 风格性格优势测试站。纯静态，没有构建步骤，没有后端，答案只在浏览器本地算。

## 预览

```bash
python3 -m http.server 5178 --directory chengfen
```

打开 http://localhost:5178 。部署时把 `chengfen/` 整个目录丢到任何静态托管即可。

## 它怎么玩

- 三种规格：试吃装 48 题、标准装 96 题、量贩装 213 题（IPIP-VIA 全量）。
- 结果是一张“成分表”：称号 =「最少那项的修饰语」+「最多那项的称号」，如“三分钟热度的十万个为什么”，共 24×23 = 552 种。
- 报告分九块：称号与结论、配料表、被看穿的小事（可勾选，统计说中几条）、主要成分 TOP5、几乎不含 5 项、隐藏款（强×弱特定搭配，现有 48 组）、六个方面、标签背面的小字、完整成分表。
- 分享：前端 canvas 画分享图；报告链接自带分数（`#r=…`），别人点开能看到同一份报告。
- 答到一半可退出，进度存在 localStorage。

## 文件

| 文件 | 内容 |
|---|---|
| `js/data.js` | **全部文案**：24 种成分的称号、小事、背面小字、隐藏款。改文案只改这里 |
| `js/items.js` | 213 题（中英、计分方向）。由 `tools/build_items.py` 从 `copywriting/IPIP-VIA_213题.md` 生成，不要手改 |
| `js/app.js` | 出题、计分、报告、分享图 |
| `css/style.css` | 样式 |
| `img/<key>.webp` | 24 张成分图，现为占位，同名替换即可（见 `tools/image_prompts.md`） |
| `fonts/` | 标题字：站酷庆科黄油体子集（OFL）；数字：Barlow Condensed（OFL） |

改了 `data.js` 或页面里的标题文字后，要重跑 `tools/build_font.sh` 重新做字体子集，不然新字会退回系统字体。

## 计分

每题 1–5 分，反向题 `6 − x`；每个分量表取题均分，换算成 0–100% 的“含量”。只在个人内部排序，没有常模，不能跨人比。同分时的先后由结果本身的哈希决定（固定、不偏向某一项）。
称号里的修饰语跳过“灵性”：中文语境里它几乎人人垫底，不跳过的话大家都是“不信邪的”。

48/96 题版的选题是人工挑的（每个分量表前 2 题一正一反），没有做过信效度检验。
