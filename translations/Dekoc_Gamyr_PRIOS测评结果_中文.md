## 你最接近的原型：成长追求者（The Growth Seeker）

成长追求者最鲜明的特点，是对学习、对自我成长与发展怀有深切的热情。他们往往好奇、谦逊，乐于接纳新观念和新体验，适应力强。

典型的成长追求者对个人成长有着无穷的兴趣，愿意把精力投入到不断的改进与蜕变之中。他们对世界、对自己在世界中的位置始终保持好奇，渴望知识，也需要理解这个世界和其中的人，而这一切尤其是为了个人和职业上的成长。凡是能让自己更有成效的事，都会进入他们的待办清单。任何有建设性的意见他们都愿意听，哪怕听起来并不好受。面对新的经历和环境，他们灵活而善于调整。

他们的其他突出特点还包括：在应对压力时沉着、踏实、不偏不倚。他们喜欢接触新的想法和信息，并靠自己把事情想明白。他们常常既坚定又谦逊：喜欢挑战自己，却不会为犯下的错误过分焦虑。事实上他们明白，能够好好反思失败，正是个人成长的关键。

有时，他们习惯先向内反思再行动，这会拖慢反应速度，可能需要更强的推力才能促成行动、做出决断。虽然有些成长追求者是天生的领导者，但也有许多人乐于做一个好的追随者。关键在于了解自己的天性，找到适合自己的路——而凭借内省和适应的能力，这恰恰是成长追求者最出彩的地方。

| 成长追求者的天赋 | 成长追求者需要成长的方面 |
|---|---|
| 对广泛而多样的领域抱有深入的求知欲 | 从反思走向果断的行动 |
| 为自我成长而获取知识、理解与智慧 | 分享知识，承担领导角色 |
| 在压力之下保持冷静、沉着、镇定 | 在不放弃对开放式探索的喜好的同时，追求更明确的路径和目标 |
| 独立达成目标，动力来自内心 | |
| 随环境变化而调整自己 | |

## 你还兼具以下两种原型的特质

**教练（The Coach）**
教练把自我成长、发展与学习视为人生和日常实践的基石，并以身作则，把这些当作值得追求的目标教给他人。他们往往既严格又关怀，既谦逊又坚韧。

**战略家（The Strategist）**
战略家擅长提出概念和想法，并把它们转化为能达成结果的有效策略。他们的思维往往既重概念又有条理，好奇而开放，同时又可靠、务实。

## 与你最不相像的原型

**执行者（The Enforcer）**
执行者倾向于依靠标准、规则和传统来与世界打交道。他们往往直接坦率、传统可靠，对自己和他人都有很高的要求。

**技术专家（The Technician）**
技术专家倾向于用有条理、讲实际的方式去拆解、分析和解决问题。他们往往精确、高效、系统而务实。

## 你在不同情境下的表现

看完上面的详细结果之后，“情境中的你”这一部分会告诉你：你的各项特质组合在一起，在各种工作和生活情境里可能会如何体现。

### 与他人相处时，你……

- 更愿意把时间花在一小圈亲近的人身上
- 往往偏严肃，而不是幽默轻松
- 以共情和体恤为先，但必要时也能给出直接的反馈
- 有时可能难以对那些你觉得应当忠于的人严格问责

### 作为领导者，你……

- 也许不是第一个站出来主事的人，但在需要你的时候会挺身而出
- 会根据你对情势的判断，在直截了当和讲究策略之间切换
- 不介意沿用现成的标准和流程，但在需要时也愿意寻找新的做法
- 更喜欢按自己的路子走，不需要别人给太多指示
- 可能更愿意表现出自信和笃定，而不是公开承认弱点和不确定
- 以更含蓄的方式影响他人，在别人询问时才给出方向
- 在必要时会坚持自己的主张，尽管这对你来说并不总是自然而然的事

### 做计划时，你……

- 会预见变化并为之做好准备，制定周全的应变预案
- 认为变化最好被看作建立更多条理和清晰度的机会，而不是需要回避的问题
- 朝着清晰、具体的目标全力推进
- 喜欢准确弄清实现目标需要什么
- 在有一份结构完整、内容充实、可以对照检查进度的计划时，状态最好
- 认真对照目标跟踪进度
- 尽力提前完成任务
- 把宏观的战略转化为详细的计划

### 解决问题时，你……

- 必要时会寻找新的解决办法，但在传统做法行得通时，不必“重新发明轮子”
- 对别人批评你的想法可能比较敏感
- 在没有太多指示或引导的情况下，也能自如地找到解决办法
- 能很快给模糊的想法加上条理，使之变得精确
- 在直觉式思维和分析式思维之间没有明显偏向，两者比较均衡

### 设定目标时，你……

- 会定下有野心的目标，并一路推进到完成
- 一般更愿意追求自己的目标，而不是跟随别人的目标
- 既目标明确，又保持灵活
- 面对阻力和障碍时，靠调整、随机应变来克服

### 在团队中，你……

- 在把想法彻底想清楚之前，可能不太愿意说出来
- 会私下、带着同理心去和别人处理问题
- 往往是个很好的倾听者
- 喜欢独立完成任务，不需要太多的互动或指示
- 会被有挑战性的目标激励；当期望没有达成时，能在委婉和直接两种方式之间取得平衡
- 认为实现高难度目标的最好办法，是彼此支持、互相帮助

### 在压力之下，你……

- 保持冷静、沉着，专注于最要紧的事
- 会去适应新的经历，而不是回避它们
- 如果能更主动地向他人寻求建议，而不是独自硬扛，会从中受益
- 自信地认为，不需要别人太多支持，自己也能处理好压力
- 无论给自己定的目标有多高，往往都保持自信和韧性
- 不轻易把情绪表露出来

### 学习时，你……

- 偏好安排有序的课程，并按清晰的进度表来学
- 认真对待自己的期限和承诺
- 习惯在自己脑子里把问题想通，而不是主动去了解别人的看法
- 喜欢抽象的、带哲学意味的科目
- 喜欢在安静、能专注的环境里学习
- 喜欢通过看、读、写来学习
- 有良好的耐力和持久力
