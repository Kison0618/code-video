# NEVER · 代码音乐视频

给 `Never.m4a` 做的纯代码视觉：1920×1080、60 帧、4 分 07 秒。画面的每一次冲击、闪白、换图案，都由这首歌的节拍网格和频段能量驱动。

## 一条命令出片

需要 Node.js 18+ 和 ffmpeg（Windows：`winget install Gyan.FFmpeg`）。

```bash
cd never
node build.js
```

脚本会自动安装依赖。有 NVIDIA 显卡时自动用显卡编码，然后多进程渲染画面，最后合成原曲。成片在 `never/render/out/`：
- `Never_v1_1080p60.mp4`：完整画质
- `Never_v1_分享版.mp4`：体积小，方便发送

速度参考：每帧约 0.15–0.4 秒（单核），8 个进程大约 10 分钟。

```bash
node build.js --from 88 --to 100    # 只渲染第一次 drop 前后（带音乐），先看效果
node build.js --version v2          # 新版本号；同名成片已存在时会停下，不覆盖
cd render && node src/preview.js shot.png 0.8 91.75 183.2   # 把几个时间点拼成预览图（不需要 ffmpeg）
```

## 音乐分析（已做好，不用重跑）

`analysis/never.json` 由 `analysis/analyze.py` 生成（需要 `pip install librosa`）。

- **速度**：精确的 126.000 BPM，每拍 0.47619 秒，第一拍在 0.2875 秒，全曲没有漂移。
- **重拍**：第 0、4、8……拍。
- **画面对拍**：底鼓的起音比低频能量峰早约 30 毫秒，所以画面的冲击整体提前 25 毫秒，看和听才是同一下。
- **结构**（小节从 0 开始数，每小节 1.905 秒）：

| 小节 | 时间 | 音乐 | 画面 |
|---|---|---|---|
| 0–16 | 0.3–30.7 秒 | 开场即全能量 | 前 5 拍 N-E-V-E-R 逐字砸下；每小节多一条轨道环，光珠每小节转一圈，每拍一道冲击波 |
| 16–24 | 30.7–46.0 秒 | 安静 | 亮核熄灭，3D 星云浮现，随旋律呼吸，高频起音点亮星点 |
| 24–40 | 46.0–76.5 秒 | 铺垫 | 生命之花每 3 拍画一个圆，后半段每拍连出麦塔特隆立方体的线，频谱环出现 |
| 40–48 | 76.5–91.7 秒 | 蓄力 | 六边形隧道加速；45–47 小节低音抽空时近乎静止；最后一小节闪白从八分音符加速到十六分音符，drop 前一瞬全黑 |
| 48–64 | 91.7–122.2 秒 | 第一次 drop | 闪白 + NEVER 砸下；12 重曼陀罗每小节换图案、每 4 小节换配色并转动画面；激光、粒子爆发、色散、镜头冲击 |
| 64–72 | 122.2–137.4 秒 | 间奏 | 曼陀罗碎成水晶碎片，慢动作漂浮 |
| 72–88 | 137.4–167.9 秒 | 再次铺垫 | 二十面体、十二面体、八面体逐层嵌套，上升光线，频谱环 |
| 88–96 | 167.9–183.1 秒 | 再次蓄力 | 十二边隧道包着多面体，同样的抽空与滚奏 |
| 96–128 | 183.1–244.1 秒 | 最后 32 小节 | 四句：曼陀罗 + 隧道 → 透视光栅地面 → 万花筒 → 全部叠加到最满，最后一小节收缩成一个点 |
| 128– | 244.1 秒– | 结束 | 余光、NEVER |
