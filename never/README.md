# We Never（若如初见）· 代码视频 v2

> **🆕 这是新版（v2，2026-10-07）。** 渲染出的成片文件名是 `WeNever_v2_1080p60.mp4`。
> 旧版 v1（震动、闪白的"节拍器"版本）保留在 git 提交 `555c5c8`，需要时 `git checkout 555c5c8 -- never/` 即可取回。

YAYI、freezepain《We Never（若如初见）》的纯代码视觉：1920×1080、60 帧、4 分 07 秒。

v2 是推倒重来的版本。v1 是一台"节拍器"：一个图形跟着鼓点震、闪白、色散。v2 去掉了所有按拍的震动、闪白和色散，
改成**九个各不相同的 3D 场景**，跟着歌曲的段落换。音乐不再晃画面，而是改变场景里的东西：
光帘上跑过的亮波、浪的高度、烟花绽开的时刻、水母收缩的节奏、时间停住还是加速。

贯穿全片的一条线：**两束光**，一束金色，一束冰蓝色（"we"）。它们在每个场景里以不同的样子出现，慢慢靠近：
街上的两束车灯，窗外的两团光斑，两颗并肩的彗星，两只水母，海上的两盏船灯，最后是两盏并肩升空的天灯。
片尾是"人生若只如初见"。

## 一条命令出片

需要 Node.js 18+ 和 ffmpeg（Windows：`winget install Gyan.FFmpeg`）。

```bash
cd never
node build.js
```

脚本会自动安装依赖。有 NVIDIA 显卡时自动用显卡编码，然后多进程渲染画面，最后合成原曲。成片在 `never/render/out/`：
- `WeNever_v2_1080p60.mp4`：完整画质
- `WeNever_v2_分享版.mp4`：体积小，方便发送

**速度**：v2 的场景重很多，单核每帧 0.2–2 秒（极光、天灯最慢），全片约 4 个 CPU 小时。
12 个进程大约 25–35 分钟。

```bash
node build.js --from 88 --to 100    # 只渲染一段（带音乐），先看效果；这一段是星系 → 极光
node build.js --version v3          # 新版本号；同名成片已存在时会停下，不覆盖
cd render && node src/preview.js shot.png 3 50 100 130   # 把几个时间点拼成预览图（不需要 ffmpeg）
```

## 歌词

画面里可以显示歌词，但需要你提供带时间轴的歌词文件（我不能凭空编写这首歌的歌词）：

1. 在网易云音乐 / QQ 音乐找到这首歌，导出或复制 **LRC 歌词**（每行形如 `[01:23.45]歌词`）。
2. 存成 `never/lyrics/we_never.lrc`（UTF-8 编码）。
3. 重新渲染即可。没有这个文件时画面里不显示歌词，其它一切照常。

歌词逐字（中文）或逐词（英文）浮现，每个场景有自己的位置和光晕颜色。
如果整体偏早或偏晚，改 `render/src/lyrics.js` 里的 `OFFSET`（单位秒，正数 = 推迟）。
可以先用 `node src/preview.js` 抽几帧检查位置。

## 九个场景

小节从 0 开始数，每小节 1.905 秒（126 BPM）。段落交界处两个场景交叉淡化（0.9 秒）。

| 小节 | 时间 | 音乐 | 场景 | 怎么跟着音乐 |
|---|---|---|---|---|
| 0–16 | 0–30.7 秒 | 开场 | **夜城航拍**：484 栋楼、上万扇窗、900 辆车的红白光河，地平线外一直铺到天边的灯海。片名 WE NEVER / 若如初见 | 高频让窗灯闪烁；两束车灯沿两条街驶向同一个路口 |
| 16–24 | 30.7–46.0 秒 | 安静 | **雨夜的窗**：窗外的城市虚成光斑；玻璃上 300 颗水珠，每颗都折射出倒过来的整个窗外，水滴一道道滑落 | 中频让光斑呼吸；两团光斑慢慢挨到一起 |
| 24–40 | 46.0–76.5 秒 | 铺垫 | **奇异吸引子**：1600 个粒子按 Aizawa 方程飞行，拖出发光轨迹，织成一座旋转的光之雕塑 | 粒子随铺垫越来越多；中频控制轨迹亮度 |
| 40–48 | 76.5–91.7 秒 | 蓄力 | **星系诞生**：三万颗星从一团旋转的星尘坍缩成旋涡星系，内圈先成形，旋臂一圈圈长出来；镜头从盘面边缘升到正上方 | 高频起音处旋臂上诞生新星；45–47 小节低音抽空时星系几乎停转；47 小节滚奏时镜头扎向发亮的核心 |
| 48–64 | 91.7–122.2 秒 | 第一次 drop | **极光**：四道光帘在雪山上空舒展、折叠，湖面倒映整片天空 | 每一拍一道亮波沿光帘从中间往两边跑；每两小节的重拍划过一颗流星；后半段两颗彗星并肩飞过 |
| 64–72 | 122.2–137.4 秒 | 间奏 | **深海**：海面的光束斜照下来，海雪飘落，二十只发光水母 | 金色和冰蓝的两只水母每两拍收缩一次（跟着拍子游），从两边游到一起 |
| 72–88 | 137.4–167.9 秒 | 再次铺垫 | **夜海**：几千个顶点组成的海面，四组波叠加起伏，月光在浪尖碎成光点，远处灯塔 | 浪随铺垫一点点变高；灯塔光柱转一圈两小节，正对镜头时落在重拍上；两盏船灯靠近 |
| 88–96 | 167.9–183.1 秒 | 再次蓄力 | **时光隧道**：沿弯曲隧道飞行，墙上几千道流光，每隔一段悬着一圈会转的刻度环 | 93–95 小节低音抽空：速度骤降，流光凝成悬停的光点；95 小节滚奏：再次加速，尽头的光越来越亮 |
| 96–128+ | 183.1 秒–结束 | 最后 32 小节 | **天灯与烟花**：drop 落下时一千九百盏天灯从湖面升起，烟花（有初速度、空气阻力、重力的物理模拟）在湖面上空绽开，湖里是整片天空的倒影 | drop 那一拍绽开一朵巨大的金色烟花；之后烟花开在每个小节的重拍上，最后一句每半小节一朵；第三句镜头抬头看满天的灯；最后金色和冰蓝的两盏灯并肩飞走；片尾"人生若只如初见 / WE NEVER" |

## 代码结构

- `render/src/frame.js`：合成一帧。按段落选场景、交界处交叉淡化，叠片名、歌词、柔和泛光、暗角颗粒
- `render/src/world/*.js`：九个场景，每个文件导出 `draw(ctx, t, section)` 和歌词样式 `lyricStyle`
- `render/src/cam.js`：3D 透视相机
- `render/src/lyrics.js`：读取 LRC 并逐字显示
- `render/src/audio.js`：节拍网格、段落、频段包络（来自 `analysis/never.json`）
- 每一帧只由时间 t 决定（所有随机数都有固定种子），所以多进程分段渲染的结果和逐帧渲染完全一样
