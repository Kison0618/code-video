# 火柴人 VS 光标 —— v6：把光标的创意挖深

> 用户："光标当主角需要你很有创意。"
> 方法（创意库第 1 节）：先列出光标和编辑器"本来就会做的事"，再把每一样直接演成物理行为；观众用过电脑，所以一看就懂，不需要字幕。
> v5（`火柴人VS光标_v5设计.md`）的故事骨架保留（多光标出生 → 偷改字 → 小蛇 → 回忆砌墙 → 条件反射 → 连招 → 和解），这一稿把对手的样子、动作、招式和高潮全部换成更有创意的版本。

## 1. 光标"本来就会做的事"清单 → 画面

### 1.1 样子会变（它的"姿态"）

| 编辑器里的东西 | 在世界里是什么 | 为什么一看就懂 |
|---|---|---|
| 下划线光标 `_` | **躺着 / 趴着的它**：平时、偷偷摸摸时 | 横着的线 = 躺着 |
| 竖线光标 `\|`（I 形，上下有小横） | **站起来的它**：认真了、要打了。`I` 的上下小横就像头和脚，像一个极简的小人 | 横着 → 竖起来 = "站起来了"，任何人都读得懂 |
| 方块光标 `█`（覆盖模式） | **吃饱、变重的它**：Boss | 实心 = 重 |
| 转圈的加载圈 ◌ | **蓄力**：转一圈满了才出大招 | 全世界都知道"转圈 = 等一下，马上来" |
| 鼠标箭头 ↖ | **它的手**：要抓、要拖东西时召唤出来 | 箭头本来就是"指"和"拖"的 |
| 文字选中的蓝底 | **它的瞄准 / 它的网** | 蓝底 = 选中了，下一步就要动它 |
| 拼写检查的红色波浪线 | **它下的诅咒**：被划了波浪线的字会出错 | 红波浪线 = "这里有错" |

→ **它的情绪全靠形态切换**：趴着 `_` 慢闪（观察）→ 竖起来 `|`（认真）→ 加载圈转（蓄力）→ 出招 → 打赢了变回 `_` 打 `hahaha`；害怕时缩成一个点。

### 1.2 它怎么走路（和主角完全不同的运动方式）

- **光标不"走"，它"跳格"**：按方向键时光标是一格一格瞬移的，`Ctrl + →` 一次跳一个词。所以它在世界里是**一下一下瞬移**，每一下"嗒"一声，中间没有过渡（正好就是原片"1 帧到位然后定住"的手绘节奏）。
- `Home` / `End`：一下瞬移到这一行的头 / 尾——它的"闪现"。
- 远处时它连跳（嗒嗒嗒嗒），近处时一格一格（嗒……嗒……），越近越慢 = 逼近的压迫感。

### 1.3 它的招式：一套"选中范围"的升级阶梯（观众一看就知道越来越危险）

| 级 | 操作 | 画面 |
|---|---|---|
| 1 | 选中**一个字** → 退格 | 小蛇少一个字母（`hi` → `h`） |
| 2 | **双击**选中一个词 → 删除 | 小蛇少一整节 |
| 3 | **三击**选中一整行 → 删除 | 他脚下的那一行地面没了（地面就是一行字），他掉下去 |
| 4 | **拖一个蓝色框**（框选）→ 删除 | 一块区域里的东西全没了：墙、字、电脑 |
| 5 | **`Ctrl + A`（全选）** | **整个世界变成蓝色**——一切都被选中了。全片最可怕的一个画面 |
| 6 | `Delete` | 世界只剩一片白 |

点击声就是它的"拳"：嗒（单击）、嗒嗒（双击）、嗒嗒嗒（三击）——声音本身就告诉观众下一下有多大。

### 1.4 其它招式（一个比一个巧）

| 招式 | 画面 | 后果 |
|---|---|---|
| **查找 `Ctrl+F`** | 它搜 `hi`：世界里所有的 `hi` 同时亮成黄色——小蛇的每一节、地上掉的、他代码里的 | "全都被它找到了"：下一步一起删 |
| **查找替换 `Ctrl+H`** | `hi` → `bye`：小蛇的每一节一起变成 `bye`，小蛇自己往外走（"bye bye bye"） | 小蛇被它"改写"走了；他要把小蛇改回来 |
| **替换他的招** | `jump` → `jmup`：他代码里所有的 jump 同时变 | 一次让他所有招失灵 |
| **拖拽（鼠标箭头）** | 箭头出现，按住他的电脑（或者他本人！）拖走，像拖一个文件 | 念力；他被拎着在空中乱蹬 |
| **回车 `Enter`** | 在他脚下那一行字中间按回车——地面一下断成两行，他掉到下一行 | 地面就是文字，换行 = 地面裂开 |
| **`Tab`** | 把他那一行整体往右推一格——他被推出去 | 缩进 = 推人 |
| **大写锁定** | 它打的字突然变成大写、很重：`BOOM` 砸下来 | 大写 = 大声 = 重 |
| **自动补全** | 他打 `ju`，旁边弹出一个它塞的建议框：`junk()`。他手快按了 Tab | 他自己打出一个坑 |
| **滚动** | 它滚动屏幕：整个世界往上滑，他往画面下面掉 | 滚动 = 世界在动 |
| **`Ctrl+/` 注释** | 它把他的代码一行行变灰 | 他的招全被"注释掉"，不能用 |
| **红波浪线** | 它在他的某个字下面画红波浪线——观众知道那个字要出事了 | "悄悄出手"的标记 |

### 1.5 主角学会它的东西，反过来用

| 他学会的 | 怎么用 |
|---|---|
| **抓住一个光标** | 把它塞进自己代码里，被迫跟着他打字——两段跳 |
| **`Ctrl+F` 找到它** | 它藏起来时，他搜 `_`：它所在的地方亮起来，无处可藏 |
| **`Ctrl+Z` 撤销** | 它删掉的东西一个个倒着回来——**这是他最后的大招** |
| **`Ctrl+Y` 重做** | 和撤销来回较劲 |

## 2. 新的高潮：全选 + 删除 vs 撤销

v5 的高潮是方块光标覆盖代码 + `try/except` 盾。v6 改成更有创意、更多人看得懂的一场"按键对决"：

1. 回合 4 末尾，它吞下他的 `def` 连招，竖起来、变成巨大的 `|`，**加载圈转满**。
2. **`Ctrl + A`**——键帽一个个弹出——整个世界被蓝色铺满：地面、代码、他的电脑、小蛇、他自己都在蓝底里。拉到大远景，一片蓝。（全片最安静、最可怕的 2 秒）
3. **`Delete`**——一切消失。纯白。他站在白色里，手里只剩电脑。小蛇不见了。
4. 停 2 秒。他低头看电脑。按下 **`Ctrl + Z`**：
   - 地面回来了（从脚下往两边长回去）；
   - 代码一行行倒着长回来；
   - 小蛇一节节回来，最后抬头看他。
5. 它又按 `Delete`——他马上 `Ctrl + Z`。`Delete` / `Ctrl+Z` / `Delete` / `Ctrl+Z`……**键帽在两人之间来回飞**，越来越快（键帽就是子弹），世界在"有"和"没有"之间一闪一闪。
6. 他用撤销把它自己也一步步"撤回"——撤回到它吃的每一个字之前，它一步步变小，从巨大的 `|` 变回最初那个小小的 `_`。
7. 回忆揭示：它出生的那一刻就是他自己按的 `Alt + 点击`；它一直在学他（他打字它就打字）。
8. 最后他没有按删除：他打了半行 `print(`，停下来等。它补上 `"hi")`。两个光标同步闪。

`try/except` 可以留在回合 3 或 4 当一次性的盾（把它改字造成的 NameError 接住），也可以删掉——高潮已经换成撤销。

## 3. 新的全片骨架（只列主要节点）

| 段落 | 它的级别 / 招 | 他的应对 |
|---|---|---|
| 冷开场 0:00–0:16 | 他手滑 `Alt + 点击` 生出它；它跟着打字：输出翻倍、小蛇一下长四节、他跳两次 | 好玩 |
| 第一幕 0:16–0:40 | 它不跟了、竖起来 `\|`、慢慢"跳格"走向小蛇；单击退格吃一个字母、双击吃一节；`Ctrl+F` 搜 `hi`——小蛇每一节都亮黄 | 抓住小蛇往回拽；按 `Esc` 没用（它打出 `no`） |
| 回合 1 0:40–1:15 | `Ctrl+H` 把小蛇 `hi → bye`，小蛇"bye bye bye"往外走；鼠标箭头把他的电脑拖走 | 追电脑；把 `bye` 改回 `hi`，小蛇回头；小蛇当鞭子 |
| 回合 2 1:15–2:05 | 三击删掉他脚下那一行地面，他掉下去；`Ctrl+V` 一排分身；框选删掉一片 | 抓住一个光标塞进代码（两段跳）；被逼到角落 → 回忆 → `for` 砌墙 |
| 回合 3 2:05–2:50 | 在他的 `dodge` 下面画红波浪线 → 替换成 `doge` | 条件反射（`while True` + `if`）；侧躺闪避；被替换后失灵 |
| 回合 4 2:50–3:30 | 自动补全给他下套；`Ctrl+/` 把他的代码注释成灰色 | `def combo()`：等 2 秒没反应 → `combo()` → `combo(3)` |
| 高潮 3:30–4:20 | 加载圈转满 → `Ctrl+A` 全世界变蓝 → `Delete` 一片白 | `Ctrl+Z` 一样样撤回；键帽对决；把它撤回成最初的小 `_` |
| 和解 4:20–5:00 | 回忆：它出生时一直在学他 | 半行 `print(`，它补上 `"hi")`，同步闪 |

## 4. 为什么这样更好（对照原片规律）

- **它的形态变化就是它的表情**（`_` 趴着 → `|` 站起来 → 加载圈 → `█`），不用加眼睛，和 e^{iπ} 靠"换写法"表演是一个思路。
- **它的预备动作是加载圈**：全世界通用的"等一下"，比"缩小再弹开"更好懂，而且每次都一样（固定词汇）。
- **招式有一条清楚的升级阶梯**（单击 → 双击 → 三击 → 框选 → 全选），观众用过鼠标，自己就能预感下一级。
- **高潮的解法是"撤销"**：所有人都按过 `Ctrl+Z`，看到世界一点点倒着回来，不需要任何解释。
- **能力全片不变**——"它能选中、能删"；变的是范围。和几何集对手"只会吃"一样，观众只需要追踪主角的新招。
