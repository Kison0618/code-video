## 一句话

黄衣剑客对白衣刀客。剑走轻灵、刀如猛虎：对峙一静，第一回合十三拍刀猛剑巧；一记力劈华山硬接，剑被磕飞插在地上，主角空手连躲三刀，倒踢剑柄、空中接剑；反击五拍、连环六拍，最后错身一斩把刀斩成两截——刀头飞上天，过了好几秒才掉下来插在主角脚边，把他吓一跳；主角转身行抱拳礼，跪着的强者点头回礼。

## 先修的：火柴人怎么"拿"剑

以前的兵器是从手里长出来的一根白线，肘永远朝下，剑举过头时手腕折得不像人。这一轮改成真的"握着"一把刀 / 剑（`fight.js` 的"持剑""刀剑的画法"两节，`actor.blade = { kind: 'jian' | 'dao', tassel, zhi }`）：

| 部位 | 现在怎么画 | 为什么 |
|---|---|---|
| 剑柄 | 从拳头后面伸出来 0.06H（刀 0.07H），棕色 | 看得出"握在柄上"，不是捏着剑身 |
| 护手（剑格） | 拳头前 0.03H 一道横的金色短杠 | 手和剑身的分界；踢剑时脚背就挑在这里 |
| 剑身 | 直、双刃、往剑尖收窄，中间一条剑脊 | 剑 |
| 刀身 | 单刃、刀头宽、微弯；**刃朝挥动的方向**（往下劈刃朝下，上撩时翻刃，翻的那 1–2 帧刀变窄，像真的转了刀） | 刀 |
| 拳头 | 握剑的手画成一个实心拳头包住剑柄 | 以前是手指尖接着剑 |
| 肘 | 按剑角自动选往哪边弯：剑举过头 / 剑尖指身后时肘翻上去，3 帧换过去（绕"肩 → 手"的轴转） | 以前肘永远朝下，剑举过头时腕角超过 150° |
| 剑指 | 空着的手食指中指并拢伸直（`zhi: true`），平时举过头顶或指着对方 | 剑法的标志：剑指管平衡、引方向 |
| 剑穗 | 红色，挂在剑首，跟着剑尾甩 | 剑动起来有余韵 |
| 在身后 | 招式写 `behind: [f0, f1]`，这几帧刀画在身体后面（缠头裹脑刀背贴着后背） | 绕身的刀法 |
| 脱手 | `FlyBlade`：被磕飞打转 → 插在地上晃 → 被踢起来 → 空中接住；断掉的刀头飞上天再掉下来插地 | 剧情要用 |
| 断刀 | 断口斜切，拖影只画到断口；判断按半截（0.3H） | 结尾 |

写招式时守的规矩：单手剑前手 `h` 在胯前 0.2–0.38H；剑在头顶横着（云剑、托刀架）用 `wl` 0.35 透视缩短，不然剑会横穿半个画面；剑尖不能插地（除了故意劈地的 `chop_down_b`）；剑碰刀碰在攻方剑的 70–87%、守方剑的 19–44%。

## 武术指导思路

**两个人物**
- **主角（黄）：剑。剑走轻灵**——不跟刀硬拼，用剑法的字化解：刺、点、崩、挂、撩、截、抹、绞、架、云、压、格；身法：闪、跳、矮身穿、铁板桥、后空翻、滚翻、仆步、提膝、腾空。左手始终捏剑指。
- **强者（白）：刀。刀如猛虎**——缠头裹脑、劈、砍、扫、撩、拦、盖，大步、整个身子压上去；刀的力在腰和步子。比主角高一头（330 vs 300）。
- 老话"刀看手、剑看走"：刀看的是那只手有多狠，剑看的是脚下有多灵。所以强者的每一刀都写得很满（举过头、甩到身后、上大步），主角的每一招都很小、很近、先动脚。

**拆招逻辑**：每一拍都是"对方这一刀从哪来 → 用剑法哪个字化解 → 化解完剑停在哪儿，正好是下一招的起点"。例：
- 挂 → 撩：挂剑把劈下来的刀顺着剑身引到下方，剑尖已经在身后下方，正好从下往上撩。
- 截 → 点：截住撩上来的刀、压住，手腕一提就是点腕。
- 刺三下 → 格三下：上中下三刺逼得强者连退，最后一格往下压——刀被压低，顺势提起来就是缠头裹脑反砍。
- 绞 → 剑首撞：绞开以后对方门户大开，但距离太近剑尖用不上，就反过来用剑首撞胸口。
- 压 → 进步刺：压住刀背，剑尖顺着刀背一滑就到咽喉。
- 提膝挂剑 → 落步劈：提起来的腿往前落一大步，就是劈的步子。

**节奏：快慢相间、动静相生**

静（对峙半秒）→ 急（第一回合 4 秒 13 拍）→ 重（力劈华山 + 慢镜头）→ 乱（空手连躲三刀）→ 奇（踢剑接剑 + 慢镜头）→ 急（反击五拍 + 连环六拍）→ 静（错身斩前蓄势 1.5 秒）→ 断（慢镜头 + 白闪）→ 静（背对背 1.7 秒 → 看刀 → 跪）→ 笑点（刀头落下吓一跳）→ 礼。

**武德收尾**：赢了不补刀。主角收剑、转身行**立剑抱拳礼**（握剑的拳头立在胸前、剑竖贴在脸旁，剑指的掌心盖住拳头），强者跪着抬头、点头回礼。

## 镜头

- 全景为主（体检：全景 85%、远景 12%、中近景 4%），两人 + 两把剑尖一起取景（`fit` 0.62）。
- 剑花亮相（0.9–2.1 秒）给主角中景。
- 剑被磕飞到接剑：取景加上飞着的剑（`flyTip`），`fit` 0.7，剑始终在画里。
- 错身斩前后放宽到 `fit` 0.5：两人冲过去以后分得很开、背对背，要都在画里；结尾 `fit` 0.6。
- 慢镜头 4 处（`clock.slow`）：剑被磕飞（0.35×）、空中接剑（0.4×）、腾空跃过（0.4×）、错身斩（0.3×）。
- 1 帧白闪只在断刀那一下；打中不停帧、不震屏（拆解 3.5）。

## 看片时请看

1. **持剑的手**：拳头包着剑柄、护手、剑穗看得清吗？剑举过头时肘翻上去那 3 帧顺不顺？刀上撩翻刃那一下像不像转刀？
2. **对峙半秒静止**（3.3–3.8）：会不会太"死"（现在一动不动）？要不要加呼吸或缩短。
3. **第一回合 13 拍 4 秒**：是不是太快看不清？哪几拍想放慢。
4. **转折段**：剑被磕飞的慢镜头、剑插地晃、空手三连躲、踢剑接剑慢镜头——帅不帅、有没有太长。
5. **腾空跃过**（15.3，新加的慢镜头）：会不会和后面接剑的慢镜头重复。
6. **连环六拍**：云剑在头顶绕的那一圈看得出来吗（剑在头顶是透视缩短的）？提膝挂剑的独立架子、托刀架像不像。
7. **结尾**：断刀 → 背对背 → 看刀 → 跪 → 刀头落下吓一跳 → 抱拳礼。笑点的时间对不对（现在刀头飞上天 4.7 秒后才掉下来插地）；抱拳礼的手看得清吗。
