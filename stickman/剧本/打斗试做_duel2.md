# 打斗试做 duel2（第 8 轮设计稿）

> 第 8 轮：按用户看 duel1 的意见重做——**"感觉不够连贯和流畅；打架中间是没有停顿的；可以设计更好的动作，他们又不是击剑，你做成了击剑的样子，而不是正常动漫用刀剑打架的样子。"**
> 场景代码 `render/src/scene_duel2.js`（`SCENE=duel2`），7.48 秒。招式在 `analysis/fight_moves.json`（名字带 `_a` 的 30 招）。duel1 保留不改，方便对比。
> **渲染和音效都在用户本机做**：沙盒里只做设计、写代码、跑体检（`qa.js`、`contact_check.js`、`fight_probe.js`）和看少量关键帧。

## 一句话

两人拖刀对冲、剑在半路撞成 X，连着六拍你来我往没有一下停；锁剑较劲被强者压住、推开、跳劈、燕返し磕飞剑、回转斩把主角打飞——主角滑着跪住时代码已经打出来了：`sword.len *= 3`，剑一帧变长，一记上撩把跳在半空的强者打飞，自己也被剑带倒，两人都躺着。

## duel1 为什么像击剑（这次改掉的东西）

1. **剑沿前臂**：duel1 的剑只能顺着"肘 → 手"伸出去，能刺、能点，劈不出大弧线——于是全是击剑的刺和格。
2. **单手、直臂**：一只手握剑、手臂伸直往前送，就是击剑的样子。动漫刀剑是双手握、手在身前，靠转腰和步子出力。
3. **每招回架势 + 定格**：每一拍做完都回到同一个架势、定住，串和串之间再停 14–18 帧。拆解 3.5 那条"快拍之后一定停"是从原片统计来的，但用户要的是**打架中间不停**——这一条作废。
4. **剑的角度没有变化**：没有透视（横扫时剑指向镜头）、没有转身、没有拖影的弧线，看起来像在一个平面里比划。

## 动漫刀剑的做法（这次的原则）

- **上一招的收势就是下一招的预备**：剑停在哪儿，下一招就从哪儿起（挡完剑在头上 → 直接从头顶劈；劈到低位 → 直接往上撩）。守方的反应也收在自己下一招的起点。
- **攻守连续互换**：六拍里每拍换一次攻方，拍与拍之间 4–6 帧，没有"回到架势"。
- **"停"换成仍在动的段落**：锁剑（两人较劲、剑一直在抖）、滑退、滑行跪地。`contact_check` 逐帧查"两人同时几乎不动超过 4 帧"。
- **双手握剑、大弧线**：剑的角度单独写（`wa`），剑从头顶、身后、地面兜出来；横扫时剑指向镜头（`wl` 透视缩短）；回转斩真的转身（`turn`）。
- **整个身体出力**：胯先走、上身跟、手最后到；踏步滑进（`slide`）；跳起来的招在空中收腿（`fr`）。
- **剑碰剑碰在剑的强弱处**：攻方剑的 70–85%（剑尖段）撞在守方剑的 25–50%（靠手的一段），这是真格挡的样子，也让碰点落在两人之间。
- **差一点比打中多**：12 拍里只有 2 拍真打中（回转斩、巨剑上撩），其余是碰剑或闪开。

## 每招要点（完整说明在 `fight_moves.json` 的"说明"）

- **拖刀冲刺 X**：两人用同一招对冲；剑拖在身后贴地（195°–200°），f9–f10 从下面兜过来、指向镜头（透视 0.75 → 0.42），f11 上撩到 35°。终点按"接触时胯相距 1.45H"一起算。
- **六拍**：每拍攻方出招 3–5 帧到接触；守方 `ready` 2–3 帧提前起手。每个守方动作收在他下一招的起点（挡斜劈的剑在 62°–70° → 反劈直接从头顶绕；后仰就是突刺的蓄力；格开的剑举在头上 → 横斩；深蹲 → 上撩；被压的剑在下 → 唐竹从低位举起）。
- **锁剑**：两人各挤进一步，剑在两张脸之间交 X，14 帧里每 1–2 帧剑角差 2–3°（抖），主角后脚分两步被推退。`contact_check` 查锁剑段两把剑一直贴着（< 0.04H）。
- **跳劈 / 后跳**：强者在空中时主角就起跳，剑竖在身前（不和劈下来的剑交叉）；劈地那帧剑尖贴地，离主角身体 0.18H。
- **燕返し → 回转斩**：劈地的剑不停，贴地翻上来磕飞主角的剑（剑被磕到 115°–140°，胸口空着），这股往上的劲带着身体转一圈，剑扫过胸口。
- **巨剑上撩**：1.65H 的剑不能真的扫过地面（会插地），所以 f1 剑指向镜头（透视 0.18），f2 从镜头里转出来（0.55），f3 整把剑撩到 40°；月牙拖影从变长的下一帧才开始画（不然变长前后的剑之间会扫出一大片灰）。

## 距离

- 碰剑：接触时胯间距 1.19–1.45H，碰点都在 攻 0.72–0.86 / 守 0.24–0.36。
- 闪开：1.33–1.5H，整条剑身离身体 0.18–0.23H。
- 打中：回转斩 0.85H（剑身扫中 @0.81）；巨剑上撩 1.16H（@0.65，主角不迈步，强者自己冲进巨剑范围）。
- 所有手、脚每一帧都够得着（`contact_check` 逐帧查，0 处）；剑尖从不插地（手高 + 剑长 × wl × sin(wa) ≥ 0）。

## 镜头

- 打斗全程 `D.follow` 平滑跟拍：每帧框住两个人和两把剑尖，再按 ±0.25 秒滑动平均——镜头不会一顿一顿地追。
- 锁剑推到中景（fit 0.8）；推开之后回到全景。
- 剑变长：下一帧起 3 帧框进整把巨剑和空中的强者；之后跟着两个人（不追剑尖），最后 0.9 秒收两个人 + 整把巨剑（z ≈ 0.72）。不用 `wide`（太远人太小）。
- 体检景别：远景 25%、全景 68%、中近景 7%。

```bash
cd stickman/render

```

## 看片时请看

1. **连贯**：从 f13 冲刺到 f97 回转斩，中间有没有哪里像"停了一下"；六拍的攻守互换顺不顺。
2. **像不像动漫刀剑**（不是击剑）：双手握剑、剑从头顶 / 身后 / 地面兜出来的弧线、横扫的透视、回转斩转身。
3. **碰剑**：碰在两人之间、成 X；有没有剑穿过身体或隔空碰上；锁剑时两把剑是不是一直卡着。
4. **跳劈 / 燕返し / 回转斩** 这一串够不够爆；主角被打飞到跪住、同时打代码，节奏是不是太挤。
5. **巨剑**：变长那一帧、从身后兜上来、强者在空中被打飞；结尾两人躺着的景别。
6. 60fps 插值和 `STEP=24` 一拍一，哪个更好。
