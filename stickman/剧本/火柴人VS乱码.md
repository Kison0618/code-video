# 火柴人 VS 乱码（第三部，长片剧本 v2）

> 先定内容，再做画面。本文件是第三部的唯一依据（v1《火柴人 VS Bug》保留在 `火柴人VS_Bug.md`）。
> v2 按用户意见改了三件事：
> 1. **对手不再是红虫子，而是乱码拼成的东西**（代码世界里的东西就该是字做的）；
> 2. **接上一集**：开场就是上一集结尾那一幕的延续（他抱着电脑、小蛇在前面带路，从左边走进画面）；
> 3. **回忆镜头**：危机时刻像动漫一样闪回上一集用过的招式，然后快速用出来；第三幕还有一次情感回忆。
> 目标长度约 5 分 30 秒，三段：**学 → 打 → 和**。

## 一句话

上一集驯服了 hi 小蛇的火柴人，抱着电脑继续往前走。他学变量、列表，发现敲 `jump()` 自己的身体会跳。一次手滑把 `print` 拼成 `prnit`，报错的红字没有消失，而是抖成一团**乱码**——`锟斤拷`、`烫烫烫`、`�`——乱码爬了起来。它靠吃代码里的字母长大：被它咬到的字母会变成乱码，长到它身上，代码因此报错，报错的红光打在火柴人身上。它越吃越大，最后用乱码拼出了一个和他一样的火柴人，再长成巨人。火柴人不会打架，只能把学会的东西变成招式；被逼到绝境时，他**想起上一集用 for 砌墙挡住长蛇的那一幕**，几秒内砌出一堵墙。最后他用 `try / except` 接住每一次报错、反弹回去，乱码一块块剥落、吐回字母，缩回一小团。手指停在删除键上时，他**想起上一集摸着小蛇的那一刻**，于是没有删，只在那行前面加了一个 `#`：注释掉，留着，但不再伤人。

## 为什么是这个故事

- **对手是字做的**：乱码是每个写代码的人都见过的东西（中文用户尤其熟悉 `锟斤拷`、`烫烫烫`），一出现就有笑点，也一看就知道"坏掉了"。
- **对手的招式是它的真实性质**：它把字母变成乱码 → 名字对不上 → NameError → 报错的红光打人。每次报错都是真的 Python 运行时错误。
- **对手会"学"**：前面是一团爬来爬去的字，吃够了就照着火柴人的样子把自己拼成火柴人（镜像对手），打斗可以用完整的招式库。
- **打斗是编程的舞台**（拆解 3.5）：主角本身不会打，赢靠改代码；差一点比打中多。
- **前面学的，后面用**：变量 → 扔出去的武器；`jump()` → 函数能让身体动 → `def` 连招；上一集的 `for` 砌墙、`while True` 都成了招式。
- **收尾是和解**：注释 `#` 正好是"不删掉，但让它不运行"；呼应上一集把长蛇驯服成宠物。

## 回忆镜头怎么拍（新工具）

参考动漫的"闪回招式"：
1. **触发**：危机的最后一刻，他身体一僵，画面 2 帧白闪。
2. **回忆**：画面变成灰度 + 暗角 + 上下黑边 + 轻微颗粒，播放上一集的真实画面（直接调用上一集的场景代码在那几个时刻渲染，不是重画），3 个快镜头、每个约 0.5 秒，最后一个镜头推近到关键的那行代码。声音：低通滤波 + 回声，像隔着水听。
3. **回到现实**：2 帧白闪，头猛地抬起（"想到了"），接着**快打**：打字加速到平时的 3 倍、键盘冒出速度线，回车，招式出现。
4. 情感回忆（第三幕）节奏慢一点：画面更暖、更柔，镜头更长（每个约 1 秒），不配速度线。

## 知识阶梯（Python 入门顺序：变量 → 函数调用 → 列表 → 索引 → 错误 → 条件 → 函数定义 → 参数 → 异常 → 注释）

|---|---|---|---|

| 2 | 重新赋值 `x = 7` | 便签撕下来飞到新掉下的 7 上，5 孤零零留在原地 | 笑点（他去安慰那个 5） |

| 4 | 字符串方法 `print(pet.upper())` | 飞出一个巨大的 `HI`，"吼"一声把他吹得后仰 | 笑点（小蛇学着吼，只冒出小小的 hi） |
| 5 | 列表 `toys = ["ball", "box", "rope"]` | 三个词装进连在一起的三节**车厢** | 埋：列表 = 连起来的一串 |

| 16 | 注释 `#` | `# prnit(toys)` 整行变灰，乱码不再抖 | 和解 |

## 角色

- **火柴人**：黄色实心头，没有台词没有脸。"精力旺盛的小孩"：好奇、一成功就手舞足蹈、得意就忘形。**不会打架**：前两回合动作笨拙，越往后越像样。
- **小蛇宠物**（上一集的三节 `hi`）：跟在脚边，会学他。被咬掉 `i` 之后只剩 `h`，蔫了。第三幕把电脑推回来，是转折的帮手。
- **乱码**：由乱码字符拼成，灰白色（和代码同色系，不是红色）。字符一直在**抖**：每隔几帧随机换成别的乱码，偶尔整块横向错位一下（像信号不好）。没有脸；头是一个大大的 `�`。四个阶段：
  - **S 一团**（诞生）：七八个乱码字挤成一团，像虫子一样用字当脚一跳一跳地爬，快、乱窜。
  - **M 小火柴人**：吃够字母后，照着火柴人的样子把自己拼成一个火柴人——骨头是一串串乱码字，头是 `�`，身高是主角的一半。
  - **L 一样高**：和主角一样大，镜像对手，招式和主角一样（用招式库）。
  - **XL 巨人**：吞下整段函数后，3 倍高，画面装不下。
  - 吃字母的过程看得见：被咬的字母先在原地乱跳成乱码（3 帧），再飞过去贴到它身上，成为它的一部分。
- **电脑**：主角掌控的标志。在手里 = 占上风；被打飞 = 失控；第三幕小蛇推回来。

## 打斗总规则（拆解 3.5，做的时候每回合对照）

- 打中不停帧、不震屏：1 帧光 + 火花 + 结果字形。只有回合结尾那一下重击闪全屏 1 帧。
- 出招 1–2 帧，预备是出招的 2–3 倍，收招 5–6 帧。快拍 3–6 下之后一定停（停在两招之间）。
- 回合 3–6 秒。主角出手多，但前几个回合都以乱码的一记反击结束。反应逐级加重：后仰 → 踉跄 → 弯腰 → 被打飞。
- 差一点比打中多：攻击在主角离开后 2–4 帧才落到原位。
- 代码高亮 4–6 帧当"预备"。
- 每种武器升级 3–4 次就换；攻击物落下后变成地形（50 那块大数字之后当掩体，墙之后当跳台）。
- **重复必须有变化**（用户对 v2 的意见）：同一个招式最多连用 3 次，每次换角度、换距离、换结果。
- 镜头：回合内固定全景框住两人；被打飞时 6–12 帧快速拉远；出新武器 / 乱码变大时推近或拉远交代规模。

## 镜头总规则（拆解 2.2）

- 基准景别全景（人占画面 35–40%）。
- 大远景：开场（接上一集）、乱码 XL 第一次站起来、被打飞到最远处、反弹时红光满天、结尾。每次 2–6 秒。
- 近景只给反应：乱码诞生时对视、小蛇被咬、`def` 写完没反应、低谷躺着、手指停在删除键上。
- 远景 + 大远景合计目标 30% 以上。

## 屏幕上会出现的代码（每次运行时都必须是合法 Python，体检会查）

编辑器像交互式窗口：每次回车只运行最新那一行（运行的灰底只盖那一行）。

```python
x = 5            # 0:10，0:22 改成 x = 7
jump()           # 0:32
jump()           # 0:37
pet = "hi"       # 0:46
print(pet.upper())
toys = ["ball", "box", "rope"]
toys[1]          # 1:03 → 改成 toys[0]
prnit(toys)      # 1:13 NameError（运行时错误，语法合法）
throw(x)         # 1:42；被吃掉 r 成了 thow(x) → NameError
chain = [1, 2, 3]
chain.append(4)  # 2:14、2:17
chain[9]         # 2:23 IndexError
for i in range(6):     # 2:55 回忆后快打
    print("#####")
while True:      # 3:00
    if near(foe):
        dodge()  # 3:26 被吃掉 d 成了 doge() → NameError，循环中断
    elif throwing(foe):
        duck()
def combo():     # 3:35，3:51 改成 combo(n) + for
    jab()
    jab()
    kick()
combo()
try:             # 4:34
    combo(3)
except NameError:
    shield()
# prnit(toys)    # 5:09
print(toys)
jupm()           # 5:21 → jump()
```

- 乱码只吃**名字里的字母**，造成的都是运行时的 NameError，不碰冒号括号（否则是语法错误，`try` 接不住，和真实 Python 不符）。
- `jump / throw / dodge / duck / jab / kick / shield / near / throwing` 和 `foe` 是这个世界自带的（和 `print` 能掉出实物一样）；开场 `jump()` 就是告诉观众"函数名 = 身体的动作"。
- 4:40 那一下是真的：`combo` 被吃掉了，所以 `combo(3)` 报 NameError，正好被 `except NameError` 接住。
