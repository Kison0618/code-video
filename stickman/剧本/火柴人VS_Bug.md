# 火柴人 VS Bug（第三部，长片剧本 v1）

> 先定内容，再做画面。本文件是第三部的唯一依据。
> 目标：5 分 20 秒左右（用户要求 4–6 分钟），故事完整，有打斗。三段：**学 → 打 → 和**。
> 写之前查过：`创意库.md`（第 3 节概念点子、第 4 节对手模式、第 7 节用过的别重复）、`拆解_火柴人系列.md` 3.5（打斗规律）、用户对 v2 的意见（同一个动作连续重复就拖）。

## 一句话

火柴人带着上一集驯服的小蛇宠物学变量、列表，还发现敲 `jump()` 自己的身体会跳。一次手滑把 `print` 拼成了 `prnit`，报错的红光里爬出一只小红虫——**Bug**。它靠吃代码里的字母长大：每咬掉一个字母，代码就报错，报错的红光就打在火柴人身上。火柴人打架很笨，只能把学会的东西变成招式：扔变量、甩列表、用 `if` 给自己写条件反射、用 `def` 把连招压成一个按钮。可 Bug 把他的函数整段吃掉，长成了巨物。最后火柴人用 `try / except` 把每一次报错接住、反弹回去，Bug 一口口吐出吃掉的字母，缩回一只小虫。他没有删掉它，而是在那行前面加了一个 `#`：**注释掉，留着，但不再伤人**。Bug 成了他的除错小帮手。

## 为什么是这个故事

- **打斗是"编程"的舞台，不是拳脚秀**（拆解 3.5）：主角本身不会打，赢靠改代码；挨打、差一点比打中多。
- **对手是自己造的**（创意库 4.1）：一个拼写错误。观众都犯过，一看就懂。
- **对手的招式是它的真实性质**（4.4）：Bug 吃字母 → 代码出错 → 报错的红光打人。每次报错都是真的 Python 错误（NameError、IndexError），不是乱编的。
- **前面学的，后面用**（创意库 1.5）：变量 → 扔出去的武器；`jump()` → 函数能让身体动 → `def` 连招；上一集的 `while True` 从对手变成帮手（条件反射要一直跑）。
- **收尾是和解，不是消灭**（4.8）：注释 `#` 正好是"不删掉，但让它不运行"。
- 小蛇宠物从上一集延续，给系列连续性；它被 Bug 吃掉一个 `i`，最后 Bug 还回来。

## 知识阶梯（Python 入门顺序：变量 → 函数调用 → 列表 → 索引 → 错误 → 条件 → 函数定义 → 参数 → 异常 → 注释）

| 步 | 学到的 | 看得见的结果 | 在故事里当什么 |
|---|---|---|---|
| 1 | 赋值 `x = 5` | 一个 5 掉下来，一张写着 `x` 的**便签**飞过去贴在 5 上 | 道具（之后当武器扔） |
| 2 | 重新赋值 `x = 7` | 便签撕下来飞到新掉下的 7 上，5 孤零零留在原地 | 笑点（他去安慰那个 5） |
| 3 | 调用函数 `jump()` | 他还没准备好，**身体自己跳了一下** | 埋：代码能让身体动 |
| 4 | 字符串方法 `print(pet.upper())` | 飞出一个巨大的 `HI`，"吼"一声把他吹得后仰 | 笑点（小蛇学着也吼，只发出小小的 hi） |
| 5 | 列表 `toys = ["ball", "box", "rope"]` | 三个词装进连在一起的三节**车厢** | 埋：列表 = 连起来的一串 |
| 6 | 索引从 0 开始 | `toys[1]` 想拿第一个，掉出来的是 box；挠头；`toys[0]` 才是 ball | 笑点 |
| 7 | 拼写错误 → NameError | `prnit(toys)` 报错，红光散去后**一只小红虫从 prnit 里爬出来** | 对手诞生 |
| 8 | 变量的值有大小 | `throw(x)`：5 → 50 → 5000，一个比一个大；5000 太重，砸在自己身上 | 武器 1（升级 3 次） |
| 9 | `append` | `chain = [1, 2, 3]` 连成链鞭，`chain.append(4)` 变长，打中了 | 武器 2 |
| 10 | IndexError | `chain[9]` 伸手去拿不存在的第 10 节，手抓空滑下去 | 失误 → 被反击 |
| 11 | `while True` + `if` / `elif` | 写出**条件反射**：Bug 靠近就自动闪，Bug 吐东西就自动蹲 | 武器 3（防守）；上一集的对手变帮手 |
| 12 | `def` 定义 ≠ 运行 | 写完 `def combo():` 什么都没发生（等了 2 秒）；`combo()` 才打出三连击 | 武器 4 |
| 13 | 参数 + `for i in range(n)` | `combo(3)` 九连击；`combo(100)` 把自己累瘫 | 武器 4 升级 |
| 14 | `try / except` | Bug 咬出来的每个错误被 except **接住，变成盾**，红光反弹回去 | 终极：反弹 |
| 15 | 注释 `#` | `# prnit(toys)`：那一行变灰，不运行，Bug 变温顺 | 和解 |

每一步只多一样东西；观众只看画面也能猜到代码在干嘛（创意库 1.6）。

## 角色

- **火柴人**：黄色实心头，没有台词没有脸。性格延续"精力旺盛的小孩"：好奇、一成功就手舞足蹈、得意就忘形。**不会打架**：前两回合动作笨拙（抓空、扔偏、被自己的链子缠住），越往后越像样——观众看到的是"他靠代码长本事"。
- **小蛇宠物**（上一集结尾那条三节的 `hi` 小蛇）：跟在他脚边，会学他。被 Bug 咬掉头上的 `i` 之后只剩 `h`，蔫了。第三幕它去把电脑叼回来，是转折的帮手。
- **Bug**：红色（和黄色主角、白色代码都分得开），椭圆身体 + 六条细腿 + 两根触角，嘴一张一合。**肚子半透明，能看见吃下去的字母**——观众随时知道它吃了什么、为什么变大。四个大小：
  - S（主角的 1/6，像老鼠）→ M（像狗）→ L（和主角一样高）→ XL（主角的 3 倍，画面装不下）。
  - 小时候动作快、乱窜（几乎看不清）；越大越慢、越重，XL 每走一步地面都震（但打中时仍不震屏，拆解 3.5）。
- **电脑**：主角掌控的标志。在手里 = 他占上风；被打飞 = 失控；第三幕小蛇叼回来。

## 打斗总规则（拆解 3.5，做的时候每回合对照）

- 打中不停帧、不震屏：1 帧光 + 火花 + 结果字形。只有回合结尾那一下重击闪全屏 1 帧。
- 出招 1–2 帧，预备是出招的 2–3 倍，收招 5–6 帧。快拍 3–6 下之后一定停（停在两招之间）。
- 回合 3–6 秒。主角出手多，但前三个回合都以 Bug 的一记反击结束。反应逐级加重：后仰 → 踉跄 → 弯腰 → 被打飞。
- 差一点比打中多：Bug 的攻击在主角离开后 2–4 帧才落到原位。
- 代码高亮 4–6 帧当"预备"：观众先看到要变的那行，再看到动作。
- 每种武器升级 3–4 次就换；攻击物落下后变成地形（50 那块大数字之后当掩体）。
- **重复必须有变化**（用户对 v2 的意见）：同一个招式最多连用 3 次，每次换角度、换距离、换结果。
- 镜头：回合内固定全景框住两人；被打飞时 6–12 帧快速拉远；出新武器 / Bug 变大时推近或拉远交代规模。

## 镜头总规则（拆解 2.2）

- 基准景别全景（人占画面 35–40%）。
- 大远景五处：开场（空）、Bug XL 第一次站起来（规模）、主角被打飞到最远处（孤独）、反弹时红光满天、结尾（空，和开场呼应）。每次 2–6 秒。
- 近景只给反应：Bug 诞生时他和虫对视、小蛇被咬、`def` 写完没反应、低谷躺着、注释那一下。
- 远景 + 大远景合计目标 30% 以上（v2 只有 18%，编程集 53%）。
- 节拍上推拉，节拍之间稳住；跟拍时给 Bug 那一侧留空间。

## 屏幕上会出现的代码（每次运行时都必须是合法 Python，体检会查）

```python
x = 5            # 0:15
x = 7            # 0:23
jump()           # 0:32、0:37
pet = "hi"       # 0:46
print(pet.upper())
toys = ["ball", "box", "rope"]
toys[1]          # 1:04 → toys[0]
prnit(toys)      # 1:14 NameError（运行时错误，语法合法）
throw(x)         # 1:42；被咬成 thow(x) → NameError
chain = [1, 2, 3]
chain.append(4)  # 2:14、2:17
chain[9]         # 2:23 IndexError
while True:      # 2:49
    if bug.near:
        dodge()  # 3:15 被咬成 doge() → NameError，循环中断
    elif bug.spit:
        duck()
def combo():     # 3:25，3:41 改成 combo(n) + for
    jab()
    jab()
    kick()
combo()
try:             # 4:24
    combo(3)
except NameError:
    shield()
# prnit(toys)    # 4:57
print(toys)
jupm()           # 5:10 → jump()
```

- Bug 只咬**名字里的字母**，造成的都是运行时的 NameError，不咬冒号括号（那会变成语法错误，`try` 接不住，和真实 Python 不符）。
- `jump / throw / dodge / duck / jab / kick / shield` 和 `bug` 是这个世界自带的（和 `print` 能掉出实物一样），开场 `jump()` 那一下就是告诉观众"函数名 = 身体的动作"。
- 4:30 那一下是真的：`combo` 被吃掉了，所以 `combo(3)` 报 NameError，正好被 `except NameError` 接住。
