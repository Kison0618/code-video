# 打斗试做 duel1（第 7 轮设计稿）

> 第 7 轮：不照原片，自己按 `动作设计.md` 的七个问题设计一段完整的小打斗，验证"设计 → 代码 → 自查"这套方法能不能做出 Alan Becker 那种观感。
> 场景代码 `render/src/scene_duel1.js`（`SCENE=duel1`），约 14 秒，24fps 一拍一出画。招式在 `analysis/fight_moves.json`（名字带 `_d` 的）。
> **渲染和音效都在用户本机做**：沙盒里只做设计、写代码、跑体检（`qa.js`、`contact_check.js`）和看少量关键帧。

## 一句话

强者几乎不动就化解了主角所有进攻，还把他打飞；主角爬起来写了一行 `sword.len *= 3`，剑一帧变成三倍长，一记弓步刺把强者打飞；他得意地举剑庆祝，剑太重，自己往后倒——两个人都躺在地上。

## 整段的七个问题

1. **意图**：观众要看懂"强弱悬殊 → 用代码翻盘 → 得意忘形"。主角急、越打越乱；强者懒、看不起人。前半段笑点是"他根本没认真"，后半段是"赢了也摔"。
2. **招牌姿势**（每一段一张能单独截图看懂的画）：主角弓步刺被对手退半步闪开（差一点）；劈空砸地、弯着腰被点脑门；被挑飞；举着三倍长的剑；两个人都躺着。
3. **收紧**：整段的"收"是第 ⑥ 段——躺着不动 16 帧、爬起来、低头看自己的短剑、抬头打代码，全片最安静的地方，后面一刺才显得爆。
4. **节奏**：两串攻防，每串拍子越来越密（间隔 9 → 7 → 6 → 4 帧），串与串之间"停"14–18 帧（拆解 3.5：停是标点）。定格：打飞后躺 16 帧、刺中后定 15 帧、两人躺着定 27 帧（1.1 秒，原片 C 的笑点定格长度）。
5. **先后**：强者从"只动手腕"（格挡）→"伸手臂"（点）→"迈一步"（上撩），动的部位逐级变多，第一次迈步就是第一次认真出手。主角正相反：一开始整个身体都在用力（浪费），最后一刺才"干净"。
6. **曲线**：出招 `out`（第 1 帧最快）；往后倒 `inOut` 晃 → `in` 倒下（重力）；被推开、踉跄 `out`。
7. **反应逐级加重**（拆解 3.5）：后仰（`flinch_d`）→ 踉跄（`bonk_back_d`）→ 被打飞（`launched`）；强者那边：闪 → 挡 → 愣 6 帧才反应（`recoil_d`）→ 被打飞。

## 距离设计（这一轮踩坑最多的地方）

- **架势间距 1.57H**（主角 x0 −240、强者 230，主角 H=300）。太近（u < 0.5，打到剑根）会显得贴身肉搏，太远招式要先补步子。
- **碰剑间距 1.2–1.4H**：两把剑要成 X，而且碰在两人之间（守方身前，`contact_check` 的 dep ≤ −0.05）。碰剑那一刺比"闪开"那一刺站远 0.3H（`opts.reach: 1.74`）。
- **闪避要"差一点"**：剑尖离身体 0.03–0.3H。
- **reach 的含义**：接触时两人胯间距 = reach − 招式自己在接触帧的胯前移；兵器招的 reach 已含兵器长。改了剑长（`sword.len *= 3` 后 1.2H）就要重算（收尾 `FIN_REACH` 2.21）。
- 校法：`SCENE=duel1 node src/tools/contact_check.js`，每拍给出间距、剑尖越过躯干、到身体距离、剑碰剑距离、剑尖插地、建议 reach。

## 镜头

- 回合内固定全景（fit 0.55），不跟着每一拍晃。
- 被打飞：8 帧快速拉远（`out3`），把落点包进来；收尾那一刺 10 帧拉远。
- 看剑、打代码：推近到主角和代码。
- 剑变长：**下一帧**起 4 帧拉开到全景——先让观众看清剑，再看强者的反应。
- 举剑推近；两人躺着时慢慢拉开到远景。
- 已知：打代码那段强者在画面右边被切掉一半（可以接受，也可以改成三人一起包进来）。

## 本机渲染和自查

```bash
cd stickman/render
SCENE=duel1 node src/tools/qa.js                 # 体检（不渲染，几秒）
SCENE=duel1 node src/tools/contact_check.js      # 逐拍查碰剑 / 打中 / 闪避的距离
cd ..
SCENE=duel1 node build.js --fps 24 --from 0 --to 14 --jobs 8               # 带音效
cd render && FPS=24 SCENE=duel1 node src/render_all.js out/duel1.mp4      # 只看画面
```

## 看片时请看

1. 整体节奏：两串攻防是不是"越来越急 → 停"，停的长度够不够。
2. 一拍一（24fps 硬切、不插值）的观感：像不像手绘，有没有哪里太卡或太跳。
3. 架势高度：主角的击剑架势这次不再蹲得很低，看是否自然。
4. 间距和碰剑：剑碰剑、闪开、点到，信不信得过（有没有隔空打中、剑穿过身体）。
5. 笑点：强者"懒"读不读得出来；剑变长那一帧和强者愣 6 帧；最后两人躺着 1.1 秒。
6. 打代码时强者在画面右边被切一半，要不要改。
