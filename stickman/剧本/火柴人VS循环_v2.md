# 火柴人 VS 循环（剧本 v2）

> 先定内容，再做画面。本文件是 v2 的唯一依据（v1 保留在 `火柴人VS循环.md`）。
> v2 根据反馈改了四件事：① 镜头学数学集（空旷开场、全景为基准、规模变大才拉远、大远景当标点）；② 知识按 Python 入门顺序排，并加一个对手；③ 学会的东西当武器 / 道具用；④ 东西砸到人要有碰撞和反应，按组合键不切镜头。

## 一句话

一个火柴人在空无一物的世界里醒来，从光标摸索出 `print`，学会用 `for` 重复、用 `i` 和 `"#" * i` 给自己搭出一座楼梯；站在楼梯顶上得意地写下 `while True`，结果造出了一条无穷长的 **hi 长蛇**。他用 `for` 砌墙挡、被无穷长的蛇翻过去缠住，最后按 `Ctrl+C` 脱身，再用**条件** `while n < 3` 写出一条只有三节的小蛇——对手变成了宠物。

## 知识阶梯（Python 入门顺序：输出 → 字符串 → 循环 → 变量 i → 无限循环 → 条件）

入门教程的通行顺序是 print → 变量 → 条件 → for / while → 函数（滑铁卢大学入门教程、Caleb Curry 系列等）。第一集只走到"条件让循环停下来"，每一步只多知道一点：

| 步 | 学到的 | 看得见的结果 | 用法（创意） |
|---|---|---|---|
| 1 | 按键 = 出字 | 光标那里冒出字母 | — |
| 2 | 随便写的词会报错 | `hello` → 变红 NameError | — |
| 3 | `print("hi")` 把字变成实物 | hi 飞出来**砸在他头上**，弹开落地 | 字有重量 |
| 4 | 手敲很累 → `for` 替你重复，要缩进 | IndentationError → 按 Tab（屏幕上弹出 **Tab** 键帽）→ 3 个 hi | — |
| 5 | 括号里的数决定次数 | 3 → 10 → 100，hi 雨**一个个砸在他身上**，把他埋了 | 循环 = 数量爆炸 |
| 6 | `i` 每次都不一样 | `print(i)`：0 1 2 … 9 排成一排 | — |
| 7 | 字符串可以乘：`"#" * i` | 每一行 # 比上一行多一个，立起来成了**一级级台阶**，他爬上去 | 循环 = 建造 |
| 8 | `while True` 永远不停 | 输出的 hi 首尾相连，成了一条**无穷长的蛇**（对手） | 无限 = 对手 |
| 9 | `for` 是有限的 | `for` 砌出一堵 `#####` 墙，蛇头撞上去被挡住——但蛇是无限长的，翻过来了 | 循环 = 盾 |
| 10 | `Ctrl+C` 强行停止 | 他按键，屏幕上弹出 **Ctrl** + **C** 键帽（不切镜头），蛇定住碎掉 | — |
| 11 | **条件**能让循环自己停 | `while n < 3:`，代码上的小标签 `True → True → True → False`，正好三个 hi | 逻辑 = 驯服 |

对手的设计（拆解 3.2）：麻烦是他自己造的（自己写的 while True），出现在知识攒够之后；对付它用的是刚学会的东西；最后不是消灭它，而是用新知识（条件）把它变成可控的、友好的东西。

## 角色

- 黄色实心头火柴人，没有台词没有脸。
- **性格：刚接触代码、精力旺盛的小孩。** 好奇、胆子不大但忍不住去碰、一成功就手舞足蹈、得意就忘形。被吓到会愣住，但恢复得很快。
- 内心过程按拆解 3.1：注意到 → 停住看 → 情绪姿势 → 小心试探 → 得出结论 → 下一步。

## 镜头总规则（拆解 2.2）

- 基准景别：全景（人占画面约 35–40%）。人和他手里的东西都要看清。
- 呼吸：东西变多变大时拉到远景几秒，然后推回。
- 大远景只在四处：开场（空）、hi 雨、蛇翻墙（规模）、结尾（空，和开场呼应）。每次 2–6 秒。
- 近景只给反应：被砸、报错、蛇第一次看他、被缠住、驯服后摸蛇。
- 节拍上推拉，节拍之间稳住；跟拍时给威胁那一侧留空间。

## 节拍表（总长约 2 分 30 秒；时间是目标值，±10%）

镜头：特远 = 大远景（< 8%）、远 = 远景（~15%）、全 = 全景（35%）、中 = 中景、近 = 近景。

## 视觉规则

- 黑底，白字代码（VS Code Dark+ 配色），黄色主角；报错红；条件标签 True 用绿、False 用红。
- 输出的东西是实物：有重量、会弹、会堆、**砸到人会弹开、人会有反应**。
- 键帽：按 Tab、Ctrl+C 这类组合键时，在电脑上方弹出白边圆角键帽，按下去会往下一沉，0.6 秒后淡出。不切镜头。
- 蛇：由 `hi` 首尾相连组成，每个字沿着蛇身的方向转，蛇头是大一号的 `HI`；它的身体就是蛇头走过的路，所以永远连着代码。

## 声音（新增，写入 `audio/音效需求.json`）

- `bonk`：字砸到头上（轻、闷、带一点滑稽感）
- `snake_slither`：蛇游动的连续沙沙声（可循环，按速度变化）
- `snake_bite`：蛇头咬在地上 / 撞墙
- `block_drop`：一根 # 柱子 / 一层墙砸到地上（比字重）
- `scale_drone`：蛇盘满天空时低沉的拉长音
- `cond_false`：条件变 False、循环结束的一声"嘀"（干净、有"完成"感）
- 配乐：第一幕、第二幕前半安静；hi 雨进轻快配乐；第三幕追逐最强；Ctrl+C 切断；最后小蛇出现时回来一段很轻的旋律。
