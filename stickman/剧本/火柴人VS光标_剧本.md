# 火柴人 VS 光标（第三部，制作用剧本）

> 依据：`火柴人VS光标_v6创意.md`（用户已同意："允许，去设计合适的效果，制作整个视频吧"）、v5 设计稿的骨架、v4 的原则（第 0 节）、拆解 2.3 / 3.5 / 3.6。
> 分五段做，每段一个场景（方便体检），最后一个总场景按顺序拼起来：`SCENE=cur1 … cur5`，总片 `SCENE=cursor`。
> 只写代码、跑体检、抽帧检查；渲染在用户本机。

## 效果设计（全片统一）

| 效果 | 样子 | 声音 id |
|---|---|---|
| 他的光标 | 代码里的白色下划线，规则闪（0.5 / 0.5 秒） | — |
| 它（第二个光标） | 同样的白色，闪得不规则；在世界里有影子 | cursor_blink |
| 趴 `_` → 站 `\|` | 1 帧切换，切的时候 `\|` 往上弹一下再落（像站起来） | cursor_stand |
| 跳格走路 | 一下一下瞬移，每格 0.4H，每下"嗒"；远处连跳，近处变慢 | cursor_hop |
| 盯住 | 停止闪烁、常亮、周围一圈淡光；全场静 10 帧 | cursor_stare |
| 蓄力 | 头顶加载圈从 0 转到满（0.8 秒），满的一帧闪白 | cursor_load |
| 选中 | 被选中的东西底下铺一块蓝色（`rgb(38,79,160)`）；单击 / 双击 / 三击分别是 1 / 2 / 3 声点击 | select, click |
| 删除 | 被选中的东西从右往左一个字一个字消失（每字 1–2 帧），它长大一点 | backspace_eat |
| 查找 | 所有匹配的字底下同时铺黄色 | find_hit |
| 替换 | 黄色里的字一个个翻成新字 | replace |
| 鼠标箭头 | 白色箭头从画外飞进来，按住东西（按下去缩一下），拖着走 | drag |
| 打字说话 | 它头顶冒出小号白字（一个个打出来），1 秒后淡掉 | key |
| 大写字砸人 | 0.5H 高的大写字从上面掉下来，有重量，落地后留在原地当地形 | thud |
| 全选 | 整个画面一帧变成蓝色，物体都还在（被选中的样子） | select_all |
| 删除一切 | 蓝色一帧变成纯白，只剩主角和电脑（没被选中的只有他） | delete_all |
| 撤销 | 白里，被删的东西倒着长回来（倒放删除的样子：一个字一个字从左往右出现） | undo |
| 键帽对决 | Delete / Ctrl+Z 键帽从两人头顶弹出，往对方飞，撞在中间碎掉 | key_clash |
| 打中它 | 它闪一下变暗、被打歪（倾斜 20°）、弹回去；1 帧白光 + 火花 | impact_* |
| 报错 | 原有的红光推人 | error |
| 回忆 | 灰度 + 暗角 + 上下黑边 + 颗粒；白闪 2 帧进出 | flashback_in / out |

地面：一行很淡的字（画面里看起来像一条灰线，近看是字），全片都在这一行上。

## 代码（每次运行都必须是合法 Python）

- `n = 0` / `while n < 3:` / `print("hi")` / `n = n + 1`（上一集）；改成 5、10；`"hi5"` 是两个光标同时打字的结果（合法）。
- `jump()`、`jmup()`（NameError）、`while True:` / `if near(cursor):` / `dodge()` / `elif typing(cursor):` / `duck()`、`doge()`（NameError）、`def combo():` / `combo(3)` 等。
- `for i in range(6):` / `print("#####")`；`print("hi")`。
