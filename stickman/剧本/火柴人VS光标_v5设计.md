# 火柴人 VS 光标 —— 设计稿 v5（对手换成"第二个光标"）

> 用户否掉了乱码造型（"都是垃圾，它可以不是乱码"），要求按参考片重新想对手。候选和理由见 `第三部对手候选.md`；这一稿用推荐的 **A：第二个光标**，并把 **B：报错**并进来（光标改了他的字 → 报错打他）。
> v4（`火柴人VS乱码_v4设计.md`）里和对手无关的部分照用，不再重复：第 0 节的原则、2.1 主角的打字姿势路线、2.2 小蛇、2.4 电脑、第 4 节打斗要点、构图规则。这一稿只写变了的部分。
> 长度约 5 分钟。只做设计，用户看过再做。

## 1. 一句话

他手一滑按了 `Alt + 点击`，屏幕上多出**第二个光标**。一开始它只是跟着他打字——他打一个 `hi`，世界里掉下两个——好玩。后来它不跟了，开始自己动：选中他的字、删掉、改掉，选中小蛇、一按退格吃掉一节，复制粘贴出一群自己，最后按下 `Insert` 变成一块巨大的实心方块光标 `█`，把他写的一切覆盖掉。他靠边躲边写撑下来，用 `try / except` 把它造成的每个报错接住。最后的回忆告诉他：它从头到尾只是在学他。结尾他打了半行 `print(`，停下来等——第二个光标把后半行 `"hi")` 补上了。

## 2. 为什么是光标（按原片对手的规律）

1. **本来就在这个世界里**：每一集开场都是一个闪着的光标；原片编程集 0:00 也是。观众一眼认得出，不用另外发明。
2. **样子极简**：一条白色下划线 `_`。小也看得清，满足"轮廓清楚"。
3. **表情全是它本来就会做的事**（不加眼睛）：闪烁的节奏、移动、选中、常亮。
4. **能力全是真实的编辑器操作**：多光标、选中、退格、改字、剪切、复制粘贴、撤销、`Insert` 覆盖模式。观众都用过，看打架就等于学操作。
5. **它造成的后果是真实的 Python 报错**（候选 B 并进来）：它把 `jump` 改成 `jmup` → NameError → 红光打他。

## 3. 对手设计卡：第二个光标

### 3.1 样子

| 形态 | 样子 | 大小 | 什么时候 |
|---|---|---|---|
| 普通光标 | 白色下划线 `_`，和他的光标一模一样 | 0.15H 宽（一个字宽） | 开场到回合 1 |
| 长大 | 还是下划线，变成一根横梁 | 0.5H → 1.5H 宽 | 回合 1 起，它"吃"字之后 |
| 分身 | `Ctrl+V` 粘贴出一排光标 | 每个 0.3H | 回合 2 |
| 方块光标 `█` | 按 `Insert` 进入覆盖模式，变成实心方块 | 1H → 3H | 回合 4、第三幕 |

- **和他的光标怎么区分**：形状一样，**闪的节奏不一样**——他的光标 0.5 秒亮 / 0.5 秒灭（原片实测），它的光标亮灭不规则；它出现在代码里时下面跟一个很小的影子（它站在地面上的时候）。
- 它在**代码里**（屏幕上）和**世界里**（地面上）都能走：从代码块里跳出来落到地上，再跳回去。

### 3.2 表演词汇（每次都一样，让观众学会读它）

| 词汇 | 做法 | 对应原片规律 |
|---|---|---|
| 平静 / 观察 | 慢闪（1 秒一次） | 多胞体匀速、慢 |
| 兴奋 / 准备动手 | 快闪（每 4 帧一次） | 预备 |
| **盯住** | **停止闪烁、常亮 10 帧**，所有声音停掉 | 几何"转到正面停一下"、编程"静止 10 帧再开火" |
| 看哪里 | 移到哪个字后面，就是在看哪里；在地面上时朝向用"往那边歪一下"表示 | e^{iπ} 的剑尖朝向 |
| **瞄准** | **选中**：一段字变成高亮底色（4–6 帧），然后动手 | 编程集"高亮 4–6 帧 = 扣扳机" |
| 吃 | 高亮之后一下退格：字从后往前一个个消失（每个 1–2 帧），它长大一点 | 几何"吃" |
| 说话 | 自己打字：`hi`、`no`、`:)`、`?`——字很小，挂在它头顶 | 编程集结尾笔记本打 `hello yellow` |
| 得意 | 主角倒地时，它在旁边打一串 `hahaha`，字一个个掉在他身上 | 数学"在原地玩刚吃的东西" |
| 害怕 | 闪得乱，往后退，缩回一个字那么小 | 数学"变小溜走" |
| 被打中 | 闪一下变暗，被打歪，弹回去；不会碎（它是光标） | 编程"写的东西被删掉" |

### 3.3 招式（全是编辑器操作，越往后越大）

| 招式 | 画面 | 后果 |
|---|---|---|
| 跟着打（多光标） | 他打一个字，它在另一个地方同时出一个一样的 | 一开始帮他（两倍输出），后来变成捣乱 |
| 改字 | 偷偷把他代码里一个字换掉 | 下一次运行 NameError，红光打他 |
| 选中 + 退格 | 高亮一段（小蛇的一节、他脚下的字、墙的一块）→ 一下吃掉 | 小蛇变短、他掉下去、墙出洞 |
| `Ctrl+X` 剪切 | 高亮 → 东西消失，出现在它想放的地方 | 把他的电脑"剪"走、放到远处 |
| 打字攻击 | 打出 `BOOM`（大写锁定）——大字从天上掉下来砸人 | 物理攻击 |
| `Ctrl+V` 粘贴自己 | 一个光标变一排光标 | 分身大军 |
| `Ctrl+Z` 撤销 | 他刚写好的代码一行行倒着消失 | 他的招被撤掉 |
| `Insert` 覆盖模式 | 变成实心方块 `█`，走过的地方所有字都被覆盖成 `█` | Boss 形态 |

每次大招前都是同一套：**快闪 → 停止闪烁常亮 10 帧 → 高亮 → 动手**。全片至少重复 4 次。

## 5. 知识点

| 知识 | 效果 |
|---|---|
| 多光标（Alt + 点击） | 打一个字出现在两个地方；输出翻倍；抓住一个光标塞进代码反过来用 |
| 选中 + 退格 / 剪切 / 粘贴 / 撤销 | 它的招式；观众看到每个快捷键的效果 |
| `Insert` 覆盖模式 | 光标变成方块，覆盖一切（Boss） |
| NameError | 名字差一个字就失灵（它偷改字的后果） |
| 改循环次数、`for` 砌墙（上一集） | 小蛇变长 / 缩回；回忆后砌墙 |
| `while True` + `if` | 条件反射 |
| `def` + 参数 | 连招 |
| `try / except` | 报错变成盾 |
