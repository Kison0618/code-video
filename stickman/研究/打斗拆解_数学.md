# 《Animation vs. Math》打斗逐帧拆解（给火柴人动作代码用）

- 素材：v2.mp4（1920×1080，23.976fps）。**帧号 = 原片绝对帧号（24fps 计）**，`f6837` ≈ 4:45.16。秒数写成 m:ss.ss。
- **H = 橙色火柴人站立身高**（头顶到脚底）。所有位置都“相对胯点、以 H 为单位”：x 正方向 = 面朝 / 出手方向，y 向上为正（胯 ≈ 0.5H 高，肩 ≈ 0.78H，头心 ≈ 0.9H）。
- 方法：2fps 全段粗扫 → 关键段 12fps / 8fps 拼图 → 交锋处原生逐帧拼图 → 用橙色像素包围盒逐帧算位移、身高（＝景别）、画面横向位置。图和数据在 `study/fight/math/`（`c*.png` 粗扫，`s*.png` 12/8fps，`n*.png` 逐帧，`tr_*.json` 逐帧包围盒 / 帧差）。
- 几个先说在前面的基础事实：
  1. **全片逐帧都有画（one's）**：抽查 4:43–4:52、7:25–7:30 共 336 帧，帧差没有一帧接近 0 → **没有“冻结帧式”的 hit stop**，打中靠“1 帧闪光 + 字形残留”来停顿。
  2. 背景是纯黑（后段有淡网格），**看不到震屏**（4:4x 的命中帧前后，对手位置连续，推测没震屏）。大招靠**全屏白闪 / 反色 / 黑帧 / 切镜**代替震屏。
  3. 打击特效有“数学含义”：`e^{iπ}` 碰到 `+1` 就变 `0`（闪光后弹出灰色大号“0”），泰勒级数项打中会喷出部分和的数字。**特效的形状 = 这一下的意义**。

## B. 招式词典

阶段帧数一律原生 24fps 帧。**“接触停顿”在本片几乎都是 0 冻结帧，只有 1 帧闪光**，后面单列“残留”帧数。

### B1 飞扑擒抱（Tackle）
- 出现：**4:14.93–4:15.47（f6112–6125）**、**7:20.75–7:21.17（f10567–10577）**、4:37.25（持 `×` 版，f6647–6665）
- 阶段：
  - 预备：7:20.75 版 **4f**（上身前倾 45°，膝弯，胯降到 0.35H，双手收到胸前）；4:14.9 版从画外飞入、无可见预备（推测预备在画外）
  - 出手（空中）：**6–8f**，横移 **2.3H / 11f**（逐帧 0.20,0.16,0.25,0.34,0.19,0.18,0.15H，接触前一帧最快 0.39H）
  - 接触：f6120–6121，**0 冻结**、无闪光
  - 收招：滑行 **3f** 衰减（0.25→0.08→0.03H）后直接转入 B2 锁抱
- 关键姿势：起跳时身体前倾 30°，双臂前伸到头前 0.3H；空中中段**蜷身**（膝收到胸，f6116 身高压到 0.8H）；接触瞬间身体**完全水平**（躯干与地面 0–10°，高度 0.3–0.4H），双臂伸到头前 0.4H 环住对方，后腿伸直拖在后面。
- 拖影：无（靠逐帧大位移）
- 挨打方：被压住、随橙一起滑 0.5H，字形被挤歪；不飞出。
- 效果：无闪光、无震屏。

### B2 锁抱扭打（Grapple）
- 出现：4:15.4–4:16.5（≈26f）、7:21.0–7:22.6（≈38f）、4:37.9–4:38.3（缠斗 6f）
- 节奏：整段是**低幅抖动**：每 2–4 帧换一个小姿势（头左右 0.05H、胯起伏 0.05H），双方贴紧，橙趴 / 跪姿（胯高 0.2–0.3H），双臂环住对方。
- 结束方式（3 次都不同）：
  - e **变形膨胀**甩开（4:16.5：e 展成 `−cos(π)+isin(π)` 长串，橙被弹出画外）；
  - e **挥砍**挣脱（7:22.75：1 帧弧形拖影，橙被向左上抛出约 1.5H、仰面落地）；
  - e **旋转摔**（4:38.0：见 B9）。
- 用在：每次“扑上去”之后都接这个，约 1–1.5s，然后一定被反制。

### B3 武器直刺 / 弓步刺（Thrust / Lunge）
- 出现：橙 `!` 4:10.4–4:10.9；橙 `+1` 4:45.11（f6836 前）、4:52.25–4:52.38（f7004–7010）；橙 i 剑 7:24.0–7:28.6 整段；e `−` 4:43.66–4:43.75（f6801–6805）
- 阶段：预备 **2–5f**（平均 3.5f）/ 出手 **1–2f** / 闪光 **1f** / 收招 **5–6f**
- 关键姿势：
  - 预备：上身后仰 10–15°，持械手收到**肩后 0.15–0.25H、高 0.8H**；重心在后脚
  - 出手：前脚迈出 **0.4–0.5H**，前膝弯（胯降到 0.4H），后腿伸直；手臂完全伸直，**枪尖在胯前 0.8–1.0H、高 0.6–0.7H**；身体前倾 20–30°（7:28.5 的长刺把身体压到几乎水平，胯高 0.3H、枪尖在胯前 1.3H）
  - 后手：击剑式往后上抬到肩后 0.3H、高 0.85H（i 剑段一直保持）
- 拖影：出手那 1 帧有**白色渐变扇形 / 条状拖影**（长 ≈ 武器长 0.4–0.6H），下一帧消失
- 挨打方：见 B11 / B12
- 效果：e 被 `+1` 刺中 → 1 帧放射白光（半径 ≈0.4H）+ 4–6 根细火花线 → 灰色大“0”（高 ≈0.6H）在接触点出现并 **5f** 淡出

### B4 挥砍 / 上撩（Slash / Upswing）
- 出现：e 横砍 4:43.83（f6806）、4:44.16（f6813）；橙上撩 4:45.12（f6836）；e 挣脱砍 7:22.75；Boss ∞ 杆横扫（见 B17）

## F. 编排原则（8–12 条）

1. **没有冻结帧的 hit stop**：所有命中都是“1 帧闪光 + 5–8 帧字形 / 数字残留”，角色继续动。要“停”就用残留物，而不是停帧。
2. **出手只有 1 帧，靠拖影**：预备 2–5 帧、出手 1–2 帧（其中 1 帧有扇形 / 条状白色拖影）、收招 5–6 帧。预备时间约是出手的 2–3 倍。
3. **快拍 5–9 帧一下，3–6 下就停**：连续攻防不超过 6 拍，之后必有 7–22 帧的停顿（悬空、对峙、换武器、压刀）。
4. **停顿有三档**：7–10f（动作中的悬空 / 瞄准）、16–22f（回合间对峙）、≥1s（倒地后 / 捡武器 / 剧情反转）。
5. **主角连攻、对手一击定局**：主角出手次数和命中数都多，但每个回合的结尾是对手的一次反击把主角放倒 / 打飞 / 甩出——回合靠“被反制”来收尾。
6. **反应逐级加重**：同一连击里挨打方反应按 后仰 → 踉跄 → 对折 → 打飞 递进，命中间隔 9–12 帧。
7. **打飞 = 爆发后 ease-out**：前 2–3 帧最快（≈0.5H/f），之后每帧减半，8 帧左右停在障碍物上；身体呈后仰弓形、四肢落后。
8. **倒地时长分两种**：战斗中 3f 倒 + 10f 躺 + 5f 起（直接起成攻击姿势）；剧情性倒地（被 Boss 打）躺 1s、起 3–4s。
9. **扑 → 抱 → 被甩** 是固定三连：扑 6–8f、扭打 26–38f（低幅抖动）、被对手用“变形 / 挥砍 / 旋转摔”反制。
10. **武器即临场拾取**：每一回合开头都先“捡 / 拼 / 改造”一件武器（×、+、+1、弓、f(•)、盾），捡的过程是回合间的停顿；武器升级（+→+1→+1×=）和回合推进同步。
11. **特效有语义**：命中特效与“数学结果”对应（e^{iπ}+1→0；级数项→部分和数字；8πr² 圆柱）。实现时让特效形状由攻防双方属性决定，而不是通用火花。
12. **镜头不跟单拍，只跟回合**：一个回合内机位固定，回合切换 / 位移扩大 / 大招时才拉远、推近或切；命中时不震屏。

### 实现备注
- **每帧都要有新姿势**（one's），不要靠 hold 帧表达停顿；停顿用“残留物淡出 + 角色缓慢的待机微动（每 3–4 帧 0.05H）”。
- 出手帧只要 1 帧，但这 1 帧必须同时有：①武器到最远点 ②拖影 ③（下一帧）闪光。顺序：`预备…预备 → [拖影帧] → [闪光帧] → [残留 ×5] → 收招`。
- 回合模板（≈3–6s）：`拾取 / 对峙 16–24f → 快拍 ×3–6（每拍 5–9f）→ 停顿 7–10f → 快拍 ×2–3 → 对手反击 1 拍 → 倒地 / 打飞 → 起身 5–20f → 对峙`。
- 镜头模板：回合内固定全景（H≈20–25% 画高）；位移超过 2H 时 6–12f 快拉远；拿武器 / 蓄力时推近到 H≈35–45%；命中不震。
