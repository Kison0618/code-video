# Animation vs. Geometry 拆片笔记（创意 / 表演 / 节奏）

- 源：`stick/v1.mp4`（1920×1080，23.98fps，9:16），抽帧时也用了 `p1.mp4` 代理
- **所有时间码都是原片时间**（0:00–0:15 是广告，正片从约 0:15 开始，片尾 THE END 在 9:06）
- 拼图：`study/geo/`。`d2_XXX.png` 是每 0.5 秒一张、每张图 15 秒；`f_XXX.png` 是原片 4–5fps 的细看；`z_*.png` 是放大裁切
- 角色：**橙色火柴人**（主角，下称"小橙"）；**φ**（黄金比符号，被小橙"发现"后成为伙伴/宠物/工具）；**对手**是一个白色线框的高维多胞体投影（像 600-cell 或超立方体的旋转投影，不停翻转、换形状），它吃掉的几何会变成灰色像素化的分形（类似谢尔宾斯基地毯）
- 全片没有一句对白，也没有一个字幕解释概念。屏幕上的字只有**几何标签**：A、B、C、D、角度数、a:b 比值、a²/b²/c²、1+1/(1+…)

**阶梯的规律**
- 维度一路升：0D 点 → 1D 线 → 角 → 2D 多边形/圆 → 定理（关系）→ 3D 多面体 → 高维的对手 → 宇宙 → 回到 0D。
- **每个新概念都先由主角"碰"出来**（拽、转、走、推），然后才出现名字或数字标签。顺序永远是"动作 → 图形变化 → 标签"，从来不先给定义。
- 前 4 分钟几乎每一步都只比上一步多一个零件：一个新点、一条新线、一个新角。

## 2. 创意清单（概念 → 画面 / 道具 / 招式）

格式：**概念**｜变成了什么｜为什么一看就懂（用上了概念的哪个性质）｜出现时长

### A. 基础元素
1. **点**｜宇宙的种子，片头和片尾各一次｜点是"最小、没有大小"的东西，和"开始/结束"天然对应｜0:15–0:21（6 秒），9:01–9:06
2. **点 → 线**｜点像水滴一样被拉长，拖出一条线｜"点运动成线"是课本定义，这里直接演出来｜0:21.5–0:23（1.5 秒）
3. **线是主角的母体**｜小橙从线里鼓起来，像从地里钻出的豆芽｜火柴人本来就是线画的，所以"线里长出火柴人"不用解释｜0:30–0:38（8 秒）
4. **线是地面、是世界的边界**｜他走到端点探头往下看，端点那边是悬崖｜线段有端点，端点之外什么都没有｜0:42–0:59
5. **命名＝认识**｜看清一个端点，它下面就弹出 A 或 B｜几何里用字母标点；"给东西起名字"就是"认识了它"｜A 0:47，B 0:50.5，C 1:00，D 1:14
6. **射线**｜带箭头的线，用法像手电筒、指挥棒、钓竿｜箭头 = 无限延伸，挥动时箭头一直伸到画面外｜1:09.75–1:30（约 20 秒）
7. **交点**｜射线扫过地面，"咔哒"多出一个新点 D｜两线相交得一点｜1:14
8. **角度读数**｜挥射线时度数跟着跳，像速度表｜角 = 两线张开的程度，读数和手势同步，观众自然把"手的旋转"和"数字"联系起来｜1:15–1:30
9. **补角**｜他把射线往地下拧，两侧读数总加起来等于 180｜两个读数一起变，一个大另一个就小，规律自己就显出来了｜1:24–1:29

### B. 黄金比 φ（全片的核心道具）
10. **比值读数 = 寻宝探测器**｜分点跟着脚步走，读数像金属探测器的指针｜比值随位置连续变化，有一个"正确答案"｜1:30–1:52（22 秒）
11. **接近 1.618 时闪金光**｜像"热了、热了"的提示｜φ 是一个特定的值，偏一点就不是｜三次：1:38、1:46.6、1:48.8
12. **φ 降生**｜光柱从天而降，符号 φ 从分点升起，像圣剑出鞘或宝箱打开｜φ 就是"那个比例"，把一个抽象的数变成能站着的角色｜1:52.5–1:58（约 5 秒，全片第一个大高潮）
13. **φ 的身体**｜竖线加一个圈，可以当一个人（竖着站）、一个轮子（躺倒滚）、一个环（套在线上滑）、一根撬棍或钩子｜字母本身的形状就是道具：圈能滚，竖线能抓｜贯穿全片
14. **φ 当宠物/伙伴**｜跟着小橙跑、蹦、转圈、先出主意｜只有"φ"会主动创造新形状，代表"数学之美"在推动发现｜2:00 起
15. **φ 是生成器**｜每次 φ 插手就冒出新几何：斜边、矩形、多边形、螺旋、黄金三角形、黄金矩形、二十面体｜黄金比确实藏在五边形、螺旋、二十面体、十二面体里，所以 φ 能"变出"它们｜全片
16. **φ 的连分数 = 弹药串**｜φ 在线上滚过留下一串圆点，下面展开 1+1/(1+…)，小橙把圆点一个个撸到手臂上，像手镯或子弹带，再发射出去｜连分数是"无限重复同一个结构"，一串一模一样的圆环正好表现"无限个 1"｜4:36–4:43（约 7 秒）
17. **φ 变成独轮车 / 滑板**｜φ 躺下，圈当轮子，小橙踩上去冲坡｜φ 里有个圆，圆会滚｜5:07–5:16，5:48
18. **φ 当钩索**｜φ 拉出一条线挂住，小橙荡秋千、空中转向｜φ 会"拉线"已经演过好几次，这里只是换个用法｜2:12–2:20，5:24，5:46

### C. 2D 图形
19. **线弯折成直角**｜他吊在线上，线以端点为轴向下转 90°｜线可以绕端点旋转，转 90° 就是直角｜2:08–2:12
20. **三角形 = 爬上去的斜坡**｜竖线、水平线再加一条斜线，三边一合就是滑梯或山坡｜三角形是"三条线首尾相接"｜2:20–2:36
21. **两个三角形拼成矩形**｜三角形翻个身贴上去，补成矩形｜两个全等直角三角形拼成矩形｜2:37–2:39
22. **平行四边形、正方形**｜同一个框子被推歪、再扶正｜边长不变、角度变化｜2:39–2:51
23. **他在正方形顶上摔个狗吃屎**｜图形变形时把他"抽走地毯"｜变形的形状就是他的地面，地面一动人就摔｜2:48.5–2:49.5
24. **正 n 边形 → 圆**｜边数一路翻倍，最后辐条像扇子一样收拢，变成圆｜"边数无限多的正多边形就是圆"（极限思想）｜2:51.75–3:02（约 10 秒，速度越来越快）
25. **多边形是仓鼠轮**｜他在里面跑，多边形跟着转，边数一多就越转越顺｜边多 = 更圆 = 滚得更顺｜2:56–3:01
26. **泰勒斯定理**｜顶点沿圆周跑，直角符号一直不变，金光｜"不管顶点在哪，都是直角"，用"动一下但某样东西不变"来证明｜3:02–3:08
27. **勾股定理 = 推箱子**｜三边上的正方形是三个箱子，小橙推倒 a²、拖到 b² 旁边，对面是 c²，冒出 "+" 和 "="｜面积是"块头"，把块头挪到一起比大小最直观｜3:23–3:55（约 30 秒）
28. **面积相等 = 灌一样多的金水**｜两边同时被金色液体灌满，液面一样高｜面积 = 能装多少东西｜3:55–3:58
29. **黄金螺旋 = 过山车 / 逃生滑道**｜φ 把直线掰弯成弧，弧连成螺旋，小橙一路跑进中心，对手被甩在外面｜螺旋向内无限收紧，越跑越小，对手体型大追不进去｜4:48–5:03（约 15 秒）
30. **螺旋中心藏着 φ**｜一层层正方形的最中心有个金色小方块｜黄金螺旋的极限点｜4:52–5:01

## 6. 转场与新点子频率

### 转场手法
1. **镜头推近 / 拉远**：同一个几何画面里推进拉出就换了场景，几乎不用硬切。0:23–0:30 从点推到小橙；1:01 拉远露出竖线；3:28 拉远看三个方块；8:27 推进十二面体内部。
2. **形状变形**：一个图形直接变成下一个（三角形 → 矩形 → 平行四边形 → 正方形 → 多边形 → 圆），中间没有任何剪辑点。
3. **金光闪白**：发现时满屏金色，闪完画面就换了尺度或场景（1:52、3:05、3:16、3:55、5:27、7:56）。
4. **跟着道具走**：跟着 φ 的动作进入下一段，φ 跳到哪儿、拉出什么线，镜头就跟去。
5. **追逐中的空间切换**：跳上线 → 进螺旋 → 冲坡 → 太空 → 五边形，每次都靠一个"掉下去 / 冲出去 / 飞出去"的动作衔接。
6. **爆炸白屏**：8:07 的爆炸、8:16.5 的大爆炸，用白屏重置世界。
7. **缩回原点**：结尾整个宇宙缩成一个点，接片尾字。

- 2:00–3:05：约每 3–4 秒一个（弯折、三角形、矩形、平行四边形、正方形、多边形、圆、泰勒斯）
- 3:05–4:00：约每 10–15 秒一个（勾股定理是一整段慢慢解的谜）
- 4:00–5:55：约每 6–8 秒一个新招（矛、连分数、螺旋、独轮车、坡道、钩索、滑翔翼、菱形）
- 5:55–8:07：约每 10–15 秒一个（五边形堡垒、思考、四面体、八面体、立方体、黄金矩形、二十面体、晶体）
- 8:07–9:06：约每 10–15 秒一个（大爆炸、十二面体、分形、内部宇宙、彩蛋、THE END）
- **全片平均**：正片约 530 秒，收录了约 50 个创意，**平均约每 10 秒一个新东西**，最密的地方 3 秒一个。

## 7. 如果做 Python / 编程题材，可以借用的点子

1. **空屏幕和光标 = 点**：开场黑屏里只有一个闪烁的光标，停 5 秒，然后光标"拉出"一串字符 `print`，火柴人从字母里鼓出来。对应"点 → 线 → 诞生"。
2. **命名就是认识 = 变量赋值**：火柴人走到一个漂浮的值 `42` 旁边，探头看了看，头顶弹出 `x = `，从此这个值有了名字。重复一次 `y = `（重复两次，第二次加料：他戳了一下，值变成 `43`）。
3. **字符串 = 珠串**：字符串是一串字母珠子，火柴人能把它当跳绳、当绳桥，`split()` 时珠子"啪"地断开撒一地，`join()` 时串回去。像 φ 连分数那段，把一串元素撸到手臂上当弹药。
4. **列表索引 = 端点探头**：他走到列表的第一个格子，弯腰探头往外看，下面弹出 `[0]`；走到最后弹出 `[-1]`；再往前一步就是悬崖 `IndexError`（掉下去 = 麻烦即入口，顺势引出异常）。
5. **循环 = 仓鼠轮**：`for i in range(n)` 是一个轮子，火柴人在里面跑，n 越大轮子边越多、转得越快，最后变成光滑的圆。对应正多边形 → 圆的加速蒙太奇。
6. **while 找答案 = 1.618 寻宝**：火柴人推着一个数值滑块，屏幕上实时显示 `abs(x*x - 2)`，越接近 0 越亮，三次尝试（大步错过 → 回头 → 趴下微调），最后 `1.41421` 时金光降下，`√2` 符号升起成为伙伴。同样可以拿二分查找来演。
7. **条件判断 = 岔路口的射线**：`if` 是一根可以转动的射线，转到 True 指向一条路，转到 False 指向另一条路，交点上弹出比较符 `>`、`==`。像角度读数一样实时变化。
8. **函数 = 伙伴角色**：一个 `def` 就像 φ，是个有身体的小角色：括号是手，冒号是眼睛。每次调用它都"变出"新东西；参数一换，变出的东西也跟着换。全片可以由这个伙伴推动新发现。
9. **return = 递回来的宝物**：函数小人钻进一个盒子里忙活，最后从盒子里递出一个发光的值，像 φ 压缩出的金色晶体。
10. **字典 = 带标签的抽屉墙**：一面墙上全是抽屉，抽屉上贴着键名，火柴人拉开 `"name"` 抽屉拿出 `"Ada"`。找不存在的键时抽屉不存在，墙上冒出 `KeyError` 的裂缝。
11. **异常 = 啃食代码的对手**：对手是一团红色的 `Traceback`，它从某一行代码的角落冒出来（先像素化，再钻出来），所过之处代码变成乱码（对应几何被啃成像素分形）。小橙先吓得跌坐，再反击。
12. **try / except = 牢笼升级**：火柴人用 `try:` 搭一个框把异常关住，被吃穿；再加 `except ValueError`，又被吃穿；最后 `except Exception` 加 `finally`，才把它关住。框子一层比一层复杂，对应四面体 → 八面体 → 立方体 → 二十面体。
13. **递归 = 黄金螺旋 / 套娃**：函数调用自己，画面上是一层套一层越来越小的框子，火柴人沿螺旋往中心跑，对手体型太大追不进去；到了中心的 base case 有一个发光的小方块。
14. **调用栈 = 楼梯 / 方块塔**：每调用一次，地上就叠一个方块；return 时方块一个个收回来。栈溢出时方块塔冲出画面顶端坍塌。
15. **列表推导式 = 一气呵成的蒙太奇**：`[x**2 for x in range(10)]` 一行代码一敲，十个方块按 0、1、4、9……依次长高，像勾股定理里灌金水的方块，每 0.3 秒一个，越来越快。
16. **== 判等 = 金水灌满**：两个对象 `a + b == c`，两边同时灌金色液体，液面一样高就是 True，金光一闪；不一样高就是 False，液体溢出来。
17. **类与实例 = 十二面体宇宙**：结尾火柴人钻进一个 `class` 的立方体，里面是一整个世界，到处是实例小人，各自带着不同属性（帽子、颜色），像片尾宇宙里那些火柴人。
18. **import = 召唤**：火柴人写下 `import math`，天上光柱打下来，`π`、`sqrt` 像 φ 降生一样落到他身边成为工具。
19. **None = 空的点**：结尾一切缩回一个 `None` 或一个空光标，变成 "THE END" 里的那个 ∘，和开场的光标首尾呼应。
20. **缩进 = 台阶 / 悬崖**：代码块的缩进是一级级台阶，火柴人往右走一格就下一层；缩进不对时地面断开、他踩空（`IndentationError`）。
21. **切片 = 黄金矩形切一刀**：`s[2:5]` 时字符串珠子被"切出"一段拿起来，剩下的仍是一条完整的珠串，对应黄金矩形切掉正方形后仍是黄金矩形。
22. **生成器 = 连分数弹药串**：`yield` 一个一个吐出圆环，火柴人撸到手上当弹药，能无限吐下去，对应 φ 连分数那串无限的 1。

## 附：可直接复用的"创意机制"总结

1. **先动作，后标签**：概念永远由角色碰出来，然后才出现名字或数字。
2. **把数字变成角色**：φ 从一个比值变成伙伴；任何关键常数、函数、对象都可以长出身体。
3. **符号的形状就是道具的用法**：φ 有圈能滚、有竖能抓。编程符号同理：`()` 是手、`[]` 是笼子、`{}` 是抽屉、`:` 是眼睛、`=` 是桥。
4. **用"动一下但不变"证明定理**：泰勒斯定理里拖动顶点直角不变，勾股定理里挪方块面积不变。
5. **用实时读数做悬念**：a:b 比值、角度数，靠近目标时闪光。
6. **反派吃掉刚学会的东西**：威胁感来自知识被抹掉。
7. **主角升维，反派不变**：观众只追踪主角的新招。
8. **毁灭即创世，结尾回到起点**：一个点开场，一个点收尾。
