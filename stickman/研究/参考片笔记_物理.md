## 0. 一句话结构

一个**没有帽子的橙色火柴人**落在虚空里的白色地面上，从"距离"一路学到"量子引力"。每卡住一次，天上那颗**亮点**就会掉下来一件道具（球 → 绳 → 火箭 → 帽子 → 手电 → 磁铁 → 苹果），他就靠这件道具学会下一条物理。最后他掉进黑洞、从另一头出来，**戴着帽子**遇见过去的自己，才明白道具都是**他自己**隔着虫洞送回去的。整集是一个**闭合时间环**：起点就是终点。

全片分 6 幕：

| 幕 | 时间 | 场景 | 学的东西 | 卡点 → 道具 |
|---|---|---|---|---|
| 1 平地 | 0:00–1:51 | 白色平地 + 星空 | 运动学、力、功、摩擦 | 没东西玩 → **球**（1:09） |
| 2 坡地与树 | 1:51–4:30 | 冰面、山谷、枯树 | 动量、角动量、能量守恒、力矩 | 过不了山谷 → **绳**（1:51、2:41），离不开地面 → **火箭**（3:39） |
| 3 太空 | 4:30–7:08 | 卫星、行星、红巨星 | 推力、光、引力弹弓 | 太慢 → **帽子**（4:43）、**手电**（5:18） |
| 4 加速 | 7:09–9:35 | 星际 → 星系核 | 电磁学、相对论 | 推力不够 → **磁铁**（7:09）、棒、线圈 |

**规律**：
- **一步只加一个量**，而且新量总是**从旧量里长出来**：尺子 → 箭头 → 两个箭头 → Δv → 力 → 力乘位移 → 除以时间。观众始终只需要理解"多出来的那一块"。
- 学会的标志总是**一个动作的结果变了**：第一次荡绳差一点（3:12），第二次拉绳就过去了（3:30）。规则是"失败一次 + 改一个变量 + 成功"。
- 中后段每个公式卡都配一个**正在变的数字**（速度、β、n），观众不用读懂公式，看数字在涨就够了。

## 2. 创意清单（概念 → 画面 / 道具 / 招式）

格式：**概念 → 变成了什么**｜为什么一看就懂（用到了概念的哪个性质）｜时间｜时长

### 2.1 运动学和力（第 1 幕）
1. **参考系 → 没有地面就看不出动没动**｜在纯星空里翻滚看不出速度，地面一出现他就"停"了：运动是相对的｜0:02–0:15｜13 s
2. **距离 → 跟着脚伸长的尺子**｜距离会累加，尺子就跟着长｜0:19–0:25｜6 s
3. **速度 → 尺子变成箭头**｜速度 = 带方向的距离/时间，箭头长度 = 大小，朝向 = 方向｜0:26–0:35｜9 s
4. **位移求和 → 地上一段段 d1…d6 首尾相接**｜位移可加｜0:37–0:45｜8 s
5. **加速度 → v_i、v_f 两根箭头，中间一截 Δv**｜加速度就是箭头"多出来的那段"｜0:51–0:59｜8 s
6. **摩擦 → 全速摔倒，反向小箭头把速度箭头吃掉**｜摩擦力和运动方向相反、让速度降到 0｜1:04–1:06｜2 s
7. **重力 → 天上掉东西 + 弹跳轨迹**｜东西会往下掉，人人都见过｜1:09–1:10｜2 s
8. **重量 → 拿起球时出现 "1 kg" 和向下箭头**｜手上感到的那份"沉"｜1:17–1:19｜3 s
9. **F = ma → MASS / FORCE 两个词依次换掉，合成公式**｜同一个球、同一根箭头换了个名字，表示它们是一回事｜1:20–1:23｜4 s
10. **功 → 举起球时三段竖线（力、位移、功）**｜功 = 力 × 沿力方向的位移，举高最直观｜1:24–1:27｜4 s
11. **功率 → WORK/Δt 分式卡**｜同样的功做得越快，功率越大｜1:28｜1 s
12. **能量损耗 → 一串越来越矮的抛物线，顶点标高度**｜每次弹跳丢一点能量，高度递减｜1:30–1:33｜4 s
13. **摩擦系数 → 地面从白变成渐变灰的冰，人劈叉**｜μ 小 = 站不住，劈叉是最好笑的"站不住"｜1:34–1:50｜16 s

14. **角动量 → 甩绳转球，L = mvr 贴在半径上**｜r、v、m 三个量都看得见｜2:08–2:12｜5 s

### 2.3 太空、光（第 3 幕）

## 3. 对手 / 麻烦

这一集**没有反派**。对手是**物理规律本身**：每条刚学会的定律下一场都会变成拦路的墙。第二条暗线是**"谁在送礼"**，结尾才揭晓。

### 3.1 规律当墙：每次交锋

| 回合 | 时间 | 麻烦怎么出现 | 主角的武器 | 结果 / 升级 |
|---|---|---|---|---|
| 1 摩擦 | 1:04 | 刚学会加速，跑到最快就摔了 | 无 | 输：第一次被物理"打脸" |
| 2 冰面 | 1:34–1:50 | 去追球，地面突然变滑 | 平衡 | 输：劈叉、摔倒 |
| 3 冰面（反用） | 2:17–2:32 | 同一片冰 | 绳 + 球（动量） | 赢：原本让他摔倒的低摩擦，现在帮他滑出去 |
| 4 山谷 | 2:40–3:14 | 镜头拉远，眼前是一道 U 形山谷，对岸跟起点一样高 | 绳 + 树枝（能量守恒） | 输：差一点 |
| 5 山谷 | 3:16–3:31 | 同一道山谷 | 半空拉绳（做功） | 赢：EXCESS KINETIC |
| 6 地心引力 | 3:41–4:24 | 想去天上的火箭 | 滑轮、力矩、单摆抛射 | 赢：飞出卫星 |
| 7 光速 | 5:04–5:17 | β 只有 10⁻⁷ | 推力不够 → 改用弹弓 | 升级：要借天体的引力 |
| 8 恒星表面 | 6:23–6:39 | IMPACT IMMINENT | 拉起 + 贴着飞 | 惊险赢，速度到 1% c |
| 9 失去火箭 | 7:15–7:20 | 自己跳下去抓磁铁，火箭飞走 | 磁铁吸回来 | 自己闯的祸，自己用新知识补救 |
| 10 光速（第二次） | 8:04–8:27 | 还是不够快 | 电磁加速环 | 40% c → 80% c |
| 11 黑洞 | 9:36–11:04 | 苹果掉进去，他**主动**跟进去 | 手电（测红移） | 他不对抗，而是观察：被拉面条、被冻住 |
| 12 奇点 | 11:05–12:01 | 所有标签都失效 | 无 | 穿过去，进入新世界 |

**升级手法**：
1. **尺度一路变大**：脚下一米 → 山谷 → 卫星 → 恒星 → 星系 → 黑洞，而且每一级都用一次**镜头拉远**来揭晓（1:11、2:39、4:25、9:16）。
2. **主动权一路变大**：前期是规律"整他"（摔倒），中期他用规律反制，到黑洞时他**自愿跳进去**（9:45 盯镜头后冲进去）。
3. **同一个障碍打两次**：第一次输，学一样新东西，第二次赢（冰面、山谷、光速都是这样）。

### 3.2 神秘送礼人（隐藏的另一方）
- **第一次露面**：1:11–1:13 镜头拉远，天上有一颗**比别的星都亮的点**。1:53–1:55、3:37–3:40、4:49–4:53、6:53、9:43–9:49 每次道具出现前后，这颗亮点都在。观众会把它记成"天上有人在帮他"。
- **每次交锋**：不是打架，是**投喂**。亮点每丢下一件道具，就解决了上一幕结尾的卡点（没东西玩 → 球；过不了谷 → 绳；上不了天 → 火箭……）。
- **升级**：道具从日用品（球、绳）变成高科技（火箭、手电），再变成一颗恒星（14:45 半透明的人把一个恒星系搬到平台边——原来 6:05 那颗红巨星也是"送"的）。
- **收场**：12:16 戴帽者遇见没戴帽的自己 → 13:29 把绳丢进平台、过去的自己身边就落下一根绳。**送礼人 = 未来的自己**。15:29–15:40 戴帽者走上平台、压压帽檐离开，没戴帽的留下来、手里拿着苹果。环闭上了，结尾也就是开头。

## 6. 转场与新点子频率

### 6.1 转场手法
1. **镜头拉远揭晓尺度**（最常用）：1:11、1:53、2:33、2:39、3:37、4:25、9:16。拉远之后通常直接接下一幕。
2. **跟着道具切镜**：球、绳、火箭、帽子、磁铁都从画外飘进来，镜头跟着道具转到主角身上。
3. **图示化转场**：真实场景淡出，只剩标注和曲线（2:53 势能面积、5:07 γ 曲线、11:52 彭罗斯图），再从图示淡回实景。
4. **白闪**：9:20 进入星系核。
5. **黑屏 + 一个光点**：9:47–9:49，用于"决定"这一拍。
6. **一镜到底钻进去**：11:05–11:27 钻进苹果，11:28 冲出去时世界已经换了。
7. **画风切换代表换宇宙**：12:09 从渲染星空换成**竖线组成的极简世界**。
8. **窗口回放**：13:10 以后虫洞平台里播放第 1–2 幕的旧镜头（雪地、球、树），新旧画面**同框**。
9. **回调式转场**：13:29 丢绳 → 切到 13:31 过去的雪地，绳落在小人身边。

## 7. 如果做 Python / 编程题材，可以借用的点子

> 借用的核心机制：**一次只多一个量**、**学会的标志是动作结果变了**、**同一个障碍打两次**、**天降道具 = 自己未来送的**、**数字本身当包袱**、**尺度一路放大并用拉远揭晓**。

1. **print = 现身**（对应 0:02 白光现身）：黑屏里敲出 `print("hi")`，输出那行字像地面一样升起来，主角掉在上面，第一次有了"站的地方"。
2. **变量 = 跟着长的尺子**（对应 0:19 尺子）：主角每走一步，头顶 `steps = 3` 的数字就滚动 +1；改名 `steps → distance` 时只有标签替换，数字不动（对应 MASS → FORCE 换词）。
3. **类型 = 劈叉笑点**（对应 1:38 冰面）：主角踩到 `"5"` 这块字符串地砖上想做 `+ 1`，脚底一滑劈叉，冒出 `TypeError` 箭头；换成 `int("5")` 才站稳。
