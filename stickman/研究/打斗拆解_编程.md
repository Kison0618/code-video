## B. 动作词典

> 阶段写法：**预备 / 出手(起跳) / 接触停顿 / 收招** = 帧数 @24fps。位移用 H。

### B1. 蹲马步硬扛（Brace）
- 时间码：2:27.80（等 bomb 落地），2:37.23（第 3 颗），5:03.42（扛方块）
- 阶段：预备 4f（2:27.63→2:27.80，从站姿转身面向来袭物）/ 保持 6f（2:27.80–2:28.05）/ 爆炸 1f 小闪 + 1f 满屏光 / 收招 6f（2:28.13–2:28.38 慢慢站直）
- 姿势：两脚横跨约 0.8H，胯降 0.2H；上身前倾 20°，双臂向两侧张开、手比胯低；头缩。
- 被击中：不算被击中，原地不动。
- 打击效果：爆炸 = 小白点 + 一圈放射线（1f）→ 半径约 1.5H 的暖黄光晕铺满（1f）→ 光晕变暗（2f）→ 爆出的 5 个拟声词组成一圈环，慢慢散开（约 8f 后渐隐）。

### B2. 鱼跃扑倒（Dive-prone）
- 时间码：2:35.73–2:35.90（躲 bomb），5:00.43（躲方块下砸），5:10.50（躲方块），5:57.88（扑向电脑）
- 阶段：预备 2f（2:35.73 下蹲 0.15H、上身前倾 45°）/ 起跳 1f / 腾空 2–3f（身体完全水平，离地约 0.3H，双臂伸过头顶，双腿并拢伸直）/ 落地滑行 4–6f（向前滑 0.5–1H，pygame 场有灰色尘土）/ 收招：趴着等爆炸过去，然后 4f 蜷起、6f 跪起
- 姿势：腾空时身体从头到脚一条直线，总长约 1.1H；落地后脸朝下，手先着地。
- 拖影：pygame 场落地时脚后面有灰色尘土粒子（5:10.5、5:01.2）。
- 被击中：2:36.07 爆炸就在他身后约 1H，他趴着被冲成蜷团（2:36.15，膝盖到胸口），再 2f 侧躺，4f 后跪起。

### B3. 原地起跳收腿（Tuck jump）
- 时间码：2:36.53–2:36.75（躲 bomb），5:11.75（跳过方块），5:56.90–5:57.25（跳过方块）
- 阶段：预备 2f（下蹲，胯降 0.2H）/ 起跳 2f（2:36.45→2:36.53 全身伸直、手臂上举）/ 腾空 4–5f（双膝收到胸口，脚跟贴臀，整体缩成约 0.5H 的团）/ 落地 2f（劈叉或宽弓步，胯降 0.3H）/ 收招 3–4f
- 腾空高度：约 0.6–0.8H（推测，随场景缩放）。
- 打击效果：起跳后 2f 爆炸就落在他刚才站的地方（2:36.78），"差一点就被炸到"。

### B4. 低弓步 / 低身冲刺躲子弹（Duck-run）
- 时间码：3:12.37–3:12.92（字母机枪），2:52.0（冲向电脑），3:13.0
- 阶段：预备 1–2f（3:12.33 上身前倾）/ 下压 2f（3:12.42 胯降到 0.35H 高）/ 保持冲刺 8–12f（身体几乎和地面平行，头比胯低）/ 收招 3f 直起

- 拖影：字母子弹自己带 3–4 条白色细速度线（长约 1H），人身上没有。
- 节奏：机枪每发间隔 4–6f，`print(gun.pop())` 白底高亮弹窗和子弹同一帧出现。

## E. 镜头

1. **景别分布（推测，按时长）**：全景 / 远景约 70%（人占画高 1/6–1/4），极远景约 10%（人只是一个点：3:07.8、4:04、4:48.9、5:43），中景约 8%（3:23.2、6:41.7 跑步），特写 / 大特写约 12%（代码、电脑屏幕、球、字母打脸）。
2. **镜头基本不动**：打斗时镜头固定，靠人和物在画面里移动。推拉都是"一级一级"的跳跃式缩放，或者 6–12f 的快速推拉，**没有手持晃动**。
3. **拉远 = 揭示**：每次对手出新招，先拉远一级给出新空间（2:43.7、3:05.7、3:47.5、4:48.5、5:24.5、5:34.6）。4:48.5 那次从全景一直拉到人只剩一个点，露出 pygame 窗口框，是"打击后果"的另一种表现。
4. **推近 = 情绪 / 信息**：被字母射脸（3:36.2）推到中近景；6:02.3 推到代码大特写看 `-`→`*`；5:32.4 球大特写。
5. **被打中那一下镜头怎么动**：普通命中不动镜头；爆炸类命中用**整屏光晕**代替震屏（2:28.09、2:36.11、3:52.78、4:11.875、6:08、6:38.3），亮 1–2f、暗 2–4f；nuke 用 4 格白闪。整段**没有明显的震屏**（推测：可能有 1–2px 的轻微震动，在 960 宽画面里看不出）。
6. **追逐时人在画面哪一侧**：被追时人在**画面前进方向的后 1/3**，前面留空间（锯齿从左追，人在中偏右往右跑，右边留 1/3 空白）；主角冲向电脑时电脑在画面右侧 1/4。turtle 段线总是从画面一边贯穿到另一边。
7. **跟拍**：2:47 上墙时镜头竖直上摇；4:32–4:39 cos 曲线段镜头往右横移（看坐标刻度在走）。6:41.7 中景跑步是"人原地、背景动"。
8. **切镜**：动作中几乎不切；切镜都落在停顿点（切代码、切电脑屏幕），切回来时人已经换了姿势（跳掉"准备"的过程）。

## F. 编排原则（非人形对手怎么打得好看）

1. **代码 = 起手式**。每一招前都有"打字 → 整块高亮 4–6f → 执行"，观众先看到代码就知道要来什么，悬念来自"什么时候来"和"他怎么躲"。高亮框就是对手的"预备动作"。
2. **对手的形状决定招式**：线 → 推、铲、劈、包围；方块 → 撞、砸、挤、当平台；球 → 从上面砸、追、弹；字母 → 机枪；柱子 → 从脚下顶、当梅花桩；曲线 → 当滑道。**先想这个几何体能怎么动，再设计人怎么被它打。**
3. **非人形对手不需要预备姿势，但需要"预警"**：要么是代码，要么是先出现再停一下（方块 4:46.72 出现，0.2s 后才被撞上；蓝球出现后停 1s）。
4. **人被打的方向 = 对手的运动方向**，位移量和对手速度成正比（turtle `fast` 把人挑飞 1.2H，普通速度只推着走）。不加特效也很有冲击感。
5. **每个武器都升级 3 次**：直线 → 拐弯 → 斜劈 → V 形；细锯齿 → 粗锯齿；单颗 bomb → 连发；方块撞 → 方块键控 → 方块 + 球。一招新东西只用 3–4 次就换。
6. **主角 80% 时间在躲或被打，20% 在反击**，而反击几乎都是"借力"：骑在攻击物上、踩着它跳、用一个敌人去挡另一个、抢电脑改代码。**最后的胜利一定来自改代码**（turtle.bye()、`-`→`*`）。
7. **对手的物理是"规则"，主角找规则的漏洞**：柱子每 0.5s 换一次 → 他学会卡节奏跳；追踪球追人 → 他让球和方块撞。观众看懂规则后才会觉得解法聪明。
8. **攻击物也是场地**：turtle 线变成墙和坡，柱子变成平台，cos 变成滑道，TITLE 字变成掩体。同一个物体先打人、再被人利用，不需要额外画背景。
9. **爆炸用光晕 + 拟声词碎片，不用震屏**：小爆 1f 星芒 + 1f 光晕，大爆光晕盖半屏 2f 再暗 4f；碎片是文字（BANG/POW、数字、字母），和"代码世界"统一。
10. **连招之间必须停**：每 3–6 拍停 2–3s（切代码 / 喘气），让观众消化，也让对手"装填"。停顿时主角姿势要清楚（趴着、坐着、蹲着喘）。
11. **"差一点"比"打中"多**：bomb 落在他刚离开的位置，柱子在他跳走后爆炸，球擦着头飞过。打中只留给段落转折点（被推走、被挑飞、撞方块、射脸）。
12. **拉远镜头当"后果"**：大的打击之后不震屏，而是停一下再拉远（4:48.5），让观众看到更大的空间 / 更大的威胁。

**实现提示**
- 24fps 原作是一拍一张（跑步、翻滚都 on ones），用 30fps 输出时按 24 帧做关键帧再插值，不要按 30 帧数。
- 所有"被打"动作都**没有 hit-stop（定格停顿）**：接触只有 1f，然后马上弹开。冲击感来自"弹回 2f 很快 + 后倒 6f 慢下来"的速度差（ease-out）。
- 爆炸光晕：`radial gradient` 暖黄 #FFD27A → 透明，第 1 帧半径 0.3×最大值 + 8–12 条白色放射线，第 2 帧到最大值，后面 2–4 帧透明度线性降到 0。
- "差一点"规则：攻击物命中点 = 主角起跳前的位置，命中时间 = 主角离开后 2–4f。
