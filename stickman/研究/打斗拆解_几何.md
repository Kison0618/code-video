# Animation vs. Geometry：动作戏逐帧拆解

素材是 `stick/v1.mp4`，1920×1080，23.976fps，画幅 16:9（任务描述里写的 9:16 应该是笔误）。
**单位约定**：帧数一律按 24fps 原生帧数计，1f ≈ 0.042s。时间码就是视频时间，前约 15s 是广告，没有减掉。H 指橙色火柴人的身高（头顶到脚底，站直时）。坐标都以胯为原点，x 正方向为"朝向前方"，y 向上。
**方法**：先用 p1 代理按 2fps 粗扫 4:00–8:24。再用 6fps 带时间码拼图逐段确认。关键段用 24fps 原生帧拼图和 `ref_strip.py`（follow/union 两种模式）逐帧看，用帧差和相关系数找切点。所有图存在 `study/fight/geo/`。
**说明**：这部片子里没有拳脚对打。橙色小人始终是弱势一方，对手是体型 3–15H 的白色线框多胞体，伙伴 φ 当工具用（钩子、轮子、武器、滑翔翼骨架）。所以下面的"招式"多半是**用道具发起攻击、闪躲、逃跑、被撞飞**，而不是互殴。

## B. 招式词典

> 每条格式：出现时间 / 阶段帧数（预备 – 出手 – 停顿 – 收招）/ 关键姿势（相对胯，单位 H）/ 拖影 / 对方反应 / 打击效果。

### B1. 惊跳后坐（受惊后仰跳 + 跌坐）
- **出现**：4:02.54（主例，原生帧逐帧）。4:43.3 转身逃跑的前 2f 是同一类反应（推测）。
- **帧数**：先**静止 12f**（4:02.00–4:02.50，蹲着不动，只有 φ 轻微晃）→ 预备 1f（4:02.54，身体缩一下，头低 0.05H）→ 起跳 1f（4:02.58，身体伸直后仰）→ **空中 5f**（4:02.63–4:02.79）→ 落地 1f（4:02.83）→ 摊开 1f（4:02.88）→ **定格 7f**（4:02.88–4:03.17）→ 5f 快速拉远转全景。
- **姿势**：
  - 起始蹲姿：胯高 0.3H，双膝前顶，手搭在 φ 上，手位约（+0.3H, 0.2H）。
  - 空中（4:02.71）：身体整体向后上方位移约（−0.5H, +0.35H）。上身后仰约 30°。双臂张开，手在（−0.4H, +0.6H）和（+0.4H, +0.5H）。双腿收成 90° 屈膝，像"坐在空中"。
  - 落地（4:02.88）：坐在地上，胯着地（y=0）。上身后仰 45°，一只手撑在身后（−0.4H, 0）。腿向前伸出 0.6H。总位移约 −1.0H。
- **拖影**：无。靠 1f 的大姿势跳变和空中 5f 读出速度。
- **效果**：没有闪光。之后切全景，这一下的作用是交代"为什么吓到"。

### B2. 线段延伸戳刺（把手里的线段瞬间伸长当矛捅）
- **出现**：4:14.42、4:20.68、4:21.14、4:21.60，4:12–4:22 之间共约 6–8 次。
- **帧数**（4:20.2–4:22.2 逐帧）：预备 **8–10f**（手举到头侧，线段短短一截贴着头，身体略后倾）→ **出手 1f**（线段从手中瞬间伸到目标，没有中间帧）→ **命中闪光 1f 满亮 + 1f 半透明光晕**（4:20.677/.719）→ **线段保持伸长 5–6f**（一端在手、一端在对手身上，端点有小圆点）→ 收回 3f（线段缩短、淡出）→ 下一次预备。**每次间隔 11f**，非常规律（20.677 → 21.136 → 21.595）。
- **姿势**：
  - 预备：双脚前后分开 0.35H，后脚贴墙角。手（握线段那只）在（+0.1H, 0.85H），也就是头侧、比胯高 0.85H。上身直立或后仰 5–10°。
  - 出手 / 命中：手臂伸直指向右上 45°，手在（+0.3H, 0.9H）。线段沿同一方向伸出 3–6H。脚不动。上身前倾约 10°。
  - 收招：手落回（+0.15H, 0.7H）。另一只手常常护在胸前。
- **拖影**：无。线段本身就是"速度线"，出手帧它整根都在。
- **对方反应**：线框在命中点出现**局部变形**：几根边被顶弯、断开，碎线飞散 4–8f。整体位移很小（< 0.1 个线框直径）。线框不后退，继续往前压，被戳只是"慢了一下"（推测是想表现"打不动"）。
- **效果**：命中点先 1f 白色星形闪光，然后 1–2f 灰白圆形光晕（半径约 1H），再弹出一个白色数字（125、91、157 等），停留约 6–10f 后淡出。**没有 hit stop**，橙和线框在闪光帧都还在动。没有震屏。

### B3. 连分数弹药连发（边退边射）
- **出现**：4:40.36、4:41.28、4:41.78、4:42.28、4:42.70、4:43.03、4:43.28，共 7 发以上。
- **帧数**：瞄准提示 **2f**（手前出现一个小箭头 →，长约 0.4H）→ **出手 1f**（一根细线从手瞬间连到线框）→ **命中闪光 1f 满亮 + 2f 光晕衰减** → 线保持 6–10f，上面标着数字 126/127/106/165/124/142/156 → 淡出。
- **节奏（加速）**：两发之间的间隔依次是 **22f → 12f → 12f → 10f → 8f → 6f**，越打越快。之后放弃攻击，转身逃跑。
- **姿势**：面朝右，**边退边射**：双腿保持走路摆动，一直往左后方退，每步约 4–6f。射击那只手在胸前（+0.15H, 0.65H），另一只手扶着。上身直立、略后仰 5°。最后 4 发（4:42.9 起）步幅加大到 0.6H，上身后仰到 15°，像慌乱后撤。
- **转身逃跑**（4:43.3–4:43.6）：上身从后仰翻到前倾 **2f**（中间有 1f 前后都不像的过渡姿势）→ 双臂甩向后方 → 进入奔跑。
- **对方反应**：线框在命中处凹陷、几根边被打弯，每次 4–6f 后恢复。整体向后位移约 0–0.2 个线框直径，偶尔顿一下。
- **效果**：每发 1f 白星 + 2f 光晕（半径约 0.8H）+ 碎线 4–6 根。没有震屏。

### B4. 惊慌奔跑 / 逃跑循环
- **出现**：4:23–4:32、4:32.5–4:39（追 φ）、4:43.3 起、6:46.9。
- **帧数**：跑步周期约 **8f 一个完整周期（每步 4f）**。按 6fps 看相邻两帧的腿是交替的，推测原生是 2 拍画。
- **姿势**：上身前倾 **45–60°**。头在胯前方（+0.4H, 0.6H）。步幅 0.6–0.7H。后腿蹬直，前腿高抬到膝盖 0.35H。双臂甩到后方（−0.3H, 0.5H）。逃命时手常甩在头上或身后，惊慌感来自"手不协调"。
- **画面位置**：侧面跟拍时人固定在画面 **x ≈ 0.35–0.45W**，背景（数轴刻度）往后滚。追兵从画面右侧进来，占 x 0.65–0.9W。
- **拖影**：无，靠背景刻度移动表现速度。

### B5. 被撞出边缘 / 跌落（无反抗的大位移）
- **出现**：4:49.5–4:51.3：线框推着橙走到数轴尽头，地面消失，橙掉进黄金螺旋。
- **帧数**：线框接近 4:49.5–4:50.8 → 地面消失 4:51.0 → 自由下落、沿螺旋弧线滑行约 **2.5s**（4:51.2–4:53.7）。
- **反应姿势**：身体团成一团，四肢乱挥。下落时镜头连续拉远，人从 0.15 画高缩到约 0.02 画高。
- **效果**：没有闪光。靠"镜头拉远 + 人变小"表现跌落深度。

### B6. 上独轮车（骑乘起步）
- **出现**：5:09.05–5:10.4（φ 横过来当轮子，n_mount 逐帧）。
- **帧数**：静止站立 **6f**（5:08.80–5:09.01）→ 预备深蹲 **6f**（5:09.05–5:09.30，弯腰到前倾约 70°，双手几乎碰地）→ 冲刺 **5f**（5:09.34–5:09.51）→ 跳起上车 1f（5:09.55）→ 落到 φ 上 **3f**（5:09.59–5:09.68）→ 摇晃找平衡 **10f**（5:09.72–5:10.13，双臂张开左右摆）→ 站稳（5:10.4）。共约 38f ≈ 1.6s。
- **姿势**：预备时胯降到 0.35H，头降到 0.55H，上身几乎和地面平行。冲刺时前腿迈出 0.5H。上车后两脚并在 φ 上，胯高 0.55H（比站立时高出一个轮子的高度，约 0.15H）。平衡时双臂伸到（±0.45H, 0.75H），左右各摆一次，每次 4–5f。
- **拖影**：无。

### B7. 骑乘冲坡 / 飞越
- **出现**：5:13.0–5:15.2（φ 独轮车冲出平台、落到 67° 斜坡上）。
- **帧数**：前倾加速 4f（5:12.9–5:13.1）→ 冲出边缘、后仰离地 **8f**（5:13.13–5:13.47，身体后仰约 30°，双臂往后甩）→ 空中前翻调整 6f → 垂直贴墙下落约 6f（5:13.9–5:14.1）→ 着陆斜坡，压低重心 3f（5:14.3）→ 低姿俯冲下坡（上身贴近车，胯 0.4H，头前伸 0.35H）。
- **效果**：没有闪光，地面角度直接标着"67°"。

### B8. 钩索射出 + 被拽走
- **出现**：5:18.98（太空）、6:38.23（金字塔下）、6:47.2（φ 当吊钩）、6:58.4（牢笼边）。
- **帧数**（5:18.3–5:19.7）：骑乘待机 16f → **甩臂预备 2f**（5:18.98–5:19.03，手臂往后、头往前探）→ **出手：钩索线伸长 5f**（5:19.11–5:19.28，线逐帧变长，端点是 φ）→ 绷紧 1f → **镜头快速拉远 9f**（5:19.32–5:19.70），人被线拖向远处。
- **6:38 版**（n_roll 末尾）：φ 抓住橙 → 线段射出 **1–2f**（6:38.18–6:38.23）→ **身体被猛拽 1f**（6:38.27，双臂前伸，腿甩在身后）→ 拖走时镜头拉远 **6f**（6:38.31–6:38.56）。
- **吊起版**（6:47，n_hang）：跑 6f → 停下伸手抓 φ **5f**（6:47.23–6:47.40，身体下蹲 0.2H）→ **被提起 1f 拉长**（6:47.48：全身竖直拉长到约 1.3H，四肢收成一束，这是全片最明显的 **smear/拉伸帧**）→ 甩到挂好 4f → 挂着时腿荡 6–8f → 收腿蜷起（6:48.1）。

### B9. 荡绳绕圈
- **出现**：5:24.5–5:27.5（太空，φ 当锚点，绕圆周甩动）。
- **帧数**：一圈约 **24–28f**（从 5:25.4 到 5:26.5 绕了约 1.1 圈）。φ 端点沿圆周走，每帧转约 13–15°。
- **姿势**：橙在圆心附近，手握线、身体向离心方向倾斜 30–45°，腿甩开 0.5H。画面上会叠一个圆形和扇形角度标记（数学可视化）。
- **结尾**：转到第 3 圈时 5:27.5 爆金光（满屏黄光约 4f），φ 变成三角形滑翔翼。

### B10. 滑翔翼飞行 / 空中闪躲
- **出现**：5:28–5:43。
- **姿势**：双手吊在三角翼下，身体竖直下垂（胯在手下方 0.5H）。转向时身体甩到 30–60°，腿甩开。闪躲时整个滑翔翼斜切 45°，大约 6–10f 一次。
- **镜头**：远景，人只有 0.03–0.08 画高。线框从画面边缘冲进来，占 0.3–0.5 画高，体型对比约 10:1。

### B11. 被撞飞（空中）
- **出现**：5:39.84（线框正面撞上滑翔翼）。
- **帧数**：线框冲进画面 **5f**（5:39.63–5:39.80，从右往左变大）→ **碰撞 1f**（5:39.84：撞击点灰白光晕 + 碎线）→ 光晕和碎线持续 **8f**（5:39.84–5:40.17）→ 橙打转着往左下方飞 **约 24f**（5:39.9–5:40.9）→ 飞出画面。
- **位移**：约 6–8H（远景下按人的身高估算，推测）。转速大约 **每 4f 转 90°**。
- **效果**：没有白星，只有一团雾状光晕（半径约 3H）+ 20 根以上碎线向外飞散。没有震屏。

### B12. 金光变身冲撞（主动撞碎）
- **出现**：5:43.09–5:44.4。
- **帧数**：金色光晕亮起 2f（5:43.09–5:43.13）→ **满亮 4f**（5:43.13–5:43.26）→ 衰减 6f（5:43.30–5:43.51）→ 冲向小四面体 **6f** → **撞击 1f 白星**（5:43.76）→ 碎线 4f → **第二下撞击 1f 白星**（5:44.18）→ 碎片飘散 8f。两次撞击相隔 **10f**。
- **效果**：白色星芒闪光（半径约 1H）+ 灰白光晕 3f + 大量碎线向四周飞。被撞的小四面体直接碎掉，没有击退过程。

### 统计
- **出手（接触/发射）帧**：几乎总是 **1–2f**，B2、B3、B8（钩索拽人）、B16 都是这样。没有中间帧，或者只有 1 张。
- **预备**：攻击类 **2–10f**（快攻 2f 箭头预告；戳刺 8–10f）。全身动作 **6f**（上独轮车深蹲、举箱推 4f）。
- **一拍平均**：密集交锋时 **8–12f 一拍**（戳刺固定 11f，连射从 22f 加速到 6f）。全身大动作一拍 **20–40f**。
- **停顿 / 闪光**：命中闪光固定是 **1f 白星 + 1–2f 光晕**。没有传统格斗那种全画面冻结（hit stop = 0）。"停顿"放在**动作之间**：惊跳前静止 12f、跌坐后定格 7f、翻滚落地后定格 10f、举箱后站立 12f、掷出后随势 22f。
- **停顿频率**：约每 **2–4s** 有一次 7–24f 的定格或空镜。大段落之间有 1–3s 的空镜或远景缓冲（如 5:41.0）。
- **攻防交替**：不是你来我往的对攻，而是 **"橙连续小攻击 N 下（对手没什么反应）→ 对手一次大压制 → 橙逃跑/换场地"** 的循环。攻防比例约 1:3（橙的大部分时间在逃）。

- **什么时候推近**：

## F. 编排原则（从数据总结）

1. **出手 1 帧、预备和收招很长**：所有攻击的接触帧都是 1–2f（线段瞬间伸出、子弹瞬间连线、掷出只隔 1 张）。速度感完全来自"前后姿势的跳变"，不靠中间帧或拖影。
2. **打击 = 1f 白星 + 1–2f 光晕 + 碎线 + 数字**，没有 hit stop、没有震屏。这套效果在 B2、B3、B12、B17 里一模一样，是统一的"打击贴图"。
3. **停顿放在动作之间**：每次大动作之前静止 6–12f（惊跳前 12f、上车前 6f），之后定格 7–22f（跌坐 7f、翻滚落地 10f、举箱 12f、掷出 22f）。
4. **重量 = 预备时长**：轻攻击预备 2f，戳刺 8–10f，举箱 4+6f，举晶体 8+8f。越重越慢，出手却一样快。
5. **连续攻击用等距或加速节拍**：戳刺严格每 11f 一下；连射从 22f 加速到 6f 后放弃。加速节拍 = 慌乱 / 绝望。
6. **弱者打强者，对手几乎不受击退**：小攻击只造成局部变形（< 0.2 个对手直径），把"打不动"表现出来。真正的击退只留给终结技。
7. **攻防不对称循环**：小攻击 N 次 → 对手一次压制 → 逃跑/换场地 → 用新道具再来。逃跑和环境互动占的时间比攻击多。
8. **道具即招式**：φ 依次变成轮子、钩子、滑翔翼、捕网、晶体，每换一次场地就换一种用法。每段动作戏的"招式"由场地和道具决定。
9. **大位移用镜头而不是用人**：被撞飞、被拖走、跌落时，人的姿势很简单（团身或四肢张开），位移感由 5–9f 快速拉远或长时间拉远来完成。
10. **追逐时人在左 1/3 往左跑，追兵从右侧压进来**。远景里体型对比 3–15 倍，是主要的威胁感来源。
11. **高潮 = 很慢的准备 + 一次爆发 + 白屏**：最后一击 4.7s 准备、2f 出手、22f 随势、38f 飞行、12f 白屏、2f 速度线。普通攻击都不用速度线，速度线只留给终结技。
12. **拉伸（smear）只用一次**：被 φ 猛然提起时全身拉长到 1.3H，只有 1f（6:47.48），用在"被外力瞬间拉走"这种时刻。

### 实现备注
- **打击贴图要统一**：白星 1f（8–12 根放射线，r = 0.6–1H）→ 灰白径向渐变光晕 1–2f（r = 1–3H，透明度从 0.8 降到 0）→ 4–20 根随机白色短线，沿径向飞散 4–8f，速度逐帧减慢。
