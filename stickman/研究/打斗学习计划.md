# 打斗学习计划（第 5 轮）

> 目的：下一部要有打斗。学完必须留下能复用的东西，而不是"看过一遍"。

## 学完要留下的东西

| 产出 | 放哪 | 以后怎么用 |
|---|---|---|
| 三集打斗的逐帧拆解（段落、招式、节奏、镜头） | `研究/打斗拆解_*.md` | 写打斗戏时查 |
| **招式词典**：每个招式的阶段帧数、关键姿势、挨打方反应、打击效果 | `analysis/fight_moves.json` + `研究/招式词典.md` | 动作代码直接读里面的帧数和姿势 |

| 打斗动作库 + 编排器 | `render/src/fight.js` | 写"谁在第几拍做什么"，自动生成动作、打击停顿、镜头 |
| 演示打斗 + 动作条对比 | `render/src/scene_fight_demo.js` | 证明动作和原片节奏一致；以后改动作先在这里验证 |

## 怎么学

1. **找段落**：从 `研究/参考片笔记_*.md` 里挑出打斗段（数学集 4:09–5:15、7:19–11:30；几何集 4:08–8:07；编程集 2:39–3:32、4:40–6:04）。
2. **逐帧拆**：用 `analysis/ref_strip.py` 以原生帧率拉动作条，每个招式数帧：预备 / 出手 / 接触停顿 / 收招；挨打方的反应类型和帧数；打击效果（闪白、震屏、停顿帧）。
3. **统一格式**：三集用同一张表的格式记录，才能合并成一份招式词典。
4. **量化成参数**：帧数换成秒（24fps 原片），姿势用"相对胯、以身高 H 为单位"的坐标描述，和我们的动作系统一致。
5. **实现 → 对比 → 修正**：做出动作后用 `move_frames.js` 出同格式的动作条，和原片并排看，差距大的再改。
6. **沉淀**：结论写进拆解 / 手册 / 交接 / 迭代记录，推送。
