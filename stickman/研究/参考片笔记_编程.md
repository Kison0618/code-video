- 素材：`stick/v3.mp4`（1920×1080 30fps），代理 `stick/p3.mp4`（480×270 10fps）。
- 抽帧拼图在 `study/code/`：`scan_*.png`（每 2 秒一张，按分钟）、`d2_*.png`（2fps，每张 15 秒）、`f5_*.png`（5fps 细看）、`h_*.png`（原片 4fps 高清拼图）、`hr/t_*.jpg`（原片单帧，读代码用）。
- 时间码一律是原片时间（m:ss.s）。代码尽量逐字照抄屏幕；看不清的地方标"…"。
- 画面右上角的"火柴人AlanBecker bilibili"是转载水印，和原片无关。

## 0. 一句话结构

| 幕 | 时间 | 内容 | 麻烦从哪来 |
|---|---|---|---|
| 第一幕：学 | 0:00–2:27 | 醒来 → 光标 → print → 变量 → 运算 → 字符串 → 下标 → for → while → 布尔/else | **自己写的代码**（报错会"打人"，死循环会把人淹掉） |
| 第二幕：打 | 2:27–6:52 | 笔记本**自己开始写代码**攻击他：bomb 列表 → turtle → 字母子弹 → matplotlib → 递归 fire → pygame 方块/球；他偶尔抢回电脑反击，最后写 `nuke` | **电脑（笔记本）本身**，后来代码里明确叫它 laptop |

核心设定：**黑底即编辑器，代码就是世界的物理规则；print 出来的东西是实体；报错是会打人的红色能量；笔记本是一个角色。**

## 3. 麻烦 / 对手

### 3.1 来源的转移

1. **0:18–2:23 麻烦全是他自己写出来的**：报错（NameError → TypeError → SyntaxError → IndentationError）每次都化成红光打人；死循环（bark → BARK → 1234）把人淹掉。
2. **2:23–2:27 转折**：他把尖叫 `RRRAAAA` 打印出来，被这根字条载着离开电脑。人和电脑一分开，电脑就开始自己写代码攻击他（2:27 第一颗 `*bomb`）。2:29 的拉远镜头专门交代"没人碰电脑，电脑在打字"。
3. **对手就是笔记本**：结尾代码里写着 `#define Memory Model for laptop`、`laptop_say = …render(predicted_word…)`，又把他叫作 `yellow`（`yellow.get_pos()`）。对手全程不露脸，只通过光标、打字和它写出来的东西出现。
4. **3:36 加码**：哪怕电脑在他怀里，它也能自己打字、对着他的脸开枪、从他手里挣出去。

### 3.2 升级阶梯（对手那一方）

| 级 | 时间 | 武器 | 怎么升级 | 怎么解决 |
|---|---|---|---|---|

### 3.3 最终解决

## 8. 原片没用、同一机制可以用在别的 Python 概念上的点子

机制回顾：① 输出是实体；② 改字面量 = 世界实时变化；③ 报错是打人的红光；④ 求值过程叠加在代码上；⑤ 参数 = 物理属性；⑥ 对手写代码，主角改它的代码反击。

1. **字典 `dict`**：主角写 `doors = {"red": "lava", "blue": "exit"}`，场景里出现两扇门，门上挂着键名标签。`doors["green"]` → `KeyError`，红光从一扇不存在的绿门的位置射出来。改成 `doors.get("green", "wall")`，绿门的位置变成一堵安全的墙。
2. **列表切片 `[::-1]`**：对手用 `bullets = list("ABCDEF")` 一颗颗射击。主角写 `bullets = bullets[::-1]`，子弹在半空掉头飞回去。`bullets[2:4]` 只留中间两颗，其余凭空消失。
3. **`try/except`**：主角预料到会报错，写 `try: ... except TypeError:`。报错的红光射出来时，`except` 那一行展开成一面透明护盾挡住，红光碎在盾上。忘写具体类型、写成裸 `except:`，护盾大到把好东西也一起挡掉（输出也被吞了）。
4. **自定义函数 `def`**：主角把一串跳跃动作写成 `def jump(): ...`。之后只要打 `jump()`，身体就执行那一串动作。后面写 `for _ in range(3): jump()`，三连跳。函数名打错 `jmup()` → NameError 把他打趴。
5. **递归与基线条件**：写一个忘了 `if n == 0: return` 的 `def clone(n): clone(n-1)`。分身越来越多、越来越小，直到 `RecursionError` 红色字条把画面塞满。加上基线条件后分身在第 3 个停住。
6. **类与实例 `class`**：主角写 `class Robot:`，什么都不发生（只是图纸，场景里出现一张蓝图）。`r = Robot()` 才从蓝图里"打印"出一个机器人。再 `r2 = Robot()`，两个一模一样。改 `r.color = "red"`，只有一个变红。
7. **继承**：`class FlyingRobot(Robot):` 让蓝图上长出翅膀，原来的方法全部保留。子类里重写 `def attack(self)`，同一个按钮打出不同招式。
8. **`import` 现场装备**：主角缺工具，打 `import math`，一个工具箱掉到身边。`from math import pi` 只掉出一个发光的 π，可以当飞盘扔。`import antigravity` 让他飘起来（Python 彩蛋）。
9. **`input()`**：程序运行到 `name = input()` 时，整个世界冻结，只有闪烁的光标等着。对手和主角都卡住，谁先打字谁赢；打出的名字变成场景里的门牌。
10. **`random.choice`**：一个旋转的轮盘，上面贴着列表元素。对手写 `attack = random.choice(["fire","ice","miss"])`，轮盘停在 `miss`，炮哑火。主角写 `random.seed(42)` 锁死随机数，之后每次都能预判。
11. **文件读写**：`open("save.txt", "w")` 在空中打开一个抽屉，`write("checkpoint")` 把当前场景压缩成一张卡片塞进去。之后被打死，`read()` 把卡片抽出来，世界回档。忘了 `close()` 抽屉一直开着，东西往外漏（或者用 `with` 自动关上）。
12. **布尔短路 `and` / `or`**：一座由 `if A and B:` 组成的桥。A 为 False 时，B 那一节桥根本不会被铺出来（短路），对手放在 B 上的陷阱失效。
13. **`range(start, stop, step)` 当台阶**：`for y in range(0, 100, 20)` 生成一级级台阶；改 step 为 50，台阶间距变大跳不过去；step 负数，台阶反向往下延伸。
14. **`del` 和垃圾回收**：主角 `del monster`，怪物不会立刻消失，只是脖子上的名字标签被剪断。几秒后一辆小清扫车（GC）开过来把没有标签的东西拖走。另一个变量还指着它（`m2 = monster`），清扫车绕道走。
15. **可变对象 vs 不可变对象**：`a = [1,2]; b = a; b.append(3)`，两个名字标签贴在同一个箱子上，往 b 里丢东西 a 也变。换成元组 `(1,2)` 去 append，`AttributeError` 弹回来。
16. **`lambda` + `map`**：对手射来一排字母，主角写 `map(lambda c: c.lower(), bullets)`，一道光扫过子弹列，大写子弹全部变成"小写"（尺寸变小、杀伤力变弱）。
17. **生成器 `yield`**：对手的弹药库是 `def ammo(): while True: yield ...`，看起来无限，但每次只取一发（要 `next()` 才出一颗）。主角发现不 `next` 它就不开火，于是偷走 `next` 键。
18. **`assert`**：主角在桥头写 `assert weight < 100`，对手的大方块想过桥，桥头的断言亮红光把它弹回去（AssertionError 当成守门员）。
19. **字符串格式化 f-string**：`f"{hp}"` 让头顶出现血条数字；对手的攻击把 hp 改小，数字在花括号里实时变化。主角把 `{hp}` 改成 `{hp*10}`，只是显示变大、实际没变，被打一下照样倒（"显示不等于状态"的笑点）。
20. **`sorted` / `sort`**：一地散乱的数字碎片（像原片核爆后的废墟），主角一句 `sorted(debris)`，碎片从小到大排成一条楼梯，他踩着走上去。
21. **`global` 与作用域**：函数里改变量，只在一个透明气泡里生效，出了气泡世界没变。加上 `global` 关键字，气泡破掉，改动泼到整个场景。
22. **`time.sleep`**：主角写 `time.sleep(3)` 想等对手过去，结果连自己也冻住 3 秒（一个 3、2、1 倒计时浮在头顶），对手趁机打他。
