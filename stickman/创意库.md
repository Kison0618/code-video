# 创意库：知识怎么变成画面、道具、招式

> 来源：四集参考片的逐段笔记（`研究/参考片笔记_*.md`，时间码都在里面）+ 我们自己做过的片子。
> 用法：写剧本前，先按第 1 节的流程给每个知识点想用法，再到第 3 节查有没有现成的点子，最后看第 6 节别重复用过的。
> 标注：〔编〕编程集 〔数〕数学集 〔几〕几何集 〔物〕物理集 〔我〕我们想的；✓ = 我们已经用过（片名）。

## 1. 想点子的流程

1. **列出这个知识的性质**（不是定义，而是"它会做什么"）：`list.pop()` → 从尾巴弹出一个；`while True` → 永远不停；`*` 解包 → 一个变很多。
2. **把性质直接演成物理行为**：弹出 = 开枪〔编〕；永远不停 = 洪水 / 无限柱〔编〕〔数〕；解包 = 手雷炸开〔编〕。观众看到动作就懂知识，**不需要任何字幕**。
3. **决定它在故事里当什么**：武器、地形、障碍、载具、伙伴、对手、门。
4. **先碰出来，再给名字**〔几〕：角色先做动作、东西先变化，最后才弹出标签。
5. **学习段埋，战斗段收**〔数〕〔几〕：前面学会的东西，后面变成关键招式（我们 v2：前面学 `"#" * i` 搭楼梯，后面用 for 砌墙）。
6. **检查"一看就懂"**：只看画面、不看代码，能不能猜出这段代码在干嘛？不能就换。

## 4. 对手 / 麻烦的设计模式

1. **麻烦是主角自己造的**：自己写的 while True〔编〕、自己算出来的 -1 的另一副面孔〔数〕、刚证明的定理被啃掉〔几〕。✓ v2 hi 长蛇。
2. **对手出现在知识攒够之后**（1:40–2:30），前面是安静的探索。
3. **先演反应，再给原因**〔几〕：主角先吓得跌坐，镜头才拉远看到威胁。
4. **对手的招式都是它的真实性质**〔数〕：乘 i 是 L 形光门、泰勒级数当弹幕、自我替换复制成大军。
5. **主角升级、对手不变**〔几〕：观众只追踪主角的新招。
6. **用对手的东西打对手**〔编〕：调用它写的函数、改它代码里的一个字符。
7. **主角和道具的距离就是剧情状态**〔编〕：电脑在手里 = 他掌控，脱手 = 电脑掌控，平静地捧着 = 和解。
8. **收尾是和解 / 转化，不是消灭**：并肩坐 30 秒〔数〕；炸成新宇宙〔几〕；电脑学会说 `hello yellow`〔编〕；✓ v2 蛇驯服成宠物。
9. **用重复串起全片**：三次 hello（NameError → SyntaxError → hello yellow）〔编〕；L 形门出现 4 次，最后一次用来告别〔数〕。

## 6. 节奏数字（实测）

- 学习段：约 **每 7 秒一个新概念**，最密 3–4 秒一个。
- 战斗段：每件武器 30–60 秒，内部 2–4 次升级，约每 8–10 秒一个新变化。
- 每个大发现："慢慢靠近 → 金光 1–2 秒 → 余韵 1–3 秒"〔几〕。
- 报错是重音：每 20–30 秒一次〔编〕。
- 高强度动作中插 1–3 秒的静止镜头换气〔编〕。
- 情绪最重的地方给最长的停顿（数学集并肩坐 30 秒）。
- 体检会报"连续 5 秒没有新事件"（`tools/qa.js`）。
