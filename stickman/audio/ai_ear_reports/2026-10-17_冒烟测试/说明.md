# AI 耳朵冒烟测试（2026-10-17）

> 这是声音**类别 / 匹配**的辅助判断，不是听感质量评分。模型只告诉我们"它认为这是哪一类声音、有多确定"，好不好听、味道对不对，仍以人耳为准。

## 测了什么

- **模型**：PANNs Cnn14（AudioSet 527 类，32 kHz）。权重 `Cnn14_mAP=0.431.pth`，来自 Zenodo 10.5281/zenodo.3987831，CC-BY-4.0。大小 327,428,481 字节，MD5 `541141fa2ee191a88f24a3219fff024e`，和 Zenodo 公布的一致。用 `torch.load(..., weights_only=True)` 安全加载，`load_state_dict(strict=True)` 全部键都对上。
- **运行环境**：仓库外的独立虚拟环境，官方 CPU 版 torch 2.14.1+cpu，没有 CUDA 包，4 核 CPU。一次报告 5–9 秒。
- **原片**：《火柴人 VS 编程》本地文件，各类声音的时间点见 `成对_*.json`，和 `analysis/ref_times.json` 一致。另外补了两处：爆炸 156.8 秒、turtle 画线 197.5 秒，都对照画面确认过。
- **合成**：当前 `audio/sfx.py` 生成的同类声音，以及样片音轨 `render/out/sfx.wav` 的 8.5–13.5 秒。
- **入库内容**：只有数字报告，不含任何音频，也不含权重。

## 结果

| 文件 | 内容 |
|---|---|
| `成对_平铺.md/json` | 12 组"原片 vs 合成"，短片段用平铺处理（默认） |
| `成对_补静音.md/json` | 同上，短片段补静音（作对照，说明为什么不用这种办法） |
| `时间轴_原片14-19秒.md/json` | 原片敲 hello、报错这一段，2 秒窗口、0.5 秒步进 |
| `时间轴_样片8.5-13.5秒.md/json` | 样片同一段剧情（敲 hello、报错、删除） |

### 1. 工具本身的限制（已经处理）

- **输入太短会塌**。Cnn14 用 10 秒片段训练，经过 6 级下采样，1 秒的输入只剩约 3 个时间步。0.04–0.4 秒的短音效补静音到 1 秒后，8 类声音的输出完全一样（Music 0.14 / Speech 0.05 / Vehicle 0.03），和 1 秒静音的输出余弦为 1.000。
- **处理办法**：
  - 短片段默认改为"平铺"：只取有声部分，每 80 ms 重复一次，铺满 2 秒。
  - 报告里会自动对比"同样长度的静音"，余弦 > 0.98 标成"≈先验，无信息"。补静音那份报告里，16 个短片段中有 15 个被标出来。
  - 最高置信度 < 0.2 标成"弱"。
  - 时间轴窗口用 2 秒。
- **平铺的代价**：重复本身会带来节奏感，可能把结果往 Music 一类推。比如单个脚步平铺后，原片和合成都被认成 Music / Synthesizer。

### 2. 关于我们音效的线索（类别层面）

- **键盘声被认成枪声**：样片 8.5–10.5 秒（敲 `hello`，末尾含运行和报错）的窗口是 Music 0.33 / **Machine gun 0.22** / Gunshot 0.14；覆盖连续删除（12.0–12.45 秒）的两个窗口是 **Machine gun 0.75–0.81 / Gunshot 0.63–0.70**。原片同类段落没有出现枪声类。按 1 秒窗口那次的试跑，原片打字段是 Computer keyboard / Typing / 相机快门，但置信度都只有约 0.06，属于弱证据。这条值得优先用耳朵确认：合成键盘声可能太冲、低频闷点太重。
- **合成音普遍偏"乐器 / 电子"**：平铺后，原片的界面音多被认成拟音类（键盘 → Scratch；选中 → Camera / Scissors；碰代码 → Zipper / Plop；报错 → Plop / Whack / Whoosh）。我们的同类声音更多被认成 Music / Musical instrument / Synthesizer。这和"原片是处理过的真实录音"的判断一致，支持键盘、选中、报错优先换成真实素材，再用耳朵比较。
- **报错**：原片 16–19 秒（回车的"啵" 17.44 秒 + 变红 18.10 秒）的窗口是 **Plop 0.71–0.85**、Whack / Whoosh；样片对应的窗口（运行 10.0 秒 + 报错 10.15 秒）是 Whoosh / Music / Bow-wow。类别不一致，但两边窗口里都不止一个声音，只能当线索。
- **比较一致的**：电脑落地（类别向量余弦 0.94）、单个脚步（0.96，但这两个都是平铺后的结果，参考上面的代价）。
- **爆炸**：两边都落在枪炮 / 爆炸一类。原片是 Fusillade / Gunshot / Boom，原片片段里叠着配乐；合成是 Artillery fire / Gunshot / Explosion。类别向量余弦只有 0.31，主要因为原片带配乐（Music 0.66）。
- **turtle 画线**：合成被认成 Rub 0.74 / Sanding 0.70（摩擦、砂纸）。原片片段被配乐盖住（Music 0.86），这一组没有可比性。

## 下一步（需要用户决定，这一轮不做）
