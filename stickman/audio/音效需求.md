# 火柴人系列 · 音效需求

> 机器可读版本：`音效需求.json`（内容和本文件一致，由同一份数据生成）。你那边的程序可以直接读 JSON。

## 交付方式

- **folder**：每个声音放进 stickman/audio/samples/<id>/ 文件夹（文件夹名就是下面的 id）。同一个 id 放多个文件 = 多个变体，管线会轮流、轻微变调地使用，避免机关枪效应。
- **format**：WAV，48 kHz，24 bit（16 bit 也行），单声道或立体声都可以
- **sync**：起音放在文件最开头（前面不要留静音），管线按"文件第 0 ms = 画面事件那一帧"放置
- **level**：level_peak_dbfs 是原片同类声音的峰值（256 点 RMS 的最大值）。你按自己的听感做就行，管线放进去时会自动把峰值对齐到这个值，所以各声音之间的比例和原片一致
- **fallback**：某个 id 的文件夹为空或不存在时，自动用代码合成的版本，不会报错
- **license**：如果用了第三方素材，请确认可以用于商业作品

## 代码界面

### `key` 普通按键

- 用在：敲代码时每一个普通字符
- 对齐：手指点下键盘的那一帧（画面里手往下点、电脑微震）
- 时长：90–140 ms
- 性格：机械键盘或笔记本键盘的"嗒"，清脆、短，有按下和松开两个小瞬态；轻、细，偏中高频
- 避免：不要冲击感太强、不要低频重击——AI 耳朵把现在的合成版认成了"枪声 / 机关枪"
- 目标峰值：-18.7 dBFS（管线自动对齐）
- 变体：8 个
- 原片参考：原片实测：约 130 ms，主峰 2296 Hz、频谱重心约 3.4 kHz；按下 → ~20 ms 触底 → ~60 ms 松开；另有 87 / 1101 / 1453 / 3738 / 8050 Hz 共振

- 对齐：同上
- 时长：100–160 ms

- 避免：同上
- 目标峰值：-19.5 dBFS（管线自动对齐）
- 变体：4 个

- 对齐：同上
- 时长：110–170 ms
- 性格：比普通键更重、更确定的一下
- 避免：同上

### `key_back` 退格 / 删除

- 用在：删除字符（可能连续快速很多下）

- 时长：80–130 ms

- 避免：连按时像枪声
- 目标峰值：-19.5 dBFS（管线自动对齐）

### `tab` Tab 键

- 用在：按 Tab 把一行代码缩进（整行往右一挪）
- 对齐：手指按下 Tab 的那一帧
- 时长：100–160 ms
- 性格：比普通键稍大、稍闷的一下"哒"（大键），后面可以带一点点很轻的"嗖"表示整行滑过去
- 避免：不要像回车那么重
- 目标峰值：-17.0 dBFS（管线自动对齐）
- 变体：2 个
- 原片参考：原片没有这个声音（我们新加的），参照普通按键和回车之间

### `interrupt` Ctrl+C 强行停止

- 用在：角色按下 Ctrl+C 停止死循环（全片最关键的一下按键）
- 对齐：手指按下 C 的那一帧（Ctrl 在它前面约 0.12 秒，时间表里是两条 key + 这一条）
- 时长：150–400 ms
- 性格：一下很果断的按键 + 紧接着一个"咔哒"的锁定感 / 电路切断感，短促有力
- 避免：不要做成爆炸，后面紧跟报错音和整个世界定住的安静
- 目标峰值：-10.0 dBFS（管线自动对齐）
- 变体：1 个
- 原片参考：原片没有这个声音（我们新加的）

### `scratch` 挠头

### `recoil_slide` 后坐力滑行

- 用在：特效样片：角色被反冲力推得脚底擦地往后滑
- 对齐：滑行开始
- 时长：300–700 ms
- 性格：鞋底擦地的摩擦声
- 避免：不要刹车尖叫
- 目标峰值：-16.0 dBFS（管线自动对齐）
- 变体：2 个

### `turtle` turtle 画线

- 用在：白色折线在屏幕上画
- 对齐：画线开始，持续到结束
- 时长：3000–9000 ms
- 性格：明亮的沙沙声（重心约 4.3 kHz），随折线每一折起伏
- 避免：不要像砂纸太粗糙
- 目标峰值：-8.0 dBFS（管线自动对齐）
- 变体：1 个
- 备注：长度不固定：做成可以无缝循环的 3 秒左右，管线会按需要的长度拼接
