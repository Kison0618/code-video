## 你只写一个文件
`demos\EC<n>.js`。不改任何别的文件。导出 `module.exports = { draw(ctx, t), over?(ctx, t), SFX }`（EC7 另导出 `END`）。
- `draw` 自己画满整个画面（背景到前景）。段的起止由总装 `ECX.js` 决定：从本段第一句 `vs-0.05` 画到下一段第一句 `vs-0.05`。开头 0.6 秒总装会做擦入转场，你把这 0.6 秒设计成入场动作；结尾 0.3 秒画面稳住。
- 字幕由总装画，你不画。`over` 里可以画泡泡、▶▶ 角标等屏幕层。
- `SFX`：`[{ t, k }]`，k ∈ knock / click / pop / tick / ff / heart / ding，按句取时间，只给关键事件（本段 2–6 个）。

## 质量底线（老板最在意）
- **不许平涂背景**：要有透视纵深、前中后景、光（灯、光斑、窗光、雾、景深虚焦），每一帧截出来像一张插画。
- 主体大（40–60%），放中上部；y>1330 字幕区别放重要东西。镜头要动，景别要换，每句至少一个镜头变化。
- 每句一个看得懂的动作，演的就是那句话的意思；不编额外的故事情节。动作有预备—惯性—余波。
- 画面字只限门牌/铭牌、泡泡（2–6 字）、片尾大字。
