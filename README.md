# code-video

纯代码生成的音乐视频。每个目录是一个独立作品，进去后 `node build.js` 一条命令出片（需要 Node.js 18+ 和 ffmpeg）。

> **接手这个仓库？先读 [`交接文档_HANDOVER.md`](交接文档_HANDOVER.md)**：协作方式、作品状态、红线、经验教训、技术架构都在里面。
