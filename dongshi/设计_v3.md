# 懂事 · v3 设计说明（风格：灯下光尘；配乐：经济舱 钢琴版整首 × 2）

## 一句话
同一个核：**情感不成熟的父母，让孩子提前长成了大人**（Gibson《不成熟的父母》）。v3 把内容加厚到 59 行字幕，配乐改成《经济舱》钢琴版**整首放两遍**（每遍 104.25 秒，都不剪），全片 **208.5 秒**：第一遍讲**他们**，第二遍讲**你**，最后回到开头那一幕。

## 配乐（`bgm_v3.m4a`）
- 由 `bgm_jjc.m4a`（104.256 秒）解码后，每一遍截到 104.25 秒，首尾相接，重新编码 AAC 48 kHz 立体声 → 208.5 秒。第二遍从 104.25 秒开始，前面那 1 秒左右的静音正好是两遍之间的换气。
- 110 BPM，一拍 0.545 秒（拍点 `0.04 + 0.545k`），一小节 2.18 秒（`BAR(n) = 1.675 + 2.18n`）；第二遍 = `BAR(n) + 104.25`。

## 时间线（`timeline.js`）
- 老场景（v1/v2 的场景代码）继续用它们原来的“场景时间”；v3 新场景用 **成片时间 + 1000**（`S3`），这样新旧场景都走同一张 `KNOT` 表：`[成片时间, 场景时间]` 分段线性，大部分段落速度 = 1，同一个成片时间出现两次 = 在黑场或静止处跳段。
- 切点暗场（`CUTS`）：59.7（大字 → 四种样子）、75.795（四种样子 → 饭桌）、140.5（屋子 → 手机）、144.4（手机 → 面具）、190.65（雨倒流 → 门厅）。
- 新场景的镜头（`CAM3H / CAM3V`）写在 `scenes3.js`，老场景的镜头表（`scenes.js` 里的 `CAMH / CAMV`）直接接上它们；`dimAt` 在 `t ≥ S3 - 1` 时交给 `dim3`。
- 一直在动的东西（雨、微尘、云、人物呼吸、盆景的红色心跳）用成片时间 `PX.t` 驱动，跳点前后不换相位。

## 字号与版式
- 字幕：横屏 54px、竖屏 62px；竖屏长句自动断成两行，落在 y 1400–1560。
- 大字：“孩子，成了父母的父母。”横 110px / 竖 104px（竖屏两行）；“孤独没有伤口，但一样疼。”横 84px / 竖 86px（竖屏两行）；“他们，也曾是那个孩子。”横 70px / 竖 62px；金句横 66px / 竖 62px。
- 小字：角标 22–26px；四类标签中文 34px、英文 20px；“退一步”的三行小字横屏 44px（x 150，y 430–630）、竖屏 40px（y 1215–1355，在地面线和字幕之间）；片尾卡只放片名（参考文献在 `文案.md`）。
