# 懂事 · v2 设计说明（风格：灯下光尘；配乐：经济舱 钢琴版整首）

## 一句话
和 v1 同一个核：**情感不成熟的父母，让孩子提前长成了大人**（Gibson《不成熟的父母》）。v2 把整片装进《经济舱》钢琴版整首（104.25 秒），所有节点卡在这首歌的小节线和拍点上。

## 风格（沿用 v1）
- 暗暖灰的房间、头顶一盏灯、空气里的微尘、地板淡淡的倒影；人物、云、雨、盆景都由光点组成（`fx.js`）。
- 关键色：冰蓝 = 孩子 / 雨 / 伞，红 = 惩罚 / 修剪 / 标签，橙 = 大人心里那个“情绪”，金 = 自己这边（只在结尾）。
- 字不发光、不抖；大字只用阴影托起来；字幕永远最后画。

## 时间线：怎么从 164 秒装进 104 秒（`timeline.js`）
- 场景代码还是 v1 那套“场景时间”（0–164 秒），新加 `timeline.js` 把**成片时间**映射到场景时间：`N2O(t)` 用一串关键点（KNOT）分段线性映射，大部分段落速度 = 1（动作不变快），只在没人注意的地方跳过。
- 跳点都放在画面已经压暗或场景切换的地方：59.7（大字淡出 → 手机）、67.36（重拍 3 的大字淡出后 → 盆景）、80.9（同一个镜头里，雨倒流前）、85.0（雨里 → 回到开头那一幕，压暗 0.45 秒）。`CUTS` 在 59.7、85.0 两个切点加一个短暗场。
- 删掉的段落：四种类型、电话、牌匾、三件小事清单（代码一并删掉）。盆景段原本向右平移给牌匾留位置，牌匾删掉以后镜头也不再平移，树留在画面正中（横竖都是），67.36 的跳点因此看不出来。
- 一直在动的东西（云的呼吸、雨丝、空气微尘、手机上的输入点）改用**成片时间**驱动（`PX.t`），跳点前后不会突然换一个相位；雨倒流用 `O2N` 换算回成片时间，保证连续。

## 和音乐对齐
- 110 BPM，一拍 0.545 秒（拍点 `0.04 + 0.545k`），一小节 2.18 秒（`BAR(n) = 1.675 + 2.18n`）。钢琴 1.68 秒进；23.475（BAR 10）全曲进入；75.8（BAR 34）音乐落下来；97.6 以后淡出，104.2 结束。
- 四次大特效全落在小节线上，前面都有约 0.45 秒的黑 / 暗：

| 秒 | 画面 |
|---|---|
| 23.475（BAR 10） | **片名**：15.4 秒男孩胸口那点光炸成 3600 颗光尘 → 停在半空，飘成一团慢慢呼吸的星云，移到片名的位置 → 每颗沿自己的弧线收进字形，落定时间散在 23.25–23.475 之间；落定那一下金色光环 + 横向光线 + 轻微色散 |
| 56.175（BAR 25） | 大字“孩子，成了父母的父母。”白色光环 |
| 64.895（BAR 29） | 大字“他们，也曾是那个孩子。”冰蓝光环 + 横向光线；大人在光里散成光尘，再聚回一个小孩 |
| 95.415（BAR 43） | 金句：一道金色横光 + 两行字（第二行金色，96.915 出现） |

- 其他卡点：字幕起点都放在拍点附近；“但伤害，是真的。”在 75.8 音乐落下的那一小节；盆景的三刀剪在 68.71 / 69.255 / 69.80 三个拍上；91.06（拍点）男孩举手欢呼；片尾卡和音乐一起在 104.25 结束。

| 59.7–64.3 | 手机：“妈妈”正在输入，三个点一直在跳，什么也没发出来（冰蓝气泡），屏幕里映着低头的孩子 |
| 67.4–75.7 | 孩子流成一棵盆景：红铁丝一圈圈缠上树干，三刀剪短枝条（剪口红色、溅火星）；背后浮出虚线的“本来的样子” |

| 85–94.5 | 回到开头那一幕：门开、大人蹲下来；花盆的裂纹被金色补上；91.06 男孩举手欢呼，金色微尘往上飘 |
| 95.4–99.7 | 金句 |
| 99.5–104.25 | **片尾光尘**：金色微尘从画面下方升起，沿弧线聚回“懂事”的字形（和开头片名同一批点），再出参考文献；104.25 淡完 |

## 字号
- 字幕：横屏 54px、竖屏 62px（竖屏离底边约 440px）。
- 角标 22–26px；片尾参考文献 v2 加到横屏 24px / 竖屏 26px，颜色调亮一档。
