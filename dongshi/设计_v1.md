# 懂事 · v1 设计说明（风格：灯下光尘）

## 一句话
一个从小“懂事”的孩子：开心要小声，难过要自己收，还得替大人撑伞。片子只讲一个核：**情感不成熟的父母，让孩子提前长成了大人**（Gibson《不成熟的父母》）。

## 风格
- **灯下光尘**：暗暖灰的房间，头顶一盏灯打下光锥，空气里飘着微尘；地板有淡淡的倒影。
- 人物、云、雨、盆景都由**光点**组成（粒子引擎 `fx.js`：边缘密而亮，内部稀而暗；只在关键物上加一点泛光）。
- 关键色：冰蓝 = 孩子 / 雨 / 伞，红 = 惩罚 / 打分 / 修剪，橙 = 大人心里那个“情绪”，金 = 自己这边（只在结尾出现）。
- 字不发光、不抖；大字只用阴影托起来。字幕永远最后画。

## 镜头
- 每段只有一个慢推或平移（`scenes.js` 里的 CAMH / CAMV 关键帧）：开头 12.9 秒起慢推向长大后的“你”；雨里那一段推近“撑伞”；盆景段向右平移给牌匾留位置。
- 竖屏（1080×1920）重新构图：四种类型排成 2×2；盆景段把牌匾放在上方、树在下方；所有内容避开左上角标和底部字幕区（已逐帧核对）。

## 字号（“字幕别太小”）
- 字幕：横屏 54px、竖屏 62px（竖屏离底边约 440px）。
- 角标 22–26px；类型标签 中文 34px / 英文 20px；牌匾引文 22px；清单 标题 48px / 条目 44px（竖屏 42px）；片尾参考文献 22px（竖屏 24px）。
