# 懂事 · v7

**257 秒**，30fps，横屏 1920×1080 和竖屏 1080×1920 两版（`demo.html?ar=9x16` 是竖屏，同一条时间线重新构图，不是裁的）。配乐：**《我心永恒》钢琴独奏，从头用到 257 秒**（片尾卡停到 257 秒，歌最后 20 多秒的尾奏不用，混音时 253–257 秒淡出；`../reference-videos/泰坦尼克号 我心永恒 钢琴独奏 My Heart Will Go On [BV1RC4y1a7Py].m4a`，285.57 秒），大节点卡在这首歌的强拍上（见 `设计_v5.md`）。内容来自 Lindsay C. Gibson《不成熟的父母》（*Adult Children of Emotionally Immature Parents*, 2015）。风格：**灯下光尘**，人物、云、雨、盆景、面具都由光点组成。下面的结构表是 v3 的时间（经济舱版），现在的时间以 `文案.md` 为准，v7 的改动见 `设计_v7.md`。

第一遍讲**他们**，第二遍讲**你**，最后回到开头那一幕。

## 结构

| 秒 | 内容 |
|---|---|
| 0–23.4 | 开头先亮观点：有一种父母，脾气说来就来，从不道歉……人人都夸你懂事；可是，没有人问过你，累不累 |
| 23.475 | 重拍 1（全曲进入）：片名“懂事”；为什么，你那么早就懂事了？ |
| 27.8–54.5 | 情感不成熟：情绪传染、“都怪我，行了吧！”、不修复关系、角色颠倒（孩子在雨里替大人撑伞） |
| 56.175 | 重拍 2：孩子，成了父母的父母 |
| 59.9–75.6 | 四种样子：情绪型 / 驱动型 / 消极型 / 拒绝型，常常混着来 |
| 75.8–102.6 | 情感孤独：家里明明有人，心里却没人；什么都不缺，为什么还是难过 |
| 95.415 | 重拍 3：孤独没有伤口，但一样疼 |
| 104.25–121.1 | 第二遍 · 懂事的代价：先看脸色、满分换来“别烦我”、把别人放第一位、演一个不添麻烦的孩子（微笑面具） |
| 127.7–140.4 | 治愈型幻想：“要是我再好一点，他们就会懂我”；无条件的爱换不来；长大后爱上熟悉的冷淡 |
| 140.8–159.6 | 那句对不起可能永远不会来；面具裂开——撑不住，是觉醒的开始；不是因为你不值得—— |
| 160.425 | 重拍 4：他们，也曾是那个孩子 |
| 163.7–182 | 根源：只该被看见、不该被听见；盆景；像一直疼着的人；不是故意的，但伤害是真的 |
| 182.2–190.6 | 出路：生气不是不孝；退一步，像旁观者一样看（原书第 8 章三个办法）；你改变不了他们，但能救自己（雨倒流） |
| 190.9–199.2 | 回到开头那一幕：以后摔倒了，先抱抱自己；不是你的错，就不用道歉；开心，可以大声一点 |
| 199.665 | 重拍 5 · 金句：看清他们，不是背叛。是终于，站在了自己这边 |
| 204.025–208.5 | 片尾卡：只放片名 |
