# 同一个人（画面工程）

1920×1080，30fps，全片 321.4 秒（按原片配音的节奏对齐；换配音后会自动变）。
只有画面，不含配音、配乐、音效。没有渲染成片，自查用的关键帧在 `关键帧/`（21 张联系表，每张 6 帧，左上角是时刻）。

## 换配音（三步）

1. 把新配音放到 `audio/`，比如 `audio/voice.wav`。
2. 对齐：`python tools/align.py audio/voice.wav`
   它会做语音识别，把 115 句文案逐字对到配音上，重写 `timing/timing.json` 和 `src/timing.js`。结束时会列出“对不上的句子”，那几句要人工听一下。
3. 预览：浏览器打开 `index.html?play`（空格播放，← → 跳 2 秒，Shift 加方向键跳 10 秒）。

画面代码里没有写死的秒数，全部用 `TL.s('句子id')`、`TL.at('句子id', '词')` 取时间，所以对齐完画面就跟着走了。
片尾在最后一句说完后留 19 秒（海和片名），要改就加 `--tail 秒数`。

出整片：`node tools/render-all.cjs audio/voice.wav`（多进程出帧，再用 ffmpeg 合成 `out/同一个人.mp4`；不带参数只出帧）。

依赖：Node + `npm i`（playwright）；Python + `pip install faster-whisper pypinyin`；ffmpeg。字体已经裁好放在 `assets/fonts/`（Noto Serif SC、Noto Sans SC、JetBrains Mono，都是 OFL 许可）。

## 文案

唯一来源是 `timing/lines.json`（115 句）。花括号里的词是字幕里变色的关键词。句子的 id 被画面引用，顺序和 id 不要动；改字可以，改完重跑 `align.py`。

和原片相比只改了一处：`i2`“你看这一屋子人”改成“你看这一排人”，因为接力那一段从屋里搬到了跑道上。不想改就把这句改回去，画面不受影响。

## 画面设计

整片是一种材质：发光的小木板马赛克。画面先画进一张 320×180 的小画布，一个像素就是一块木板，再一块块铺满屏幕；每块木板可以单独翻面。“被换掉”这件事全片都用翻木板来演，和“木板一块一块全换掉”是同一个动作。近景换成 12px 的粗木板，看得清一块一块。

关键色只有一种：金色，代表“原来的”和“被传下去的”。红色只用在“被换掉、被骗”。字不发光、不抖。

## 和原片的关系

文案、段落顺序、“九样东西偷偷换掉”和“九个词里没有睡觉”这两个骗局来自原片，这是内容本身。画面是重做的：房间的布局、配色、家具、人物造型、船的样子、揭穿的方式、计数方式、接力的场地都和原片不同。

## 需要在你那边做的

- 配音、配乐、音效、混音、出成片。
- 音效建议点位（按句子 id，换配音后不会错位）：a2 海翻成房间；b6 每张卡片弹出；b10 整屋一下子翻回去；c1/c3/c5/c7/c9 每次换年纪；d2–d4 旧木板飞走、新木板落下；d5 最后一颗金钉灭；g4“没有”；g10 拼出“睡觉”；g15–g17 重拼越来越快；i6–i8 每次交船；j8 递出去、剪影亮起。
- 竖屏版没有做。

## 没把握的地方

- “往前看、回头看”那张图是示意图（画面上标了“示意图”），柱子高度不是论文数据，只保证方向对：每个年纪回头看的变化都比往前估计的大，两者都随年纪变小。出处 Quoidbach, Gilbert & Wilson, *Science*, 2013，一万九千多人，18 到 68 岁。
- 词表实验标的是 Roediger & McDermott, 1995。原片说“做了三十年”，我没有另外核实。
- 胃壁几天、皮肤一个月、血四个月、骨头十年，以及“旧零件早够再拼一个你”，都照原片文案，没有另外核实。
- 时间是按原片配音对齐的，新配音的停顿不一样的话，“有没有睡觉？”后面那段留白（现在约 3 秒）要再看一眼。
- 我只看了静帧，没有看过连续播放，动作的快慢要你预览时判断。

## 文件

| 路径 | 内容 |
|---|---|
| `index.html`、`src/player.js` | 预览页；不带 `?play` 时只等逐帧脚本调用 `window.render(t)` |

| `tools/align.py` | 配音对齐 |
| `tools/frames.js`、`tools/render-all.cjs`、`tools/sheet.sh` | 抽帧、出整片、拼联系表 |
| `tools/subset_fonts.py` | 重新裁字体（画面里加了生僻字才需要） |
